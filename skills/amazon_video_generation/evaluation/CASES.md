| 单镜要环绕+升降+推近+转焦 | 保留一个主路径（必要时K类一条辅助），其余拆镜或删除，不堆叠 |
| “两倍环绕”指的是2×取景 | 按SC-06锁定档位、后退取景、走15–30°短弧；不写“商品放大两倍”，不承诺背景压缩 |
| 只有一张正面图却要贴面低角掠移 | 允许在已知角度内小位移，但需说明台面/盆底关系来自实拍；无依据时改常规横移或固定 |
| 新品要“多角度丰富” | C02给2–3个角度差≥30°的机位（P2/P3/P6），不是五个相同轻推；C03仍以证据镜为主 |
| 交付分镜CSV | 跑 check_camera_plan.py，无error才算结构过关；脚本通过不代表成片质量 |

## v3.4 可变时长、片段内切镜与跨片段换场景
