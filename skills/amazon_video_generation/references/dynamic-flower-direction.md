# 花卉动态导演：环绕、尺寸、细节、插花与生活场景

适用于v6.1花卉路线，追加[终态倒推与真实运动](terminal-state-and-motion.md)。用户明确纠正：镜头环绕，载体和花卉不自行旋转；尺寸可做立体空间展示；细节需要微风/接触等可见动态；插花展示多次；多场景不能是静图缩放后轮播。本文件是分镜与写词必读的执行规则，覆盖旧版相冲突的拍法。

## 1. 相机绕行，主体扎根在空间里

本节固定落点/不自转适用于固定陈列的运镜展示；不禁止有真实驱动的手持单件小转或已核悬挂物轻摆。后两者另写握持/支点、作用力与终态，不把例外迁移到无人操作的台面成品。

花器/载体的落点、朝向及与台面的接触关系锁在场景坐标中，花卉不作为一个整体自行转动。相机沿以花卉为中心的短弧移动并持续对准主体，花卉在屏幕中的可见侧面、重叠和轮廓随视点自然改变。柔软枝叶因风或接触的局部摆动另行描述，不与整体自转混为一谈。

背景随视点产生**透视和视差变化**：近处桌沿/前景与远处窗框/墙面产生不同幅度的屏幕位移、遮挡关系改变，并露出原来被主体遮住的背景。房间和家具本身固定，不让背景贴图绕着静止正面商品旋转，也不把整张图做二维旋转。锁定世界中的窗光位置；镜头移动可改变可见明暗面，但不让光源跟着镜头转。

每个环绕词给出起始机位→终止机位、路径方向、焦距/拍摄距离策略、一个近景参照物与一个远景参照物的视差。具体角度在参考覆盖和时长内选择，不能因角度不足直接把用户要的环绕换成静图放大。

写法示例：相机从花器正前方沿台面外侧向右侧前方缓慢绕行，保持拍摄距离和焦距，持续对准花卉中心；花器底部落点与朝向固定。近处桌沿与远处窗框出现不同幅度的视差，逐渐露出花束左后方原被遮挡的柜面；花束不自行转动，最后在侧前构图停稳。

## 2. 尺寸段：真实空间中的测量关系

早期折叠/展开参考已转成文字（原图可从amazon-video-v6.1.0恢复），借用范围仅为：斜俯视、可辨顶面/侧面、沿实际轴线的长宽高标注、状态分别可读。两张静图不能证明中间运动路径，也不授权把其尺寸或折叠机制迁移到花卉。

尺寸镜默认切入专业洁白无缝影棚或干净白色空间，参考[WHITE01](display-background-library.md#white01-洁白影棚与尺寸空间)；白色产品用轮廓光和浅灰接触阴影分离。默认采用镜头的空间绕行：固定完整花卉与花器，机位从侧前斜俯视移至另一有依据的侧前视角，展示纵深、花冠宽度、单枝长度或整体高度。尺寸引线在三维测量端点建立，随视点更新投影；数字始终正向易读，不能粘在画面角落假装跟踪端点，也不随商品透视缩放而改变读数。可先出现高度，再出现宽度/深度，最后停留读数；不必每个SKU都有三个尺寸。

只有确有两种状态（如已核收拢/整理后）才做“状态A→有依据的展开动作→状态B”，分别用对应实际尺寸。普通固定花束只展示多角度和测量关系。尺寸线可自动展开，花器与花束仍不自行旋转。D2分组陈列是另行选定的视觉动画，可移动真实独立花枝进行分组，不作为载体和整束自转的例外。

## 3. 细节有可见响应

可独立拿取且有依据的单枝/部件，优先稳定握住下部，轻转到已知侧面并短暂停留，再按材质选择轻抚或小幅拨动。可塑枝释放后可保持新形，不默认回弹；固定花束不拔枝，干脆花材不强弯。细节的目标是看清多个面和局部响应，不只是让全束摇晃。

每个细节镜至少安排一种与产品相符的连续变化，不再以整段纯静帧或二维放大作为默认：

- **微风**：只让有柔性的花瓣边缘、叶尖或细枝小幅、错相、略有迟滞地摆动；花器底部、主茎固定处不漂移。给风向、影响部位、幅度和逐渐停下的终态。无需所有花瓣一起周期振动，不让花朵像旗布起伏。
- **轻抚**：手从画面外接近，以指腹沿一片花瓣边缘或一小簇花材轻抚，局部轻偏移，松手后自然稳定；写接触点、另一只手是否支撑和终态。不能用手遮满主体或通过按压夸张宣称柔软/回弹。
- **材质不适合风或触摸**：用短距离侧向移动/贴面掠移，让前后花瓣产生视差、表面明暗自然变化；说明不采用风/接触的产品原因，不把“保持细节”当静图轮播理由。

相机可固定，画内有动作仍是动态镜头；相机移动与主体接触不宜都大幅变化。先让人看清纹理，再看细微响应，保留短暂可读停留，不强制每一帧都晃动。动态观感不构成材质或性能实测证据。

## 4. 默认3次插入，或手中整理后成束插入

先选好最终造型，再按[终态倒推](terminal-state-and-motion.md#1-先确定完成态再设计可到达的中间态)反向规划去除的三枝/三组与剩余基础布置。所有状态对照同一完成态，正向补入后应恢复其轮廓、疏密、高低与朝向；三次不是最终只剩三枝。这里倒推的是参考状态，视频仍正常插入，不倒放抽出动作。

选择逐次插花时，默认展示**3次可辨认的插入—落位—松手**，并穿插扶正、疏开、调整花头方向；用户可调整次数。容器不必为空，可预先已有部分同SKU花材，起态须记录器内、手中、台面的花材及其来源，后续在此基础上累积。不能只完成一次普通插入后立刻用成品静图冒充3次过程。

另有独立替代模式：**先在手中整理好部分花材，再一次性插入**。显示一手握住数枝下部、另一手调整高低/朝向与颜色层次→收拢并对齐茎端→整束进入花器→落位松手→轻整结果。可从手中已有部分花材开始，也可插入已含其他花材的容器；束径与瓶口、手部抓握和枝条轨迹须合理。该模式计为1次成束插入，不要求再重复3次；它的完整整理过程与普通单枝插一下不同。已选此模式不得被旧的“禁止一次插入”规则拒绝。

多色/多花型产品优先让不同已确认售卖花材参与不同轮次：各次按目标造型的实际缺口补入，例如补中心高度、侧向层次或局部空隙；已有基础花材时不重新打乱整体来硬套这个顺序。每轮在已有花材上累积，器内已有枝不消失，台面/手中花材来源清楚。同一套装混色与不同色号分别销售须区分：独立色号可用独立片段/容器展示，不能默认混插成一套。

可以在落位松手后跳切到下一次取枝，省略等待和搬手的空时间；每种关键动作保留足够的入瓶过程。不要倒放插入、连续变色或把花材突然增多当作插花完成。过程不必展示售卖的每一枝，仍应明确是展示而非完整教程。

25–30秒综合片通常给插花约8–10秒，具体依3次操作或手中整理成束的实际长度调整。15秒版先减少其他模块/场景或加长；若改用成束模式，明确其完整动作和时间取舍，不默默删成单枝插一下，也不用异常加速塞满动作。固定不可拆成品改为真实整理/摆放步骤，不假装重新插入不能拆出的花枝。表中记录模式 `sequential` 或 `bundle`、目标插入次数（默认3或成束1）、起态已有花材和逐步终态。

## 5. 每个场景是一段发生中的画面

室内、室外展示台按[背景库](display-background-library.md)匹配产品配色和尺度；前几秒可在该台完成环绕亮相，再接尺寸、细节、插花与其他场景。开场成品切回插花过程须交代为另一镜的过程展示，不能在连续镜头中让花材消失。场景图提供空间与外观参考；视频重新描述该空间内的时间过程，不逐张播放套图。每场写出“进入时正在发生什么→中间怎样变化→结束时是什么状态”，并交代至少一个能看见的动态来源。

生活场景优先持续的轻微画内过程与合理响应，并配低幅度可达机位轨迹；一次姿态后冻结不算完成，复杂接触可固定机位；只有不适合动作或用户约定无互动时才单用真实机位运动，并记录理由，不同时堆所有动效：

|场景任务|可执行过程|空间真实感|
|---|---|---|
|客厅展示立体轮廓|相机从扶手/桌边前景旁做侧向弧移，逐渐露出完整花卉|前景、花卉和远处墙面产生不同视差；花器落点不滑动|
|餐桌使用|手将花器放稳、松手，轻整一枝后离开，短暂停留结果|接触、承重、遮挡和花枝响应连贯；不暗示道具随货|
|玄关或边柜适配|相机沿柜面横移，花卉始终为主体；人物经过可作为用户选定的背景动作|相机经过真实空间而非裁切放大；背景人物不抢主体|
|窗边近景|柔和空气流动只带动柔软花材/窗帘，相机可固定或轻微侧移|不同部位的幅度与迟滞自然，固定容器不动|

允许有信息目的的相机沿光轴推进，但必须描述真实透视/遮挡变化或配合可见动作；纯数字裁切放大不能代替摄影运动。场景序列不允许每段仅“静图＋慢慢放大＋淡入下一张”。静止物件不需要全都运动；有合理三维视差的环绕/横移可建立空间，但生活场景不以它作为全片默认替代微动作；按用途选择合适轻微响应，不强制添加人物、粒子或不适合的风。

每场先列用途、主体摆位、近远锚点与相对上一场的空间差异，再选择运动；不是每场复制同一角度横移。按[运动与联动规则](terminal-state-and-motion.md#3-多场景先区别用途与空间再选运动)说明可见侧面/遮挡变化，光源保持世界位置。悬挂花篮有真实支点才摆动，篮体姿态、柔软花叶迟滞及可见投影相互对应；台面花篮不整体漂移。静止背景及稳定光照可以保持稳定，不强求光影闪动。

跨场仍用匹配剪辑或必要遮挡转场：相邻镜头接续商品位置、主朝向、景别或运动方向，每一场内部先具有真实过程，再讨论怎么切到下一场。不能靠花哨转场掩盖各场仍是静图。

## 分镜与生成后验收

每镜在表里列 `相机运动 / 主体动作 / 环境响应 / 空间参照与视差 / 起中终状态`，分清谁动、谁固定。固定相机不等于静止画面；环绕也不等于商品旋转。

关键动态镜至少用两个有意义的状态/视角表达变化，必要时补中态。不可把同一图裁成大/小两格当成相机位移证据。静态分镜只能检视计划；生成后才检查连续帧中的视差、接触与累积动作。

判为待修正：花器自转或底部滑移；背景像平面贴纸旋转；整张画面等比放大却无空间/动作变化；细节全静止；每朵花同步摆动或材质液化；逐次模式目标3次却未完成，或成束模式缺少手中整理便直接跳成品；多色变换没有真实取枝动作；跨场SKU外观漂移。先修路径/参考/动作和时间分配，不直接退回静态轮播并称完成。
