# 花卉、植株与树木的视频方法

> 适用范围：花卉按[结构库](flower-video-formats.md)选择F01–F07，只有F01默认前5秒环绕＋人物插花；草木按项目选镜。新项目通常约30秒内；本页旧时长仅历史例子，摄影手法是可选工具，不限制首尾运动、人物或留白。

用于从买家问题选择镜头，而非固定镜头模板。**先选结构**：[蓝图库](plant-video-blueprints.md) 的 B01–B09 决定四段顺序与所需素材；**再筛卖点**：[卖点证据表](claims-and-evidence.md) 决定哪个卖点能进画面。本页负责“什么商品适合拍什么事件”。方法综合公开品牌教程正文、平台可访问说明与 Amazon 制作指南；来源及访问限制见 [平台研究](platform-research.md) 与 [本轮研究](research/2026-10-29-plant-video-research.md)。下文的镜头设计是迁移提案，不是声称看过某条参考片的逐镜还原。

外观和生活方式表达另结合两条本地拍摄样片提取的 [商品摄影与场景导演](product-cinematography.md)：用布景、光影、景别与可见事件形成氛围，来源与实际抽样范围单独记录，不与上述文字调研混作连续观看证据。

## 先分商品，再选事件

| 商品类型 | 优先解决的问题 | 操作前需要的本 SKU 依据 |
| --- | --- | --- |
| 仿真花、散枝、枝束 | 实际有几支、花头/茎杆细节、插瓶后多大、如何整理 | 支数、总长与花头尺寸；是否可弯/可剪及具体部位；花瓶是否随货 |
| 花盆、花器及托盘 | 盆体设计、表面/底部结构、适配摆放、随货边界 | 内外尺寸与材质、孔位/托盘关系、允许用途、配植/介质是否随货；不从镂空外观推透气、排水或耐热性能 |
| 仿真盆栽、大树 | 到货状态、展开后的轮廓、底座与装饰盆、房间占地 | 枝叶能否整形、真实展开步骤、基座结构、组装连接、测量状态与端点 |
| 花环、藤条、花墙、地插 | 怎么固定、覆盖范围、一个包装够哪里、收纳 | 长度/直径、安装点、承重与适配支撑、固定件/工具是否随货；室内外用途 |
| 活体盆栽、树苗 | 到货形态、盆/土/根系、摆放、养护 | 品种、售卖生长阶段、规格范围；本品光照/浇水/修剪说明与适用条件 |
| 鲜切花 | 开箱、整理、插瓶、阶段性状态 | 交付成熟度、支数、保鲜说明；修剪/换水步骤及配套材料 |
| 干燥花、保鲜花 | 脆弱部位、摆放、除尘、保存 | 工艺和材质、避水/避晒/湿度要求与可清洁方式；不能自动套用鲜切花养护 |

没有材质/说明书时，不因为外观看似塑料就演示冲洗，也不因为茎杆有线芯就安排反复弯折。其他品牌的教程只能说明可研究哪类问题，不能授权我方相同动作。

## 可组合的镜头模块

从“买家疑问 → 可见事件 → 可验证结果”写起，每段只承担一个主信息。优先选有证据且影响购买的少数模块。

| 模块/问题 | 可拍事件与镜头连接 | 最小输入与验收重点 |
| --- | --- | --- |
| 整体效果：摆进家里是什么样？ | 从已经布置好的真实比例全貌开始；切到商品占主导的中景，保留桌面/地面接触 | 同 SKU 清楚全貌、尺寸与场景比例；不把背景植物混成套装，不开场只放 logo |
| 细节：近看是什么外观？ | 先交代局部在全株的位置，再沿一片叶/花瓣小幅横移，停在纹理或连接处 | 原始局部清楚可辨；不过度景深虚化关键结构，不用逆光隐藏材质差异 |
| 尺度/包装：到底收到多少、多大？ | 同一平面摆出实际售卖支数；需要时展示已知测量端点、完整盆底和树顶 | 套装数量、测量状态/端点、道具归属；镜头焦距/透视不能夸大尺寸 |
| 开箱/整形：如何从包装状态变成成品？ | 包装全貌 → 取出/支撑 → 一处代表性展开动作 → 同角度完整结果 | 本 SKU 包装和真实演示；不凭最终美图编到货状态，不暗中增加枝叶或剪掉步骤 |
| 布置使用：我能怎样摆？ | 让已知容器/支撑在画面里；手先托稳，再放入一支或将盆栽置入装饰盆，松手后停稳 | 同 SKU 步骤、容器尺寸、插入深度/支撑；多次布置不暗中剪短茎杆，装饰盆另购时明确 |
| 安装：能不能装、装好是什么样？ | 中景交代支撑与配件 → 接口局部显示接触与固定 → 中景展示稳定结果 | 接口/固定件细节和真实安装步骤；不能用遮挡切换伪造卡入、承重或适配性 |
| 清洁维护：需要做什么？ | 已确认可用的工具入画 → 手托部位 → 完成一次明确清洁动作 → 保持原色与结构的结果 | 本 SKU 清洁说明/允许工具与介质；不凭品牌通用文案安排喷剂、水洗、吹风、蒸汽或加热 |
| 活体养护：什么条件下怎么做？ | 先交代与步骤有关的盆土/位置，再演示有依据的一步，保留实际状态 | 本品养护说明；不生成生长/复活来证明效果，不把特定浇水频率变成所有植物通用建议 |

整形重点是可见的结构展开，不是凭空“变蓬松”。前后对比保持同一产品、支数、尺度、机位和灯光；允许的造型改变单列。除尘不等于零维护；不浇水不等于可水洗；室外摆拍不等于耐晒、耐雨或抗风。没有对应证据，就换成室内场景和可见外观信息。

用户明确要求维护而依据缺失时，说明当前版本尚未覆盖该部分、最小所需依据及可替换镜头。已授权直接给方案时先交可完成的内容，不静默删掉维护后声称全部目标达成，也不重复询问用户已经明确未知的事实。

## 实拍与 AI 的分工

默认四段AI视频时，在镜头卡注明C-ID、所需实物照片/操作视频及参考角色；操作实拍参考不自动成为外部剪辑片段。只有用户选择混合制作时才安排实拍与AI的后期路线。这里不扩大为自动拍摄、提交模型或生成最终视频的权限。

- **真实操作参考优先**：包装取出、接口组装、整形、剪枝、浇水、清洁、承重/固定；先看同 SKU 真实操作，再决定必要景别。原片也需检查遮挡、变速与跳切，不能只凭前后状态推断接触；默认它用于约束同次AI生成，非强制插入后期实拍段。
- **AI 可用**：清楚已知外观下的场景、构图、柔和光线与小幅相机移动预演。手物接触清楚有依据时可预演，但生成结果仍是演示草案，不承担功能验证。
- **混合方案（用户选择时）**：实拍关键动作，AI 预演场景/过渡；匹配主体轮廓、物理尺度、灯向、手别与道具。整片路线中，真实动作也可只作为输入参考；事实不足则收窄或将总词标草案，不自动转为实拍混剪；默认四段AI之间按连续性约定连接。

每个操作写出“手/工具从哪里进入 → 支撑哪里 → 接触哪个部位 → 向哪个方向施力 → 何时松手 → 结果如何停稳”。同一短镜只留一个主要操作；需要多步时拆镜，在确实发生的动作上接切，保留识别动作前后状态的余量。

## 构图、灯光与声音怎么服务信息

- **花瓣、叶脉和细茎**：用面积较大的柔光从侧前方建立层次，反光过强时调光位或加柔光；局部保留颜色与纹理。逆光可作轮廓辅光，不能用通透效果宣称材质，也不能让叶面曝光失去细节。
- **高树与垂挂藤条**：先拍完整轮廓与支撑点，再拍细节；竖构图与目标横版冲突时重新构图，不用模糊侧边补成横版。顶部、盆底、花环悬点按主信息保持可见。
- **操作镜头**：固定机位或轻微跟随，让手避开连接点；统一白平衡和曝光，避免绿色偏色或亮度跳变。实拍可锁定曝光/对焦并用稳定支架，生成词则描述相应画面目标，不虚构相机型号来保证效果。
- **剪辑**：全貌 → 动作/局部 → 结果有识别链；用同向动作、同位置或相近轮廓接切。不能为卡点剪掉关键接触、换货或支撑，操作速度以看懂为先。
- **声音**：静音也应看懂主要事件。包装、枝叶、布料等声音仅在真实存在且版位支持时使用；仿真塑料不强加植物生长/绽放声，维护效果不靠夸张音效证明。广告版位的声音和字幕选择见 [版位适配](amazon-placements.md)。

## 可调整的剪辑例子

以下是本技能的策划示例，均以事实齐全、目标版位允许为前提，不是平台规定或来源视频的实测节奏。默认时段是整片内部生成节奏目标；动作过多先收敛代表动作，需改总长时尊重用户决定，不要求逐秒命中，也不默认后期裁切。

| 示例 | 连续剪辑时间线 | 适用条件 |
| --- | --- | --- |
| 15 秒外观/布置片 | 0–3s 整体场景；3–8s 一次已确认的摆放动作或局部观察；8–12s 另一处有用细节；12–15s 完整结果 | 适合较少信息；操作无依据时改为局部展示，不自动加入维护 |
| 30 秒详情说明片 | 0–3s 成品效果；3–8s 售卖数量/尺度；8–16s 真实布置或展开；16–22s 纹理细节；22–26s 已确认的维护一步；26–30s 完整结果 | 维护不适用或依据缺失时删去并重排；需要读字/复杂组装则调整时长 |
| 单特征独立片段 | 商品/操作对象直接入画 → 完整的一次动作 → 结果停稳 | 用于 Sponsored Products 等独立特征组织；无声能懂，不依赖上一段，也不自动加尾卡 |

交付时把采用的模块、选择理由、依赖事实与实拍/AI路线写进分镜或镜头卡，不再另建一份重复镜头表。没有实测数据，不宣称某开头、镜头频率或时长能提高转化率。
