# 卖点证据与合规边界

> 适用范围：花卉按[结构库](flower-video-formats.md)选择F01–F07，只有F01默认前5秒环绕＋人物插花；草木按项目选镜。新项目通常约30秒内；本页旧时长仅历史例子，摄影手法是可选工具，不限制首尾运动、人物或留白。

用途：在选 C03 卖点、写后期文案之前查这张表。规则只有一条——**每个进入画面的卖点，都要有一张能拍出来的证据镜；没有证据就换卖点，不换形容词**。

证据来源：亚马逊误导性声明政策、广告审核指南、公开评论与品牌支持页，见 [本轮研究](research/2026-10-29-plant-video-research.md)。以下为一般性说明，不是法律意见；实际站点与品类以官方入口为准。

## 一、买家问题 → 画面证据 → 不能声称

### 真植物

| 买家问题 | 需要的画面证据 | 不得声称 |
| --- | --- | --- |
| 到手是不是死了/蔫了 | 开箱第一帧、叶片与茎杆状态 | “保证鲜活到货” |
| 实物比图小 | 手或已知参照物同框 | “所见即所得” |
| 会不会掉叶 | 完整株、正常光照下的稳定状态 | “零掉叶” |
| 是不是只有扦插条 | 冠幅与株型完整可辨（有根系资料才拍根） | “多年生大苗” |

### 仿真植物

| 买家问题 | 需要的画面证据 | 不得声称 |
| --- | --- | --- |
| 会不会一眼假 | 侧光近景的叶脉与叶缘、自然光下的真实色 | “以假乱真”“最逼真” |
| 塑料味重 | 画面无法证明，因此不谈气味 | “无异味” |
| 颜色失真、荧光绿 | 自然光实拍、同场景真叶并置（若已有） | “和真植物一模一样” |
| 会不会掉屑 | 叶片完整、接缝干净的近景 | “永不掉叶” |

### 花盆/花器

| 买家问题 | 需要的画面证据 | 不得声称 |
| --- | --- | --- |
| 含不含盆/托盘 | 整套商品平铺清点的画面 | “含盆/含托盘”（若实际不含） |
| 盆壁薄不薄、会不会裂 | 盆壁截面或边缘厚度近景 | “防摔防裂” |
| 有没有排水孔 | 盆底/孔位翻转特写 | “可直接种活植物” |
| 尺寸合不合适 | 与植株/手同框的比例 | “适配任意植株” |

### 树/大件

| 买家问题 | 需要的画面证据 | 不得声称 |
| --- | --- | --- |
| 高度够不够 | 卷尺或人/家具同框的完整全高 | 未经测量的具体高度 |
| 是不是光杆秃枝 | 整树完整轮廓、多角度 | “枝繁叶茂” |
| 户外会不会褪色倒伏 | 加重底座、结构连接近景 | “户外耐晒十年” |
| 要不要自己组装 | 组装前后对比、接口特写 | “免组装” |

### 折叠/带灯装饰（pop-up 树、pre-lit、可拆装）

| 买家问题 | 需要的画面证据 | 不得声称 |
| --- | --- | --- |
| 到底多高多宽 | 与标准门框（美标内门约 80 英寸高）或沙发扶手同框、平视完整全高 | “超大”“比同类都大”；不用仰拍夸大 |
| 装起来麻不麻烦 | 同款已核步骤支持的AI演示或用户选择的实拍；接触支撑可辨，不把生成时长当实测 | “几秒装好”（无实测就不写数字）；AI演示不靠“自己长高”的形变代替动作 |
| 收起来占多大地方 | 收起状态与门后/储物柜同框（实拍） | “随便塞哪都行” |
| 灯珠与模式数量 | 亮灯 1–2 个可辨状态 + 后期字幕 | 不逐个数灯珠；10 秒里演“8 种模式”；不说寿命、省电 |
| 插电还是电池、线够不够长 | 实拍插头/适配器静帧 + 线长字幕 | 不说 cordless/battery；不说 UL/CE 认证（无证书不写） |
| 装饰是不是都带 | 近景扫过蝴蝶结、织带、球、金花，字幕写“comes with…” | 不把礼物盒、花环、挂袜、蜡烛、壁炉算进画面暗示随货；数量不写进画面 |
| 会不会掉针、掉金粉 | 针叶与花瓣接缝近景，正常光照 | “零掉毛”“永不掉” |
| 阻燃/防火 | 无检测报告就没有画面证据 | fire-retardant / fireproof 一律不出现 |

## 二、高频差评词与画面回应

| 英文原词 | 中文 | 画面怎么回应（不是文案怎么解释） |
| --- | --- | --- |
| looks fake | 显得假 | C01 用侧光近景给叶脉与叶缘，不用正面平光 |
| smaller than expected | 比预期小 | 全貌必须带参照物；不用仰拍夸大 |
| arrived dead | 到货已死 | 只做 B02 且素材真实；否则不拍开箱 |
| leaves fell off | 掉叶 | 拍完整株稳定状态，不拍“抖一抖”表演 |
| strong plastic odor | 塑料味 | 画面无法证明，不碰这个卖点 |
| color is off | 颜色失真 | 自然光、统一白平衡；不把绿叶调成荧光 |
| sheds everywhere | 到处掉屑 | 叶片接缝近景；不说“永不掉” |
| not as full as advertised | 不如宣传饱满 | 整形前后同机位对比（仿真），数量可数 |
| bottom chipped | 盆底磕缺 | 盆底完整近景 |
| fades in sun | 晒褪色 | 没有耐晒报告就不拍户外长期使用 |

## 三、亚马逊视频里不出现的内容

- 价格、折扣、优惠码、限时、促销 CTA、站外链接。
- 评论星级、Best Seller、#1、销量排名、模拟的亚马逊页面/按钮/Prime 标识。
- 点名竞品或贬低竞品。
- 健康与安全功效：抗菌、防霉、净化空气、防过敏、适合婴幼儿房。
- “guaranteed / 100% / 永久 / 终身” 类绝对承诺。
- 未经证实的性能年限：UV-resistant、fire-retardant、lasts 10 years 等，只有检测报告才可说，且不能写成 fireproof。

## 四、表述分级

| 级别 | 例子 | 处理 |
| --- | --- | --- |
| 可直接用（画面可证） | faux eucalyptus in a 6-inch pot；no watering needed；shown at actual size | 直接写，前提是画面真的这么拍 |
| 需证据才可用 | most realistic；UV-resistant；fire-retardant；fade-resistant | 有报告/说明书才写，并在 brief 记录证据编号 |
| 不要用 | best、guaranteed、lifetime、air-purifying、anti-allergy | 一律删掉，换成可拍事实 |

## 五、合规边界（一般说明）

- **欧盟 GPSR**（2024-12-13 起）不涵盖活植物；仿真植物与花盆属一般消费品，需 EU 境内责任人与可追溯信息。CE 不是这类产品的通用标志，不要自贴。
- **活体跨境**：对美受 APHIS 要求约束（许可、无土介质、植物检疫证书等）；对欧盟需出口国植物检疫证书，部分高风险属有暂禁清单。因此视频**不承诺**“全球直送活体”“跨境可寄”。
- **仿真植物的标注**：listing 与视频应明确 artificial / faux，不用“真植物”暗示；室内外用途按产品说明，不自行扩展。
- 具体站点、类目与广告入口的细则会变，交付时按 [版位适配](amazon-placements.md) 复核，不把本页当合规结论。

## 六、自检三问

1. 这个卖点在画面里**看得到**吗？看不到就换。
2. 换成竞品也能说吗？能，就还不是差异化卖点。
3. 买家收到货会不会说我骗人？会，就删。
