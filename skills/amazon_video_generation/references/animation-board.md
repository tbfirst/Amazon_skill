# 分镜确定后的一次故事板生成

## 默认产物与触发

分镜已确认，或用户授权自行决定且关键事实/创意齐备后，默认调用**一次内置 image 工具**，生成一张包含三段全部镜头的真实故事板总览，保存并在对话展示。不是每镜一次调用，也不把拼接脚本当作生图功能。格数随已定镜头数，不能为九宫格增删剧情。用户明确只要文字/不生图时跳过；仅研究/修改技能不触发商品生图。

分镜表是文字；故事板是静态画面预演；animatic是按时间播放的实际视频，只在请求时制作。一次调用无法装下可读的全部镜头时先简化不必要镜头；确需多页则说明额外调用需求与范围，不能静默漏掉镜头或声称一次返回了独立全尺寸关键帧。

## 实际调用

1. 按 `imagegen` 技能使用内置工具。先查看本地产品图；实际传入所有必要图，不把文件名写在提示词里当已附图。原始SKU、局部、场景参考分别说明角色。
2. 准备共同身份/场景锁和逐镜静止状态：S-ID、C-ID、构图/角度、商品姿态、支撑、手/道具位置、光影与承接。每格只显示一个瞬间，动作先后写在镜头卡。
3. 一次请求生成**一张完整故事板图**，按C01→C02→C03顺序排列，镜号/时间放在画面外的留边或由网页在图外显示。每个面板保留商品完整性和目标视频画幅。要求固定商品特征、数量和场景，区分允许的相机取景变化。
4. 保存实际输出到项目 `storyboard/storyboard-v1.png`，保存生成词、输入角色和分镜版本。工具默认目录中的图要复制入项目。检查真实排格/顺序、颜色、部件、盆体、支撑、光向和跨段状态，再展示。
5. 在 `video-plan.json` 写实际图片与按目视确认的面板范围，生成本地编辑页。工具未生成/源图缺失时只交文字与缺口，不创建冒充实图的色块、SVG商品或空框动画板。

总览是一个栅格图像，不是可分层设计源文件；编辑方式见 [故事板编辑](storyboard-editing.md)。首次一次调用不是后续修改的次数限制。用户要求修改后可追加定向编辑；普通重试不循环追求完美，失败/持续漂移说明具体问题与已完成部分。

## 画面修改与版本

用户可在对话指定S-ID或在网页导出修改单。Codex先核原分镜版本及事实，改相应镜头/接缝，实际附上旧故事板与商品参考，以内置工具定向编辑；另存v2并目视复核未要求改变的面板。整板局部编辑仍可能影响其他面板，不能未经检查说全部保持。

仅改说明文字不会改变图像；在编辑页/交付状态中标画面待更新。删镜、换场、调序或时长变化可能影响段内15秒合计、邻接接缝与后段参考，须同步修订，保持稳定S-ID。旧图保留对应旧版本，不仅换标签。

## 干净关键帧是额外输入资产

故事板总览默认只审阅，不上传为首帧。若模式需要高质量首/尾帧或用户要完整逐镜干净帧，再按实际需求调用image生成/编辑；本阶段不能承诺只调用一次即可得到全部独立关键帧。

可从真实边界提取面板作审阅缩略图，但不能按理想等分自动切出串格/标题；低分辨率宫格局部不能假称高保真输入。需要产品图编辑时用内置image工具；程序只做文件整理、无损排版和审阅裁区，不补造商品像素。

已有干净帧仍可用 `scripts/assemble_storyboard.py` 与 `--manifest` 排版（Python3+Pillow），按S-ID/state/file对应。脚本检查时序/路径并等比留边，不生成场景，也不验证商品真实性。输入与可选caption字段见 [交付格式](deliverables.md)。

## 验收边界

逐镜状态 `not-rendered / rendered-reviewed / needs-revision / stale`；图像成功返回不等于已通过。真实生成画面不能成为商品事实来源。静态预览不能证明动态中间帧无变形；视频生成与验收分开记录。不可用工具时保留文字成果并明确故事板未完成，不静默切换付费API。
