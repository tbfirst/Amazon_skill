# 从最终图片开始

花卉优先提供已精修选定的11张套图，或手头已有产品图；有同SKU事实自动承接，不要求重新做整套资料。图片策略提示词本身不等于已经生图。

默认25–30秒综合展示：相机环绕→空间尺寸→1–2个动态细节→多次插花/整理→2–3个动态场景→成品收尾。按3–4轮弹窗收敛，已答跳过。详见[花卉整片工作流](flower-showcase-workflow.md)与必读的[动态导演规则](dynamic-flower-direction.md)：主体不自转，背景有真实视差，逐次插花默认3次，可从已有花材开始；也可手中整理后成束一次插入，场景不能静图放大轮播。

开场可按商品配色从[展示台背景库](display-background-library.md)选室内或室外环境，把用户商品放入主位后相机环绕，再接尺寸、细节、插花与其他场景。

交完整中文即梦词、分析说明书、给即梦的真实画面分镜板PNG、给人看的详细分镜表PNG/MD/CSV与精选上传图。缺少动作画面可用内置图像工具补成。当前用户Mini全能参考单次15秒，超过则交前后两段自足词与衔接；换2.5时按实际入口核实整片能力。不自动提交视频。

草木保留[草木路线](foliage-video-workflow.md)；旧项目按已约定内容继续。
