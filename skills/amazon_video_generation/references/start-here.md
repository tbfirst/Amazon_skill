# 从产品素材开始

先读[通用商品流程](product-video-workflow.md)，承接已有SKU事实与选定图片；套图计划不等于成图存在，也不要求凑齐11张才开始。按实际商品进入general、[花卉](flower-showcase-workflow.md)或[草木](foliage-video-workflow.md)路线，具体偏好与缺口通过弹窗确定。

按[整段交接](full-film-prompt.md)选择一个或必要的两个生成任务；按[精简交付](flower-storyboard-package.md)输出C01/C02内的提示词和全部上传图，以及根目录三个规定文件。表板同时交即梦参考，按[同源数据](jimeng-board-schema.md)保持镜号与状态对应。补图使用已查看本SKU参考，不自动提交视频。
