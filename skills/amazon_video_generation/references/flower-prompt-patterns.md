# 花卉提示词：把导演方案编译为可见画面

导演表负责时间预算、景别切换和后期硬切；生成正文负责此刻可见的主体、场景、起态、连续运动和落位终态。默认一镜一生成，不在正文堆入“0–4秒”“第5秒硬切”。只有核实入口支持原生多镜且项目选择该模式，才按其实际方式写多镜词；不把所有模型描述成不会切镜或不解析时间。

## 每个C-ID的正文

依次写：实际附件角色与必要身份锚点 → 本镜布景/人物/固定光源 → 可见起态 → 一个主运镜与有顺序的动作簇 → 结束状态。身份锚点用已核花型、颜色、枝叶结构、比例和轮廓密度；SKU准确数量在事实表核对，不用“23变24、六色各4”要求模型逐枝计数。密度也须忠于实物，不能增加花量。花器是否随货写brief和后期呈现说明，不把“不随货”当生成指令。

每个附件明确主职责（外观、细节、环境或接续锚点），避免一张图同时锁定商品、花器、环境及机位。已弃用素材不得自动重新启用。带字图有文字残留风险，不能断言必然污染；优先无字原图或可辨干净区域，需要清理时列依赖，不假称一句“无文字”已完成清理。

正向写可见支撑与空间关系，如“瓶底始终贴住台面”。不要塞满验收清单。位移推进写明摄影机实际向前移动、焦距保持不变；变焦另列，不能两者混用。环绕角度按参考覆盖与所选方案，60–90°是F01默认目标，25–30°或横移是资料/失败迭代下的具体选项，不是全局禁令。

## 连续插花示例（虚构教学SKU，不直接搬作事实）

前提：奶白仿真玫瑰外观、可见花器口、散枝插入方式和操作初态已确认。片长在设置及导演表填写，此处为一个连续操作镜正文：

> 参考图1锁定奶白仿真玫瑰的花型、绿色茎叶与真实疏密，参考图2锁定浅灰陶瓷花瓶的可见瓶口，参考图3提供浅木台面、米灰墙面与操作初态。柔光来自房间左侧固定窗户。人物只见米色衣袖、双手与局部上身。固定侧前中近景，瓶内已有初步花型，同SKU待插枝铺在右侧操作区。右手以流畅利落的节奏接续取枝，从可见瓶口放入，花枝落稳后松手再取下一枝；左手轻扶瓶身，并在插入间隙扶正外侧花枝。花冠逐渐形成参考中的高低与疏密。结尾刚插入的花枝稳定落位，双手自然停稳，花瓶底部始终贴住台面。花型与颜色保持参考身份，画面无生成文字或水印。

这不是从空器完成整盆的承诺，也不限定只能插一枝。合理速度服务动作可读性，不写无法核实的精确循环次数或高速瞬移。

## 细节与适量触摸示例

> 参考图1锁定本SKU花瓣边缘与原有叶片形态，参考图2提供同场景操作区。固定侧前近景，花冠外缘与手指完整可见。手指轻掠外侧花瓣后离开，随后轻托原有外侧枝叶，将其轻轻疏开至已确认的自然展开状态。花头保持原有结构，手退出后枝叶稳定停留，柔光方向与背景保持一致。

按材质选择一个适宜动作，不必把两项塞进每条词。干花易碎、固定成品不可调或缺少弯折依据时，不编受力和变形。触摸仅表现互动，不证明柔软、耐用；舒展不等于自动开花、拉长或新增枝叶。需要真正插入演示时保留核心接触，不能默认靠切镜跳过却称演示完成。

## 迭代

先查参考/初态矛盾，再减少同时变化的变量；固定操作机位、缩短手部路径、分动作簇、在稳定落位后分任务。减少插入数量是具体失败后的备选，不恢复“只插一次”的默认。检查中间帧的花材去向、手茎接触、容器支撑、花色与轮廓。未生成只称方案，末帧锚点未产出列pending依赖。多场景F07也默认一镜一任务，详见综合编排；剪辑点放表里。
