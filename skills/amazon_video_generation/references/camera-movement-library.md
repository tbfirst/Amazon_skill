# 商品运镜库：单运动、组合与选镜

> v5.1花卉优先遵守[动态导演规则](dynamic-flower-direction.md)：相机环绕、花器和花卉整体不自转，近远背景随机位产生真实视差。尺寸段也遵守；M19不适用于当前花卉路线。固定相机可拍画内动作，不能把本页旧C01–C04时间预算或静态降级方案套回新花卉整片。

> 适用范围：花卉按[结构库](flower-video-formats.md)选择F01–F07，只有F01默认前5秒环绕＋人物插花；草木按项目选镜。新项目通常约30秒内；本页旧时长仅历史例子，摄影手法是可选工具，不限制首尾运动、人物或留白。

用于已锁定商品事实和四段任务后的选镜。术语依据与访问边界见 [研究记录](research/2026-10-29-camera-movements.md)；下列幅度、时长和植物适配是本技能导演建议，不是两条用户视频的逐镜复刻、平台标准或模型执行保证。逐条可抄的执行卡、提示词句式和失败验收见 [运镜执行卡](camera-shot-cards.md)；机位怎么摆、角度怎样覆盖见 [机位覆盖与多角度](multi-angle-coverage.md)。

## 先选信息，再选运动

每次选镜先写一句“这一镜新增了什么”：体积、枝叶层次、纵向结构、局部做工、实际占地或生活用途。连问三句再决定：

1. 这一镜要让买家多知道什么？
2. 不用运动能否看清？能看清就用 M00，镜头不动不等于片子死。
3. 运动停在哪里观众才看得清？终点写不出可辨结构，这条运动就该缩短或换掉。

- 首镜：花卉F01前5秒环绕完整主体；草木按辨识任务选择运动，不预设缓推。
- C02：主要使用本库；在2–3镜内选有信息差异的路径，通常只安排一个环绕或一个揭示镜头，另配清楚的全貌/尺度镜头。不强制每片都用新花样。
- C03：围绕1–2项有依据卖点选择近景、纵移、微幅横移或固定观察；不用持续遮挡和虚焦藏细节。
- 收尾：按项目选择运动、人物与构图；固定镜头和留白仅为可选拍法。

一个镜头一个主要运动，允许为保持构图做轻微摇/俯仰/跟焦补偿，它们不算额外动作。只有单一运动无法完成明确任务时，才用两种已写明的兼容运动（见“组合语法”）。不同时叠加环绕、升降、推近、变焦、转焦和人物整理。实拍能完成的复杂轨迹，不等于即梦已支持可控复现。

## 单运动词典

优先级针对本技能的商品保真与阅读任务，不代表通用艺术评价。“建议时长”包含进入、展示和停稳。

| ID / 手法 | 相机实际做什么 | 商品用途 / 段位 | 边界与证据要求 | 降级 |
| --- | --- | --- | --- | --- |
| M00 固定 / locked-off | 位置、朝向、焦距全程不动，只有画面内元素可动 | 做工证据、动作接触或完成态观察 | 分别写固定部分与可动部分；固定相机仍可拍微风/接触响应 | 保留固定，不为丰富而移动 |
| M01 慢推 / push-in | 沿光轴靠近目标，焦距不变，缓入缓停 | C01 后7秒；C03 靠近已知结构 | 终点仍留必要连接/轮廓；近距纹理需真实参考 | 缩短行程或放宽景别，不把数码放大称推镜 |
| M02 慢拉 / pull-back | 沿光轴后退，逐步纳入环境 | C02 从商品到摆放空间/体量 | 终点完整冠顶、底座、支撑可见；背景道具要有用途 | 可切完整中景；按项目核对首镜选择 |
| M03 横移 / truck | 相机与商品保持距离平行直线平移，背景产生视差 | C02 读枝叶层次；C03 读已知盆壁 | 只在已有角度范围；桌面纹理与接触点关系稳定 | 缩小位移或改固定观察 |
| M04 短弧环绕 / arc | 以商品为圆心走短弧，镜头持续对准主体，不绕满一圈 | C02 读花冠、盆体立体轮廓（产品适合小环绕） | 弧线经过的侧面都要同SKU参考；起稿约15–30°/4–6s | 花卉先列角度缺口并补有依据的参考；不擅自改成静图放大，不编背面 |
| M05 升降 / pedestal | 相机整体竖直上下移动，朝向基本不变 | C02/C03 读盆口到花冠、树干到枝冠 | 避免穿叶；高树扫描后另给完整全貌，不用扫描代替尺度 | 分切两个已知部位或固定中景 |
| M06 俯仰 / tilt | 相机位置不动，只改镜头上下朝向 | 高树、垂藤、长茎的纵向浏览 | 起终部位明确；角度不能凭空看见未知盆内 | 改 M05 或两个固定角度 |
| M07 水平摇 / pan | 相机位置不动，向左右转向 | 宽花环、花束或已确认组合的横向关系 | 只适合全程可识别的主角；不是横移，不承诺平移视差 | 全貌固定或小幅横移 |
| M08 遮挡上升 / rising reveal | 从低位升高，让固定前景边缘退出画面，商品逐渐显露 | C02 引入空间与完整主角 | 场景卡写明前景、商品、背景距离；优先已有非售卖道具 | 直接升降或硬切全貌 |
| M09 前景掠过 / lateral reveal | 横移时让固定失焦前景边缘掠出画面 | C02 形成克制空间层次 | 前景只遮边缘，不掩关键卖点，不穿透实体 | 改 M03 无前景横移 |
| M10 转焦 / rack focus | 相机可固定，焦点从一处移到另一处 | C03 同SKU前排花瓣到后排结构（辅助） | 两处均有依据，转焦后留足清楚停留 | 主卖点固定对焦 |
| M11 跟随 / tracking | 相机跟随正在移动的主体或手部事件 | 仅 C02 有真实摆放/搬动事件时 | 已确认可移动、接触、支撑；静止植物不能自己滑动配合 | 固定机位拍完整摆放动作 |
| M12 甩镜 / whip pan | 极快横甩，过程带运动模糊，用于衔接 | 仅社交版转场（9:16 社媒剪辑），不进商品主片 | 约0.5s，必须落在可辨画面；列表视频易被读成粗糙 | 硬切 |
| M13 滚转 / roll、荷兰角 | 机身沿光轴转，地平线倾斜 | 一般不用 | 破坏重力感与尺度判断，静止商品会像倾倒 | 取消，用 M06 表达纵向 |
| M14 变焦 / zoom | 焦距变化，机位不动 | 条件使用：设备确实有光学长焦且必须固定机位 | 透视不变、背景不压缩；数码裁切会降画质 | 物理移动 M01/M02 |
| M15 推拉变焦 / dolly zoom | 机位推进同时反向变焦，主体大小不变、背景拉伸 | 仅风格化版本 | 需要滑轨/稳定器与配合变焦；普通推近不等于眩焦 | 常规 M01 |
| M16 手持 / handheld | 无稳定器，保留呼吸和步伐的轻微不规则晃动 | 仅 C02 生活情境插镜，且品牌调性允许 | 幅度要小、方向有目的；亚马逊列表里“抖”常被读成不专业 | 固定机位或三脚架+轻推 |
| M17 贴面掠移 / low-angle glide | 镜头贴近台面（约10–20cm）平行滑过 | C02 读台面接触、盆底与占地感 | 贴面高度会让商品显大，需保留真实尺度参照 | 常规 M03 |
| M18 完整环绕 / 360 orbit | 绕商品一整圈 | 仅在四向参考齐备且需展示全周时 | 10s 内绕满一圈会压缩细节；未知背面必然编造 | 拆成 2–3 个已知角度硬切 |
| M19 主体自转 / turntable | 商品在转台上转，相机不动 | 仅其他明确选用转台的实拍项目；当前花卉不选 | AI 生成易把“转台”画成瓶子变形/盆底滑动；静止商品默认不自转 | 改 M04 相机绕行 |

## 组合语法

组合的价值是“一次行程完成两件事”，不是把会的动作都塞进去。规则：

- 一个主路径 + 最多一个同向辅助（补偿或收尾），单镜不超过 2 个运动。
- 两个运动必须方向相容、能连续解释；反向互冲（边推边拉、边升边降）只在下面 K01 有明确停顿设计时成立。
- 只在 10 秒段内信息确实装不下时才组合；能用两个 5 秒镜表达，就切镜。
- C01 的“0–3s 停留 + 3–10s 推近”是同一镜的阶段，不算组合，不要记成 K 类。
- 组合里出现环绕时，商品仍不得自转；出现升降时，机位高度变化不得造成商品“变高”。

| ID / 组合 | 何时用 | 路径与10秒内时间分配（起稿） | 风险 | 降级 |
| --- | --- | --- | --- | --- |
| K01 推→停→拉 | 先聚焦细节再交代摆放效果；一段内完成“看清—看见” | 0–4s 推近到可辨局部，4–5s 停稳，5–9s 后拉到完整中景，9–10s 停稳 | 行程过长导致两头都不清楚；速度突变 | 拆成两镜：局部近景 + 完整中景 |
| K02 环绕+推进（螺旋） | 产品亮相：既有立体感又收拢到细节 | 0–1s 起幅，1–8s 短弧15–30°同时缓慢推近，8–10s 停稳 | 双重运动易让商品漂移/变形 | 只保留短弧，或只保留推近 |
| K03 横移+微升 | 桌面组合或高低错落套装，读层次与占地 | 0–1s 起幅，1–8s 横向平移并轻微上升，8–10s 停稳 | 上升过快会像无人机俯冲 | 纯横移 M03 |
| K04 推进+前景遮挡 | 换场/引入新主角的转场；也可做 C02 开场 | 0–2s 越过固定前景，2–3s 前景出画，3–8s 继续推近，8–10s 停稳 | 遮住卖点、穿模、把道具读成随货 | 硬切 + 固定全貌 |
| K05 环绕+缓慢后拉 | 段落收尾的氛围镜（不是 C04） | 0–1s 起幅，1–8s 短弧同时后拉纳入环境，8–10s 停稳 | 后拉露出未确认道具/空间 | 只后拉 M02 |
| K06 升降+俯仰补偿 | 高株/垂藤纵向浏览，需要保持盆口或冠顶入画 | 0–1s 起幅，1–8s 上升约一个结构段，8–10s 停稳 | 补偿写成第二个主运动，实为两个动作 | 纯升降 M05 或分两个固定角度 |

## 速度、起落幅与时长

- **慢运动是默认**：推/拉一个完整行程 5–8 秒；中速 3–5 秒；10 秒镜通常只走一个行程，不走两个来回。
- **起落幅各留 1–2 秒**稳定画面（C01 的 0–3s 停留就是起幅，C04 全程就是落幅），方便剪辑和后期叠字。
- **全程匀速**，不忽快忽慢；提示词写可感知速度（缓慢、平稳、匀速）；具体秒点放导演表，只写“推镜头”会留下速度歧义。
- 摇镜约 60–90°/分钟；环绕起稿 15–30°/4–6s；甩镜约 0.5s。
- 实拍按 180° 快门法则（24fps→1/48，25fps→1/50，30fps→1/60）得到自然运动模糊；这条只写进实拍执行卡，不写进 AI 提示词。
- 竖屏版本（9:16）减少大幅旋转和极速摇镜，眩晕感在手机全屏时被放大。

## 提示词三段式与句库

生成正文按四段写全，缺一段模型就会自己补：**运动+速度 → 起点与终点 → 主体固定状态 → 必要补偿**。镜头ID只进内部表，交付词必须展开成自然中文，用可辨结构当终点锚点，不虚构焦距/厘米/设备。

| 运动 | 可直接改写的句式 |
| --- | --- |
| M00 | 相机全程完全静止，位置、高度、朝向和取景不变；只有叶面在环境光下极轻微自然晃动，商品与台面接触处不动。 |
| M01 | 相机从完整中景沿光轴缓慢推近，约6秒匀速到达盆口与花冠的局部近景，最后1秒停稳；焦点始终在商品主体，终点仍保留花冠与盆口的连接关系。 |
| M02 | 从可辨的植株近景开始，相机沿光轴缓慢后移，约6秒纳入完整容器、桌面和一侧家具参照，停在完整商品中景；只扩大取景，植物尺寸与支撑位置不变。 |
| M03 | 相机与商品保持固定距离，从画面左侧沿水平直线平稳横移到右侧，约6秒匀速走完；商品、桌面纹理和盆底接触点保持不动，背景产生自然视差，最后停稳。 |
| M04 | 相机从正面中景出发，沿向右的短弧缓慢移到参考图覆盖的右侧前方，约5秒、角度约20度，镜头持续对准盆体与花冠中心；拍摄距离大致稳定，花器落点与朝向在场景中固定，商品不自转；近处桌沿与远处窗框产生不同幅度的视差，背景遮挡关系随视点改变，最后停稳。 |
| M05 | 相机正对已知枝干局部，平稳竖直上移至花冠下缘，约6秒匀速，保持同一正面角度和可读焦点；枝干分叉连续可辨，最后停稳，不抬升植株、不穿叶。 |
| M06 | 相机位置不动，镜头由盆口缓慢向上转至花冠，约6秒匀速，最后停在完整冠顶；底座与冠顶的上下关系连续可读。 |
| M08 | 低矮书脊位于近处画面下缘，失焦且只挡少量盆底，商品上部从首帧即可识别；相机平稳竖直上升约4秒，书脊逐渐退出下缘，完整容器与桌面接触处显露，最后1秒停稳。 |
| M10 | 相机固定，焦点从前排花瓣缓慢移到后排已确认结构，约2秒完成，之后留足3秒清楚停留；两处都在同一株上。 |
| M16 | 相机轻微手持，随呼吸产生极小幅度、方向一致的浮动，始终对准商品；商品与桌面不动，画面不出现乱晃或突然变向。 |

## “两倍环绕”怎样处理

“两倍”不是明确的相机路径。完整判定、三种解释与三套改写见 [执行卡 SC-06](camera-shot-cards.md#sc-06-两倍环绕)。要点先记在这里：

- 未澄清前**不猜**，也不把 720°、倍速环绕当默认；正式提示词用已确定的小弧线方案，并标为本次适配建议，不称已复刻原教程。
- 若指 2× 取景：开拍前锁定设备 2× 档位，后退到所需构图再走短弧，拍摄中不切镜头不变焦；2× 是设备相对标记，不等于某个焦距，也不自动“压缩背景”。
- 若指两倍速或绕两圈：会压缩细节阅读时间并扩大未知角度，优先改成正常慢速短弧；用户坚持时另定时长与验收。

## 遮挡上升与“前景”边界

完整执行卡见 [SC-07](camera-shot-cards.md#sc-07-遮挡上升)。三条硬约束：前景与商品都固定，移动的只有相机；相机不穿桌面/书本/枝叶；遮挡不得掩盖换款、数量增加、盆底滑移或改变场景。整屏遮黑不能当默认转场。

前景是“已有且非售卖”的道具时优先（书脊、桌沿、门框、空画框边）；如果这个道具会让买家以为随货，就换低干扰物体或取消前景。

## 较强效果的取舍

快速甩镜、滚转、荷兰倾斜、手持随机晃动、速度坡变、穿叶穿孔、大范围360°环绕、希区柯克式推拉变焦不作为展示片默认。它们可能改变重力/尺度感、遮蔽卖点或需要更多隐藏结构资料。用户明确要风格化版本时评估可行性与验收方式，而不是永久禁用；但要在分镜里标为风格化选择，并写清失败时退回哪个安全镜头。

普通推近/拉远不等于 dolly zoom：后者是机位位移与反向变焦的组合，不能混写。手持也不等于“随便抖”：有目的的轻微浮动是 M16，无目的的乱晃是废镜。

## 失败与降级阶梯

生成后按开始、运动中、结束及关键遮挡点查看连续画面：商品是否被当转台旋转；盆底/挂点是否滑移；花叶/分叉是否增减；前景是否穿模；角度是否超出参考；焦点是否让卖点读不清；终点能否接下一镜。首尾正常不代表中间正常。

发现问题按这个顺序退，不要一次跳到底，也不要靠堆负面词硬压：

1. 收窄行程：缩短弧度/位移/推近距离，保留同一运动。
2. 取消辅助：去掉前景、转焦、补偿，只留主运动。
3. 换安全镜头：改为已知角度的固定镜或两个固定角度硬切。
4. 重写并重生成一次，改动同步分镜、提示词和接缝；仍失败就如实说明并列出补图需求。
