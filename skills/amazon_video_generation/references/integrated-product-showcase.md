# F07 植株花卉通用展示模板：信息、景别、动作与场景

当用户希望像广告样片一样兼有卖点、人物和多个用途，使用此编排；不要要求从F02细节/F03摆位/F05操作/F06场合中只能选一个。花卉记录`flower_format: F07`；草木记录`narrative_format: integrated`并继续用foliage检查。来源为[已采样的B站案例](research/2026-10-29-bv1ag-product-showcase.md)，以下为原创适配，不是原片提示词或精确分镜。

## 模板复用边界与填充入口

**复用的是镜头承担的信息任务，不是参考商品的功能、演员、场景或动作。** B站玩具片只提供叙事与视听组织参考；儿童使用、折叠、机洗、泡棉、旅行等内容不进入植株花卉模板。执行时只需要本SKU资料与本模板，无需重新照着玩具片逐镜改名。

先填六项：①售卖主体与固定身份（花/叶形、颜色、数量、比例、容器属性）；②1–3个有依据的核心信息；③可见细节；④允许的人物动作或无人展示；⑤主场景与辅助场景分别增加什么信息；⑥总长与现有角度覆盖。未知项列缺口，不从参考片补事实。鲜花、干花、仿真花、盆栽和树的动作分别核对。

依次完成：**产品资料→买家问题→视觉表达→景别与机位→主要运镜→场景和时间→中文生成词**。不能先挑炫酷运动再为它编卖点。

## 先定主张，再组合镜头

一句核心主张贯穿全片，例如“让日常桌面成为有花的空间”。选支持它的2–3个已核信息点：外观层次、真实比例、放置/整理方式、不同使用位置等。卖点按重要性与证据筛选，不按成品套图顺序逐张变视频。

推荐叙事：**使用效果开场 → 关键细节 → 人物演示 → 用途扩展 → 使用效果收尾**。顺序可按商品调整；用途画面和卖点画面要互相解释。人物不只微笑望镜头，每次出现负责放置、整理、搬放或参与使用情境之一；复杂动作分镜时保留关键接触及落位结果。

每个卖点建立短链：`买家问题 | 已核事实/来源 | 可见画面 | 人物动作 | 使用结果 | 可选后期短句 | S-ID`。例如“放桌上会遮挡交流吗”需要已核花高与真实场景比例，拍餐桌侧面空间关系；不能用假人物比例或压低花束作答案。若主张需要检测，视觉只做解释，不做证明。

## 可执行的预算

用户没给时长仍可出15秒精简版；综合内容较多时推荐24–30秒并解释取舍，不能静默把默认改成30秒。参考片约38秒不改变技能约30秒常用预算。

- 15秒：入口容纳时用一个C01，内含用途全貌、关键细节/操作与结果或第二用途；具体镜长按可读性分配，只取1–2个主信息点，不称完整插花或安装。
- 30秒示例见下表：若单次上限15秒，按稳定切点分C01/C02；入口容纳整片时优先一个任务。每段可含多镜/多场景，信息模块不是C-ID。

|模块 / 30秒示例|镜头信息任务|景别与主要运镜候选|植株花卉的可替换内容|
|---|---|---|---|
|A 用途建立 / 0–3s|马上识别商品及空间价值|环境全景/远景，M01缓推或M00固定；商品仍能辨识|花束在台面、盆栽在边柜、树在室内角落；按实际场景选|
|B 主体识别 / 3–6s|看清完整轮廓、层次与体量|完整中景，M04短弧或M03横移；角度不足则M00|花冠与花器、叶冠与盆体、树冠与底部；完整取景不等于必须正面|
|C 细节支持 / 6–10s|用真实局部支持一个卖点|近景/特写，M00固定或M03微幅横移，焦点落于有依据部位|花瓣层次、叶片纹理、枝茎连接、实际盆器表面；不凭空生成微观纹理|
|D 人物互动 / 10–15s|说明动作、使用或尺度关系|中景交代手与主体，必要时硬切接触近景；接触时M00|放稳、整理已允许调整的枝叶、示范一枝；固定成品不强行插花。无人方案可替换为尺度关系镜|
|E 结果落位 / 15–20s|让观众看到动作完成后的效果|中景停留或M02缓拉至完整陈列|花束/植株落稳、人物松手，保持商品轮廓清楚；与D构成因果关系|
|F 场景扩展 / 20–25s|增加一种适用空间/构图关系|先用全景说明新位置，再按预算切中景；M00或M03|按本SKU选择第二用途场景，不固定客厅/餐桌/玄关，不增加无依据户外功能|
|G 主体收束 / 25–30s|回到最有说服力的完整效果|完整中景，M01缓推或M00；末端稳住|商品为画面中心，人物可在边缘；不强制白底、空白尾卡或无人|

模块是信息功能，不是必须七镜；C和D可交换，D可删/替换，多个卖点可重复C→D→E中的必要部分。15秒保留A/B识别、一个关键证据单元和结果/第二场景，不平均压缩七个模块。示例的3/4/5秒是镜头预算，按连续镜头组织为实际入口支持的C-ID，任务安排按[整段交接](full-film-prompt.md)。

### 远中近景与运镜如何搭配

|要让买家看清什么|优先景别|运动的具体用途|避免|
|商品与环境的关系|环境全景/远景|缓推把注意力带向商品；缓拉揭示已存在的空间关系|商品太小、长时间空房、只拍装饰|
|完整外观与比例|完整中景|短弧显示有依据的侧面层次；横移用视差区分前后枝叶|相机绕与商品自转混淆；裁掉花冠/盆底|
|真实细节|近景/特写|固定给观看时间；短横移显示有依据的纹理与重叠|为追求“质感”虚构材质、过浅景深看不清细节|
|手与花茎/花器接触|动作中景→必要接触近景|固定或先移后停，保持操作区域可读|接触瞬间环绕、焦点漂走、手遮住落位|
|完成效果|中景→环境全景，或完整中景停留|缓拉交代布置结果，或缓推收束商品|与开场完全重复却不增加结果信息|

景别是取景范围，运镜是相机运动，两者独立选择；远景也可固定，近景也可横移。不是每镜都动，也不把全片都写成固定镜头作为通用默认。按镜头任务选择固定观察或一项主运动；有运动时写起幅→方向/路径→速度→落幅；候选到执行词阶段必须选定，不留下“推或拉”。幅度依据商品参考覆盖决定，不强制60–90°或360°。

### 镜头连接与节奏

用“全貌定位→局部解释→动作→结果→新空间”建立阅读关系，避免连续几个相似中景。近景必须能让观众知道它属于哪个主体；从近景切回全貌时保持身份与合理方位。操作按接触前、接触、落稳保留可读状态，在落稳后切镜更容易衔接。复杂动作分配更长时间，纹理/全貌给予看清时间；不以固定每两秒切镜或增加运动种类充当质量标准。

视觉统一靠产品色彩、光线风格、构图重心与适度的运动速度；无需所有场景同一房间或同一光源方位。运镜参数是设计目标，原片采样没有证实的轨迹不冒称已观察。

## 多场景连续性与变化

整片允许多场景，默认建议2–3个互补用途，数量由信息和时间决定，不设全技能硬上限。同一C-ID可用明确切镜进入新场景；连续镜头内保持空间关系，不用融变代替换场。入口能力不足时明确调整内容/设置的取舍，不自动按场景增加任务。

固定项：同SKU花种、颜色、枝数、尺寸比例；若容器是随货件，其身份固定。变化项：背景、台面、人物、服装和布景；光源在每个场景内部固定，场景间可有合理不同光线，但花色不能随之换色。演示道具可换但要说明，不能把不同花器暗示成多件随货。

每场明确“同一人物继续行动”还是“独立用途示例”。前者需要人物/服装与动作状态衔接；后者可换人物，不能写成同一人瞬间换装或连续移动穿越空间。跨场切镜不必生成拎花穿门等过渡动作，也不要求未来末帧作下一场首帧。

新场景必须增加一个用途或尺度信息。客厅、餐桌、玄关可以各有构图任务；若只是墙面颜色改变且没有新信息，删掉重复场景。户外画面不等于耐晒/防水证据。尺寸文字、材质声明、维护演示各自要证据，不能从参考视频搬到花卉SKU。

## 提示词编译与可选文案

每个C-ID正文自足：商品身份与实际附件角色 → 本场SC-ID具体布景/人物 → 起始状态 → 连续动作 → 结束状态。不要一条词笼统写“多场景、人物互动、突出卖点”。换镜明确景别、可见部位和信息；切点写导演表；多镜和画幅按实际入口核实。跨C-ID说明“独立使用示例硬切”，避免背景融化转场。

沿用用户已选文案与声音；在CSV记录准确短句、依据、时间窗、位置与语言，正文只写选定成片文字。需要后期修字/叠字时把处理计划写入说明书，不另交字幕文件，不声称尚未执行的修正已经完成。字幕应点明已展示信息，不能靠字幕遮住接触或用文字替代动作。静音观看仍应能理解主要用途。

## 验收

逐镜检查是否增加信息；卖点是否有依据及对应可见画面；人物动作是否必要、完整可读；场景改变是否增加用途；产品是否成为背景；不同场景商品身份是否一致；同人物是否跳装；字幕是否跟随对应画面；总时长和各C-ID是否合理。15秒塞不下时删次要卖点或提议延至约30秒，不加速所有动作假装演完。

结构检查：花卉`--profile flowers --flower-format F07 --strict`；草木`--profile foliage --strict`。脚本不验证多场景语义、人物一致性或卖点真实性，这些仍需逐项复核。

## 可复用提示词骨架（设计模板，不是最终执行词）

每个C-ID填一次；具体模块与切点来自已选分镜，不能只替换商品名称而保留不适用动作。方括号填完、有参考依据且入口能力核对后，才能交TXT；缺项保持draft。

> 实际附件[编号/单一主角色]锁定[本SKU外观身份与比例]。本场为[场所、台面、背景、固定光源]，人物[范围、服装、任务]。起始状态为[可见布局与接触]。摄影机以[单一主路径/固定机位]保持[景别与可见部位]；主体依次[连续动作和支撑关系]，结束于[落稳状态和构图]。画面无生成文字或水印。

跨场的下一C-ID独立重复身份和新布景，注明“独立用途示例硬切”，不写空间融化；同人物连续行动需重述人物与服装。只需要两镜就删掉多余占位，不为模板凑镜。

**花卉填写例**：信息“花瓣有层叠与渐变”→实物细节图→侧前近景→固定观察可辨层次；信息“摆在餐桌的完整比例”→已核尺寸/场景→餐桌中景→短横移保持花束完整。**植株填写例**：信息“叶冠层次”→全貌与侧面图→中景短弧；信息“角落摆放效果”→已核高度/空间参考→全景缓推到完整植株。两者使用同一镜头语法，具体花材、动作和环境由SKU决定。

模板提升规划的完整性与一致性，不保证单靠提示词得到高质量成片。生成后仍检查运动、中间帧、接触、产品身份、焦点与切点。
