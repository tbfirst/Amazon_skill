# 花卉视频结构库 F01–F07

所有当前花卉结构均遵守[动态导演规则](dynamic-flower-direction.md)：环绕与尺寸是相机空间绕行、主体不自转；细节有自然响应；选逐次插花默认3次落位松手、容器可已有花材；也可完整展示手中整理成束后1次插入；场景有真实过程。以下旧精简预算若不能容纳动作，减少模块或加长，不把3次模式缩成单枝插一下，不使用静图缩放轮播。

先选买家需要看清的问题，再选拍法。v5默认F07综合展示（见[整片工作流](flower-showcase-workflow.md)）；已指定无人、细节、固定成品、数量或用途时直接匹配相应结构，记录选择依据，无须再问一次许可。信息不足可推荐两套不同重点的草案。两套方案不应只换台面颜色。新项目默认16:9，默认25–30秒，15秒为精简方案，按信息量选择15–30秒；下列时间均为本技能设计示例，不是参考片时间码或平台档位。

## 脚本从信息到动作

每镜写六项：**买家问题 → 本SKU依据 → 画面答案 → 主体动作/相机路径 → 起止状态 → 切镜关系**。例如F02买家问“花头层次如何”，以真实细节图为依据，用固定侧前近景展示花瓣层次；不用夸张开花变形回答。F03回答“摆起来占多大空间”，用已核花高与桌面比例、一次可读放置动作回答，不用人物手掌估计精确尺寸。

v5默认简短英文卖点＋准确尺寸标注＋轻音乐、无旁白；文字先在视频生成，出错再后期修正。每镜只回答一个主要问题，不能堆“高级、逼真、百搭”而没有可见画面。质感展示不等于测试；包装、性能和尺寸均需已核事实。
