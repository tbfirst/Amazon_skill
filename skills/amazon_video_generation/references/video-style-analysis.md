# 竞品相关视频识别与风格分析

用于用户给ASIN、参考片或要求竞品视频研究的任务。成果是**相关视频清单、基于实际画面的风格比较、适合我方的风格选择及镜头/总词落地**。商品图集、A+版式与评论不作为默认采集/分析任务；已有静态图研究也不等于视频研究已完成。我方商品照片仍是商品身份和真实操作的输入。

## 1. 先识别视频，而不是盘点图集

用户已给本地参考片时，先读取该文件、核对可解码性/时长/画幅，再建立V-ID与实际查看记录；不把搜索ASIN或外网补研究当先决条件。非目标商品的拍摄样片归为同类风格参考。没有持续挂载原片的环境可用便携的观察记录和代表缩略图复用方法；需确认新动作/切点时仍回源核实。内置两条本地样片见 [学习记录](research/2026-10-28-local-shooting.md)。

从目标ASIN的视频入口、品牌/卖家发布视频、顾客使用视频或用户提供的参考链接寻找候选。先查看视频标题、作者类型、视频ID、来源链接/媒体地址、时长/画幅及关联ASIN等可取得信息，按视频实体去重；同片的不同码率或多页重复出现只算一条。

核对视频实际内容与当前商品的关系，保留以下区别：

- **对应商品/变体**：能确认是目标商品或所选颜色/尺寸；可研究其表达，但不自动承接性能。
- **同系列/跨变体**：品牌合集、多色款片或其他尺寸；只取适用的风格片段，注明具体显示了什么，不能当当前子体安装证明。
- **同类风格参考**：相似植物/装饰商品但非目标ASIN，只借镜头语言；不冒充该竞品视频。
- **无关或归属不明**：列排除原因或待核，不纳入已完成风格结论。

同一ASIN页面可能包含推荐内容、多产品片、顾客片或其他尺寸。页内出现不等于归属已核验；标题、品牌和缩略图只是初筛，尽量用实际视频画面交叉。静态主图/参数页只在解决身份疑问时少量查看，不顺带采集完整图集、A+或评论；用户另有明确研究要求时再扩范围。

## 2. 取得与查看实际视频

优先可直接播放的原视频或公开媒体，记录实际查看范围。取得视频文件可按场景变化查看并抽帧；节奏、转场或手部动作需要时，在对应区间加密观察，不机械地用几个封面判断整片。可用音轨再做听审，音轨存在、字幕存在和实际听过分别记录。

访问受限时尝试同一发布方的公开视频页、嵌入入口或官方其他渠道。没有拿到画面时只保留候选/访问状态；文字稿可说明口述内容，但不能填视频运镜/节奏风格。一个来源受限不阻止分析其他可看视频；只有已失败入口时不反复重试。访问层级详见 [平台研究](platform-research.md)。

不以批量下载主图/附图/A+来补“视频不可访问”，不凭标题、封面、元数据或AI臆测风格。采样间隔影响结论精度：抽样图可支持所见景别、顺序和构图；精确镜长、速度、切点、细微动作及声音要有对应连续画面/音轨依据。

## 3. 分析视频怎样表达

对可见视频写具体观察，未知项标未核，不用“高级、温馨、电影感”几个词代替分析。不要求每条视频都有操作、人物、字幕或声音。

| 维度 | 观察什么 |
| --- | --- |
| 片型与叙事 | 氛围展示、操作教程、顾客布置、品牌合集或混合；开头先给什么，事件怎样推进，信息顺序是什么 |
| 节奏与时间分配 | 整体快慢、操作/细节/场景各承担多少注意力、是否有停稳；镜长/切换密度按实际可核精度描述，不从抽样间隔反推原片切点 |
| 景别与构图 | 完整商品/中景/局部如何交替，前中后景、留白、瓶底/树座落点、产品与环境的视觉占比 |
| 相机与焦点 | 固定、推拉、横移、倾斜、环绕或焦点变化；区分相机移动与枝条/手部动作，不凭孤立帧判定运动轨迹或速度 |
| 主体演示 | 静态陈列、手部接触、真实操作的起止状态与完成态；外部步骤只作观察，不补我方未知结构 |
| 光影与配色 | 可见明暗层次、冷暖关系、枝叶/灯点如何与背景分离；不从画面推精确灯位、功率或商品照度 |
| 场景与道具 | 家居、节庆、婚礼等环境语言、材质层次、布景密度，以及道具是否抢主体 |
| 剪辑与转场 | 实际可见的硬切/叠化/动作衔接、换场和换色款的方式；抽样看不清的过渡标未核 |
| 字幕与声音 | 可见文字的角色、位置与出现方式；听审后再写音乐情绪/节奏、旁白、环境/接触声；未听音轨不判断有无音乐/口播 |
| 收尾 | 最后停留的是商品、空间还是品牌卡，如何形成完整结束；是否适合我方目标版位 |

视频样本存在差异时横向比较其风格与适用任务。推荐适合当前商品和既定时长/用途的一种主风格，说明采用哪些具体手法、放弃哪些不合适元素。风格差异不足时直接说明，不为凑固定几套方案编造差别；用户已有选择则沿用。

对于布景/氛围片，补看“为什么这幅画面成立”：主售商品是哪件；台面、前中后景、高低/疏密与留白怎样分配；每件道具传达什么用途；局部镜新增了什么可见信息；每次换场有没有新增情境。把可见光影结果与推测的灯具/布光方法分开，转写方法见 [商品摄影与场景导演](product-cinematography.md)。

## 4. 输出与落地

研究通常集中在一份 `video-research.md`，避免给用户增加一套难辨文件。至少包含：

1. **视频清单**：稳定V-ID、目标ASIN/商品关系、标题/作者类型、原页与视频ID/源URL、可核时长/画幅、实际查看/采样与音轨状态、纳入/排除理由。没取到的字段标未核，不补值。
2. **视频风格观察**：按实际可见维度描述，给可复核的观察区间/帧；实际看到的内容与本次创意推导分开。仅封面/文字的候选不列成已看风格案例。
3. **横向比较与推荐**：主要相同/不同点、对我方适合度、一种主风格及理由；无转化数据不称其效果最好。
4. **落地表**：`来源V-ID及观察 → 借鉴维度 → 我方具体S-ID/镜头与总词指令 → 我方真实依据/限制`。

已有项目文件可更新，不强制每视频另建JSON/TXT。媒体/抽样证据需要保留时放 `competitor-research/` 并由README说明用途；旧有图片资料作为历史存档，不为本流程继续补抓。

把推荐转成可执行文字，例如“完整中景交代枝束与花瓶落点→一处灯线近景→换场后稳定完整收尾”，再在整片总词安排景别、运动、转场与音画节奏；写清这是适配我方的提案。不要只交风格标签，或把研究报告变成需要用户自行拼接的额外视频提示词。

风格不会改变我方枝形、颜色、数量、尺度、盒体、接杆、真实步骤或随货范围。参考片的展示状态不能推作我方操作后的默认结果，例如看到竞品常亮不代表我方开灯默认常亮；档位与动作起止状态仍需我方依据。竞品原片、抽帧、水印、品牌和音乐不默认进 `jimeng-upload/`；可迁移方法以文字落实。只有用户明确要求媒体风格参考且当前模式支持时才另列该角色，不能替代我方商品身份参考。

需要修改项目时同步分镜、当前约定的四条提示词（明确单次时为一条）、实际参考包/清单、设置和输出README；仅研究或仅优化技能的任务按请求交付，不擅自重写用户已确认的成片方案。
