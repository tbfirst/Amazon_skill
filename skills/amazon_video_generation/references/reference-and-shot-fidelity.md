# 先保商品与镜头任务，再增加动态

适用于旧版效果回归、复用场景/补帧、细节镜、装配终态和多图输入。与物理连续性配合使用；不以关键词齐全代替图文一致，也不承诺文字能约束模型全部中间帧。

## 1. 改写前保留有效信息

逐镜比较旧版与新版的**展示目标、关键可见部件及连接、构图起终点、主运动、完成结果、附件角色**。这些放原CSV/说明书，不另交检查文件。用户已选环绕、摆动或特定细节路径时保留其意图；资料/时间不足就提出具体取舍，不静默改为横移、微移或换一个好生成的卖点。

取舍顺序：本SKU事实与用户意图→商品形态/关键细节读得清→操作能达到结果→主运动与必要响应→风格修饰。不能为体现“体积证据”把结构细节改成孤立孔壁，或为了所有字段都写运动反复说同一件事。改写后检查有没有丢掉原本有效的部件交界、支撑点、定位特征或停留；新加形容词不抵消这些损失。

## 2. 参考素材按属性分工，先消除冲突

策划时为本段实际附件/宫格格子指定角色，上传词只保留清楚的绑定：

|角色|约束内容|不应扩展为|
|---|---|---|
|同SKU实物身份/结构依据|固定轮廓、部件数量、邻接与连接、颜色材质|所有镜头冻结成同一姿势/视点|
|已核操作状态|同一部件的实际位置、开启/装入关系|与闭合图叠加出另一个组件|
|选定完成态F|本场布置的整体轮廓、分布、层次与目标落位|所有场景必须相同容器或参考图证明套装计数|
|场景/风格图|已选择环境、配色、光与构图|重设计商品结构或新增同款主角|
|生成预演/宫格|本镜计划状态与观察角|隐藏结构的事实来源，或覆盖实物身份|

**不设置“第几张必然权重最高”的平台规则。** 角色绑定是导演指令，不是模型硬隔离开关。实物与场景图里的商品有冲突，先修正/换掉冲突图；不能一边上传错误结构，一边说“只参考背景”就视为解决。未修妥的格子标needs-revision/stale，不进入标为可直接提交的包。事实缺口留说明书，不把疑似错误图用数量凑齐。

逐张比对原身份依据，包括嵌在故事板里的小图：固定外壳轮廓；主要部件的数量、位置和上下/内外邻接；本镜活动件开闭位置；容器/支撑；场景中是否无意多出另一个同款商品。合理透视/开合不等于结构冲突。密集小件不能目数确认时明确无法从图验证，不能勾选精确计数通过。

操作图只改变已选组件的位置；例如抽屉打开后原开口变为对应空腔，不同时保留一块闭合前板再在上方长出新抽屉。正式词按真实SKU简述固定壳体与活动件的关系，不能把“同一个/只有一个”当全部几何说明。并非所有柜子都单抽屉，数量必须来自本品。用户批准某图的道具或风格不自动等于核准整张图的商品结构。

不把所有附件和约束复制到所有镜头：爪孔细节只绑定身份与相关局部图，绳子状态只在绳子/抽屉镜绑定。同一状态图只服务指定S-ID及state；共享身份始终有效。模型仍可能混用，所以实际成片继续验收。

## 3. 细节镜要有定位参照与阅读结果

先决定“观众看懂什么”：纹理、接缝、连接、边缘厚度、开口形态或操控点。保留一个必要的邻接参照（门框与侧板交界、容器口沿与侧壁、连接处与主体等），使人知道细节长在哪里；已有前镜充分交代时可以更紧，但不能每镜都只剩没有位置关系的纹理贴片。

写清起幅可见内容→一个有用的主运动/接触→终点要读清的细节与短暂停留。焦点覆盖卖点，景深不要把结构参照全部糊掉；质感与形状需同看时采用合适斜角/掠射柔光，不为了夸张孔深改变板厚。空间变化是该拍法的结果，不另要求本已清晰的孔壁必须从“不可见”开始，也不要求微小零件在两秒里经历全套重建。

例：若本品与角度有依据，可写“侧前近景，起幅同时见门框竖边、侧板转角与邻近爪孔；相机沿侧板缓慢移到爪孔区域，保留转角作定位，停稳看清木纹、完整孔形与孔壁。”对另一类商品改用它自己的连接/轮廓参照，不沿用柜体词。移动长度按实际构图决定，未测量时不用厘米数字制造精确感。

## 4. 检查状态间的变化是否由动作产生

完成态倒推详见[终态与运动](terminal-state-and-motion.md)。逐对核对前终态、后起态及目标F：本步只新增/移动了什么；其他物体为何改变；手松开后结果是否已经成立。不能只见“花色相同”“组件总数相同”就认定布置一致。

同一机位比较轮廓与关键布局；不同机位先排除投影差异再判结构。若最后补入一件却需要整体变宽、缩短全部外露杆件、重排已有部件或填补多个无关空洞，当前步骤不足以达到F：先修基础态与该件落位，或明确加入有依据的调整动作及时间。不能把最后成品画得漂亮就算动作链成立，也不能偷加件数。

## 5. 交付与版本回归

同一S-ID的TXT、表、格说明和实际图必须指向相同任务、轨迹与状态。PNG是同源生成只能证明编号同源，不能证明图片内容相符；“已查看”不等于“已通过”。有结构冲突、不可达终态、把指定环绕改成横移等已知缺陷时，README应列未齐项，修复后再标可提交。关键完成态/几何只在小格看不清时，优先从九图预算里给它独立清晰图；删除重复图或重排，必要时询问取舍，不默认加第十张。

旧版/新版对比先锁定SKU、附件、镜头任务、模型入口和设置；保留旧包，用新revision记录改动。能控制时先只改一个问题镜的词或对应图，其他内容保持，用户生成后再比。不要同时换素材、道具、轨迹和时长后，把一次优劣归因于技能版本；也不要把文本修正称为视频修复。没有完整视频时，截图只支持该帧结构/形态观察，运动故障注明用户反馈，版本致因留作假设。
