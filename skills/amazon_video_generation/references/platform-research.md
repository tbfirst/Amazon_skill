# 平台研究：访问口径、方法迁移与本轮来源

## 什么时候研究

用户给竞品ASIN、指定参考片、要求调研，或新商品/操作/风格确有信息缺口时增量搜索。默认先按 [视频识别与风格分析](video-style-analysis.md) 找相关视频并研究其镜头、节奏和音画风格；不默认爬竞品图集/A+或分析评论。普通前期制作可直接使用已有可靠视频观察与 [植物镜头方法](plant-video-playbook.md)，不要求每次搜遍平台或凑固定案例数。外部片只提供方法启发，不补造本 SKU 的结构和功能。

按目标分工检索：YouTube 优先品牌开箱/整形/安装/维护；B站可找产品 B-roll、布光与具体花木教程；抖音可找花艺布置与短视频表达。搜索中文商品名/仿真与活体区别，也用 `artificial plant shaping / unboxing / styling / care` 等英文词。优先具体视频与作者原说明，访问受限时查同一发布方的官方嵌入页/文字稿，再找可公开的配套正文。

## 证据能支持到哪一层

| 实际访问到的内容 | 可用结论 | 不能推出 |
| --- | --- | --- |
| 连续视频画面/音频 | 实际可见动作、构图、切换、光影/声音；记录真实观察区间 | 未展示的结构、我方性能，或凭播放量推转化效果 |
| 下载视频后按间隔查看抽样帧 | 抽样所见的场景顺序、动作阶段、景别与前后构图；保存采样间隔、视频来源/时长和实际抽样图 | 已连续播放或听审、精确切点、每个中间帧无异常，或未出现于抽样的短动作绝不存在 |
| 官方文字稿/字幕 | 明确说出的动作与叙事顺序；有时间码才记相应时间 | 实际灯位、运镜、镜长、音乐或画面真实性已经核验 |
| 作者教程正文/简介 | 其明确给出的步骤、条件与选题；注明是正文 | 未写出的画面细节或逐镜制作流程 |
| 搜索索引摘要 | 摘要确实写明的主题/条件，作为待核线索 | 完整视频已看过、未显示部分的答案/步骤 |
| 仅标题、缩略图、关联推荐 | 候选主题/链接，推荐文案还需注明来自哪个页面 | 问题标题就是结论，或某动作/效果已经发生 |

正文/文字稿可支持其明确的主题/步骤选择，不代表看过视频，也不足以完成视频视觉风格分析；只看缩略图不做逐镜拆片。访问失败记录当时结果，停止重复碰同一个拦截入口；可继续其他视频来源，不虚构观看、时间码或平台能力，不用静态图集替代不可访问的视频。

新增研究写 `video-research.md`，按视频实体给稳定V-ID，记录清单、实际观察、风格比较/推荐与镜头/总词落地，字段见 [风格分析输出](video-style-analysis.md)。日期不明就写未核实；案例来自关联推荐时保留该出处。用户要还原指定参考片的实际运镜/节奏而无法访问时，请其提供可访问的原片/片段，其他工作可继续。

## 用户给竞品ASIN时

沿用当前商品与已确认时长/颜色/流程，不重开需求访谈。直接识别各ASIN相关视频，按 [专门流程](video-style-analysis.md) 核对归属并分析视频风格。公开页面/缓存仅用于定位视频、元数据和必要商品身份，不扩成竞品静态图策略；来源抓取时间与当前访问限制分开。无视频的ASIN保留缺口，可继续其余可看视频，不用图集/评论凑完成度。

## 历史记录：2026-10-27 首轮平台调研与复核

以下是当时已执行的研究范围，不是当前必须重跑的采集清单。正文/摘要线索不计为已完成视频风格分析，后续按上述视频流程补充。

本轮由三个研究 agent 分别搜索 YouTube、B站和抖音，再由主 agent 合并、自审和抽查原始来源。保存 **20 条主候选来源**（7 条 YouTube/官方教程相关来源、7 条 B站来源、6 条抖音来源），另有 Vimeo 品牌教程等交叉材料。这里的数量包括未能播放、仅正文或索引的候选，**不是观看了 20 条视频**；7 条第一组中 Balsam Hill 的视频所属平台未核实，不计为已验证 YouTube 视频。

访问结果：没有实际播放连续视频，未做逐帧/声画/镜长审查。National Tree 三页提供官方 `Video Transcript`；抖音精选两页和 B站一页正文可读；其余按各报告记录，存在 YouTube Cache miss、B站 412、抖音空响应/缓存失败。强证据支持操作叙事、方法与条件，无法支持原片运镜或转化效果结论。
