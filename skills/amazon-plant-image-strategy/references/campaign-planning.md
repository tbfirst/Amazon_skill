# 从购买任务到图片序列

## 策略定位

将核心购买任务写成：“当我处于某个具体情境时，我想完成某件事，以便得到某种结果。”标注用户确认、评论支持与推断边界。不要把“想买高质量植物”当作完整 JTBD。

每个候选方向比较目标人群、任务、证据、视觉可表现性与取舍。通常给两个有实质区别的方向即可：如客厅空角的体量适配，或近距离可见的叶片质感；不同滤镜不算不同策略。主线选定后，全套图围绕同一产品身份与购买任务展开。

若用户要求多色/多品类组合，主线可以包含多个已确认身份，按[载体内容表](arrangement-composition.md)逐一锁定，不强行收回单色SKU，也不把上传数量当作组合授权。每图的同时陈列/替代用途、容器分配与售卖边界要一致；图数仍是整套11张。

## 优先级

先排除无法支持或不允许使用的宣称，再给可执行概念排序。用户提供的简化分数可作启发式：

`优先级 =（意图覆盖 × 异议频次 × 转化影响）÷（制作成本 + 合规风险 + 证据缺口）`

各项有真实数据则注明口径；否则用 1–5 的相对判断并注明理由和 `heuristic`，不得写成测得的人数或转化提升。评分分母至少为 3（各项最低 1）；缺数据用“未知”而不是 0，必要时不算总分，只给定性排序。合规与事实门槛不能被高总分抵消。低频但会造成严重误购的问题可以优先，解释原因即可。

## 固定交付：六张附图 + 五张 A+ 图

本版本不新增主图；竞品主图仍需研究，用于了解识别方式与信息取舍。附件中出现的“12张/A+图6”及费用、耗时只是参考草图，以用户当前确认的 **11 张**为准，不把截图估算变成承诺。

| 固定资产 ID | 类型与任务 | 设计重点 |
| --- | --- | --- |
| DIM01 | 尺寸图 ×1：是否适合我的位置 | 实测端点、展开状态、单位、轮廓、尺寸线和可信尺度 |
| DETAIL01 | 细节图 ×1：近看是什么样、差别在哪 | 有来源的花叶/枝干/盆体特写，实际纹理、少量清楚标注 |
| SCENE01 | 场景资产1：优先购买任务 | 按用户分配采用单场景/四宫格/安装/对比；任务、真实尺度与依据明确 |
| SCENE02 | 场景资产2：补充购买任务 | 按已选类型增加用途、风格选择、真实操作或条件比较信息 |
| SCENE03 | 场景资产3：另一可支持任务 | 结构与信息服从用户分配；不以滤镜变化凑图 |
| SCENE04 | 场景资产4：补足信息覆盖 | 回应剩余重要问题，避免重复、无依据户外或夸大状态 |
| APLUS01–APLUS05 | 五张独立 A+ 图片 | 依据下文分工，深化认知与选择，不复制六张附图 |

六张附图的建议展示顺序可按研究调整，固定1张尺寸、1张细节、4张场景资产与稳定ID。尺寸图缺实测数值就保留DIM01阻塞草案，不用额外场景图顶替。先按[四类场景问答](scene-types.md)弹窗收集单场景、四宫格、安装/使用/维护、对比在4张中的张数分配，并逐图选择1600/2000/2048方图像素，再映射到SCENE01–04；各类可为0、总计4，不默认每类一张。四张固定1:1，不再询问横竖比。四宫格的一张位图内含四个不同风格场景，每格都有同款商品，仍只占一个SCENE资产。

生活场景的环境由产品用途和证据决定，不强制每种植物都放客厅/门廊/浴室/花园；安装图可围绕真实操作面，对比图可在同地点保留机位并改变一个明确条件。使用范围狭窄时可以同一环境提供不同有用信息，写明差异与不变量。

每张只回答一个主要问题。先按[文案与字体问答](copy-typography.md)收集基础文案：有输入则保留原意并润色，提交空白或明确委托则依据已核实事实生成；未答不能视为提交空白。再提供含Apple风格的基础字体菜单，用户选择优先，明确委托AI时才保留适用短标题的主动艺术字默认。英文标题一般3–6个词，中文标题一般4–8字，这是编辑目标，不是Amazon限制；无需把中文“≤6字”套到英文。证明句只放买家需要的事实和条件，内部证据编号不出现在成图上。

先依照[场景与节日拓展](scene-expansion.md)制作候选清单，给出有依据的四类分配建议再弹窗，不能等用户逐一提供场景。列出产品适配、竞品/评论启发或独立假设、季节兼容性、支撑与尺度条件、选择/排除理由。无证据支持的使用性能不因场景常见而成立。按[视觉指导](visual-art-direction.md)为生活场景指定建筑锚点、空间层次、配色角色、文字区和照明机制；多个独立生活场景原则上在用途、位置、观看距离、时间/光照中至少有两项实质差异，四宫格逐格采用不同风格并明确实际场所与任务。安装序列以真实步骤的信息递进区分，对比图以明确变量及可比不变量区分，不强迫它们更换地点、机位或两个条件。缺操作、耐候或工作状态依据时先弹窗，不由参考图补造。

素材同质或用户要求丰富时，执行有边界的公开场景检索；来源与已读范围记入账本，位置/早中晚/季节/活动/道具只是组合维度，不是四张图的固定配额。用[尺度记录](scale-and-composition.md)约束每张实际构图，先保证比例，再决定道具和文字区。图中氛围物件可以存在，商品仍是首要视觉对象。

## A+：固定五张图片，按实际模块适配

整套文案按[保义、自然英文、版面适配三遍编辑](copy-typography.md)处理。每张H1新增一个具体任务，不以同义氛围口号重复11次；术语、大小写和必要售卖边界保持一致。文字版式按[文字布局](text-layouts.md)接入已选骨架，逐段记录准确英文、断行与具体字区；原生A+字段不自动烘焙到图片。

保留 APLUS01–APLUS05 五张图的完整策略、brief 和 prompt。桌面制作默认1464×600；资格/实际槽位未知时标上传适配待核，不阻塞默认画布，不擅自减为0张。用户明确要求取消或改数量时再变更范围。没有同品牌产品时不编造交叉销售表，改用真实使用/细节/选择信息。

候选职责：

- 品牌与产品定位：真实品牌定位和使用情境，不编造历史、手作工艺、环保或认证。
- 细节与使用利益：增加证据、解释和选择信息，不能把副图原封不动复制一遍。
- 到货/整理/摆放或养护：展示真实可操作的过程。只有存在对应证据与可比条件时才考虑前后对照。
- 规格或型号选择：真实参数，比较自家已知型号，说明测量端点与条件。
- 深层 FAQ 或同品牌相关选择：来自实际疑问，不承诺未证实保障，不填无关 ASIN。

默认可规划五个单图概念，再适配实际 Content Manager。记录模块名称、适用能力（Basic/Premium/待确认）、每个 APLUS ID 对应的图片槽位、原生文字字段、桌面/移动端要求和来源日期。

为五张图制定递进叙事和版式节奏，例如定位横幅 → 使用位置组合 → 真实细节组 → 有依据的整理步骤 → 尺度/选择信息；按产品证据替换不适用职责，不强制凑步骤。可以使用全幅环境、左右分栏、同一图片内的场景组合、局部放大、流程栏等原创版式。避免五张都“左产品右标题”，也避免只靠换背景重复副图。一个组合位图与一个原生多图模块必须分别计数，详见视觉指导。

**五张图预算固定，模块数另记。** 例如三图模块用 APLUS01–03，两个单图模块用 APLUS04–05，总共三模块、五张图，不变成七张或十一张 A+ 图。不把真实三图模块拼成一个无法上传的大图。若实际规格要求额外独立移动端图，列为范围外适配需求，向用户说明再变更数量；不悄悄生成额外 prompt。

## 竞品视觉 → 我方单图设计

实际读取竞品有序图谱后，先依据[参考路线弹框](set-layout-dialogue.md#先弹窗选择提示词参考路线)让用户选择刚抓取套图反推、内置套图提示词或明确混合，再在所选路线内比较具体套图并选择/委托结构。不默认把新抓套图仅当背景研究后直接套LIB。确定跨图标题层级、色板、边距、标注语言和排版节奏，逐资产锁定版式，不能只在各张prompt里零散说“参考竞品”。

每张图都要说明：来源V-ID与可定位的竞品图/独立LIB-ID → 实际观察或模板阅读范围 → 为什么适合买家任务 → 用户选择/委托 → 我方如何适配 → 不沿用元素。保留参考的信息组织和版式骨架（分区、全貌/特写关系、窗格、文字层级、标注方式），配合我方商品与原创文案/场景。不要只借氛围后改成完全不同的版式；也不复制竞品商品、品牌、宣称或整幅现成画面。

把观察值和设计值分开写：竞品“目视估计主体占画面约一半”是观察；我方“主体区 x=8–65%、标题区 x=70–94%”是布局建议，不是测量结果。可以用 0–100% 的归一化区域、文字线框或简单示意说明构图，适配实际长宽比，不强迫所有图同一种左右布局。

每张必须具体说明以下要素，确不适用时说明：

- 布局：横/竖版、主次分区、主体占比、左右/上下位置、文案块、留白、安全区、尺寸线/特写窗口。
- 镜头与尺度：视角、景别、透视、背景虚实、产品与家具/墙门的真实比例，不能为突出产品缩小家具。
- 光线：主光从哪侧来、柔/硬、画面偏亮/中调/低调、明暗反差、填充光、色温倾向；以可理解的方向描述为主，不编造竞品摄影 EXIF。
- 阴影：接触阴影位置，投影方向、长度与软硬、透明感；光源与影子方向一致，不让产品悬浮；无可见投影时也说明保留哪些体积层次。
- 质感与颜色：如何展示真实材质而不漂色，背景与产品的分离方式，禁止“塑料变真叶”。
- 道具与文字：道具仅作环境，不能暗示随货；英文标题/证明句/标注逐字给出，限定信息密度与字重层级。

光影不能止于“温和自然光+简单投影”。说明相对相机的光向、光源高度和表观大小、亮面/暗面、补光目的、受影平面、距离带来的影缘变化；按图的任务选择定向日光、窗边漫射、逆光加正面补光、低角度长影、真实窗格影或冷暖暮色。尺寸与颜色识别图可采用均匀光。少量有理由的照明变化即可，不为花样使用全部方案。配色区分背景主色、辅助色、点缀色与商品原色；文字指定字号层级、字重、对齐、行数与对比，不能统一“大黑字”。

没有实际看到竞品图时，这些可以作为独立设计建议继续完成，但必须标明来源缺口，不假称来自竞品验证。多竞品都使用某种版式仅证明常见，不能推断高转化。

## 产品身份锁与视觉锁

产品身份锁记录经过核实的种类/型号、形状比例、花叶特征、颜色、关键枝干、可核实数量、材料、盆器与配件、真实尺寸和允许调整范围。难以数清的叶片不编精确叶数；用真实轮廓、分枝与密度参照。活体使用有依据的批次/季节范围，不承诺每株逐叶一致。

视觉锁记录背景族、配色角色、照明逻辑、机位语言、用户所选字体/AI委托、文案层级、留白和信息层级；它保证系列感，不要求每图相同灯位、布局、文字底板配色或道具花瓶。按[逐场景配色与载体表](visual-art-direction.md#按场景选择配色与载体)为不同使用场景选择兼容容器及局部字色；只将真实随货/固定容器纳入商品身份锁，换道具后按跨场景几何记录重算。可按用户标注图选择大中小层级、米白信息区、加粗标题、细边框标签及有来源的手触细节；这些是可选结构，不是柔软、Real-Touch或抗UV等性能证据。风格锁不能改变产品颜色和材料。默认欧美住宅，按站点本地化；美国站优先可信的美国家居。生活场景写出可识别的门窗、墙面、柜体等建筑锚点，操作近景无需强加住宅全景。避免未经要求的亚洲/非洲主题布景；此规则约束环境风格，不限制人物族裔。用户明确文化/地区方向及产品实际用途优先，具体选型见场景拓展参考。

## 规格与验证计划

以下为用户2026-10-19制作默认值及2026-10-23场景问答更新；旧项目规格不无声迁移：

|用途|默认像素|比例|适用说明|
|---|---|---|---|
|DIM01、DETAIL01|1600×1600|1:1|已知默认，不重复询问；sRGB制作目标|
|SCENE01–04|逐图弹窗选择1600×1600、2000×2000或2048×2048；1600为默认推荐|固定1:1|prompt前同一场景决策环节收集四类张数分配和逐图方图像素；不再问横竖比|
|五张A+桌面图|1464×600|61:25|宽横幅重新构图，sRGB制作目标，不横拉商品|

明确的后续项目规格覆盖默认；SCENE收到非方图要求时先澄清是否明确变更固定1:1。已回答的分配/像素不重问，未答或仅预选不能视为委托。A+即使采用场景、步骤或对比结构也保持1464×600默认或其明确覆盖，不自动方图、不纳入4张SCENE分配。1464×600是制作画布，不代表每个Basic/Premium原生模块槽均接受该大小；实际账号确定的图槽若不同，列出画布→槽位适配及裁切/重排要求，上传待核单列，不把用户已知尺寸改为unknown或反复追问。手机规格未知不自行继承参考值或增加图数。

用户明确仅做测试并授权自行决定规格时，可以指定具体测试画布与暂拟模块，写清“可测试生成、账户上传待核对”的 PROVISIONAL 状态。不得把参考成品的像素尺寸称为实际账户规格；缺商品事实仍须阻塞受影响内容。

规划尺寸、工具实际返回像素、正式上传导出是三个阶段。后续出图未达到目标时报告实际值，标明精确导出未完成；不得写提示词目标便视为输出达标。默认规格改变只影响新规划/明确要求迁移的项目，不在技能维护时无声改写历史成图。

移动端以实际缩略预览可读为目标，预设小屏预览宽度并建议用户验证；“28pt”不是所有图片的统一要求。规划阶段尚未出图，应标为待视觉验收。

实验一次改变一个主要变量。本套附图/A+优先关注会话到订单、相关退货原因或错选率；CTR 可作运营背景指标，但没有改变搜索曝光图时不能把 CTR 变化直接归因于这 11 张图。观察期与样本条件按流量确定，并记录价格、广告、库存、季节等混杂因素。没有随机实验时只描述相关变化，不能断言因果。
