# 从具体竞品套图迁移到可核对的提示词

用于竞品反推或有实际参考图的混合/内置路线。参考路线、具体套图、逐图来源是三个不同决定；只选了“竞品反推”不等于选定某个ASIN，也不等于允许任意融合。

## 选定可见的来源

先在聊天展示已实际查看的套图概览/代表图，标明ASIN、变体、图序及图库/A+覆盖；再用当前可用弹窗让用户选择具体套图。候选应说清可见差异，例如左文字右产品、底部色块、硬侧光与长投影，不只说“高级感”。已明确指定主套图或委托则跳过重复问。选混合时，落实每张主结构来源与辅助来源各负责什么；“A信息＋B氛围”仍需落实具体文件和属性。

默认做接近所选源图的结构适配，保持文字/图像布局和可观察光影；不是只沿用背景色或产品类型。若已有用户布局与该源图冲突，展示具体差异并弹窗决定保留旧布局还是靠近新参考。只问冲突项，不重新询问全部已确认项。产品事实、安全容纳及用户明确覆盖永远优先；无法兼容的部位标为适配，不承诺完全一致。

## 每张图的迁移约定

直接放入现有`layout-decisions.md`及Brief，无须新增11份文档：

| 项目 | 记录与执行 |
|---|---|
| 来源 | 主ASIN/变体/图序/V-ID和真实文件；实际目视范围。辅助源另列所负责属性 |
| 骨架 | 分区数、顺序和比例，主体中心与占比，完整图/细节窗，阅读路线与安全边距 |
| 文案表现 | 标题/标签位置、对齐、行数和层级；字形风格、字色、底板形状/填充/边界。文案原创，不能复刻品牌或未经证实的卖点 |
| 光影 | 可见的主光方向、软硬、亮暗面、对比、色温关系；接触影和投影的承接面、方向、长度和边缘。看不出的灯具参数标我方设计假设，不写成观察事实 |
| 保留/调整 | 每个关键属性是保留还是调整；调整后的唯一值及理由：真实SKU/数量、画幅、用户选择或商品保护区。不能用“优化”概括所有变化 |
| 实际输入 | 本图上传顺序中同时列我方身份/细节图和所选竞品的风格图，真实文件名与角色匹配。风格参考不提供我方花材、件数、包装、品牌或文字事实 |

风格图只写在研究文档里、只给URL/V-ID、只在聊天看过，都不代表生成工具收到了该图。交付用户复制的提示词时明确要上传哪些文件；后续另行授权生图时，核对工具实际输入。工具不接受或无法获取来源图时，如实记录`text-only adaptation`，依具体观察写完整布局/光影；不能声称已传入视觉参考，必要时让用户选择此降级或可用替代。

源图中的文字底板不能按通用“去掉色条”规则删除；但底板遮到我方商品时应移位/缩小或重新留白，并记录这处适配。单图字体统一要求与源图混排冲突时保留其信息层级和字区、改为统一字族并明示。竞品比我方枝数更多时保留编排方法，按我方实拍数量与密度重算，不追求相同花头填满面积。

## 对照后再交付

按“源图实际属性 → 本图设计 → 最终prompt/附件”逐项核对骨架、文字与底板、主体尺度/数量、光向/明暗和投影。至少让用户看得出每张保留了哪些具体特征、哪些有意不同。若全部只剩颜色相近，回到来源或适配决定，不标为结构接近。

策略阶段只能标`design-checked; render-unverified`。若之后获授权生成，采用实际源图与成图并排查看上述属性；字体混用、底板漏失、光向反转、稀疏或多枝分别记为差异并修订相应输入。不把一次prompt审查或生成成功等同于相似度、精确计数或字体排版验收，不伪造相似度分数。
