# 从具体竞品套图迁移到可核对的提示词

参考图迁移按[通用视觉结构分析](complex-layout-analysis.md)识别元素、归属、几何、图层、对齐、视觉层级和文字关系；按实际复杂度展开，将关键关系落实到执行词，不预设版式形状或场景数量。

用于竞品反推或有实际参考图的混合/内置路线。参考路线、具体套图、逐图来源是三个不同决定；只选了“竞品反推”不等于选定某个ASIN，也不等于允许任意融合。

## 先确定继承强度，再应用设计默认

旧套图更新时，在展示实际来源后让用户直接选择以下方式，可整套选择并逐图覆盖；未答时只推进不依赖该选择的工作，不擅自认定其中一种：

- `reference-replace` **完整画面替换式适配**：以源图背景场景、建筑、兼容道具关系、机位、裁切、图文比例、信息分区、字体组合和光影为基准；替换我方产品、准确文案、指定配色及必要适配，并默认允许下节限定的容器配色、机位与少量装饰调整。不是逐项冻结所有可选道具。
- `structure-adapt` **排版结构适配**：保留分区、阅读顺序、图文关系与信息层级，按本品任务重新设计场景、道具、字体、配色和光影；将新决定逐项写清，不能只写“自由发挥”。

记录`designTransferMode`及覆盖资产；没有参考来源的原创图不冒称这两种参考迁移。已有明确要求“只换产品，其余保持”等直接记为对应选择，无须重复问。新套图用户指定参考继承程度时同样适用；一般竞品路线未指定时按下文接近源图的结构适配执行。

此选择与旧稿执行方式独立：`layout-rebuild`可完整继承新竞品，`bounded-edit`描述的是具体编辑底图和边界，不能据此误锁旧稿。每条prompt分别命名**商品来源、设计主参考、实际编辑底图（若有）**，来源不同就分别列出，不含糊地统称“保持原图”。

## 有限生图自由度

参考迁移默认具有以下局部设计权限，`reference-replace`也适用；不另增第三种迁移模式，也不要求每张必须改。先在策划阶段确定唯一结果，再交给生图模型执行。用户明确要求某区域、配色或机位完全不变时，按其范围收紧权限；“完整继承”本身不取消这里的适度自由。

|可调整项|目的与范围|仍须满足|
|---|---|---|
|道具容器颜色|可调整不随货、未锁定花器的色相、明度或饱和度，让主产品的颜色与轮廓更易辨认；通常先保留容器形状、材质和尺度关系|产品自身颜色及随货/固定盆不变。不能靠透明瓶改成不透明来掩盖不合理插入或剪茎；换色后重新检查环境联系、反光及主次|
|拍摄角度与机位|可适度移动相机、改变拍摄高度、侧向角度或景别，展示有来源的花叶层次、形态与空间感；保留可辨认的原场景与主要构图关系|不以俯拍变平铺、正面变背面或全景变特写为“微调”；新可见部位有本品证据，未知背面/连接不凭空补造。重算透视、遮挡、画幅占比、文字留白及影子，商品实际尺寸不变|
|少量装饰与类似替换|可增加少量服务尺度、生活气息或场合的点缀；也可用用途、体量、轮廓或材质作用相近的物件替换原有装饰，如同位置书本、托盘或小型摆件|保持视觉重量低于主产品，延续原来的前中后景和支撑关系；不遮关键部位、不堆满留白，不引入新的主花材、假随货配件、额外口号或品牌。茶壶/杯子作背景不等于可承载花材，常规容器规则继续有效|

判断是否仍为完整继承，看原分区、阅读路线、主体落点与空间关系、场景锚点及光影特征是否仍清楚。几项轻微变化叠加后若已重做整套布景、构图或光线，就超过此权限，应按`structure-adapt`讨论；不以变化百分比或固定角度阈值代替实际判断。适度自由旨在更好展示本品，不强制每图都改色、改机位、加装饰。

在现有保留/调整记录中简记“源值→选定值→展示目的”，例如“暖白道具陶瓶→低饱和深蓝灰，以分离白色花瓣”；机位写明确的视点/景别，道具写具体对象、位置和相对体量。产品事实、源图观察与我方设计调整分别记录。无需为本范围内每项重新弹窗；涉及锁定要求冲突、缺本品素材或跨越继承强度时才追问。

优先顺序：商品事实与适用性、常规容器边界及完整商品保护 → 用户明确指定且不存在未决冲突的要求 → 所选参考与继承强度 → 自主设计默认。完整继承时，源图的字体组合、无字/有字结构、底板、布局及光影优先于单字族、少底板、主动艺术字、空间拓展或跨图多样性等默认；无需为保留这些已选属性再逐项申请例外。字体只按可观察字形描述，不能伪称识别出确切字库。若明确品牌/字体要求与新选源图冲突，只澄清该项。保留文本的视觉层级不等于复制竞品品牌、原句和性能主张；图内文案选择与我方准确内容仍按文案规则落实。

## 选定可见的来源

先在聊天展示已实际查看的套图概览/代表图，标明ASIN、变体、图序及图库/A+覆盖；再用当前可用弹窗让用户选择具体套图。候选应说清可见差异，例如左文字右产品、底部色块、硬侧光与长投影，不只说“高级感”。已明确指定主套图或委托则跳过重复问。选混合时，落实每张主结构来源与辅助来源各负责什么；“A信息＋B氛围”仍需落实具体文件和属性。

按已选继承强度实施；一般竞品路线未指定强度时，默认接近所选源图的结构适配，保持文字/图像布局和可观察光影，不是只沿用背景色或产品类型。若已有用户明确锁定的布局与该源图冲突，展示具体差异并弹窗决定；仅在旧稿中出现的布局不构成锁定。只问冲突项，不重新询问全部已确认项。产品事实、安全容纳及用户明确覆盖永远优先；背景与可选道具还须通过[市场及组合适配](scene-product-container-fit.md)，不兼容时局部调整，明确要求保留而有冲突时先追问；无法兼容的部位标为适配，不承诺完全一致。

## 每张图的迁移约定

直接放入现有`layout-decisions.md`及Brief，无须新增11份文档：

| 项目 | 记录与执行 |
|---|---|
| 来源 | 主ASIN/变体/图序/V-ID和真实文件；实际目视范围。辅助源另列所负责属性 |
| 骨架 | 分区数、顺序和比例，主体中心与占比，完整图/细节窗，阅读路线与安全边距 |
| 文案表现 | 标题/标签位置、对齐、行数和层级；字形风格、字色、底板形状/填充/边界。文案原创，不能复刻品牌或未经证实的卖点 |
| 光影 | 可见的主光方向、软硬、亮暗面、对比、色温关系；接触影和投影的承接面、方向、长度和边缘。看不出的灯具参数标我方设计假设，不写成观察事实 |
| 保留/调整 | 每个关键属性是保留还是调整；调整后的唯一值及理由：真实SKU/数量、画幅、用户选择或商品保护区。不能用“优化”概括所有变化 |
| 实际输入 | 本图上传顺序中同时列我方身份/细节图和所选竞品的风格图，真实文件名与角色匹配。风格参考不提供我方花材、件数、包装、品牌或文字事实 |

风格图只写在研究文档里、只给URL/V-ID、只在聊天看过，都不代表生成工具收到了该图。交付用户复制的提示词时明确要上传哪些文件；后续另行授权生图时，核对工具实际输入。工具不接受或无法获取来源图时，如实记录`text-only adaptation`，依具体观察写完整布局/光影；不能声称已传入视觉参考，必要时让用户选择此降级或可用替代。

源图无底板时保持无底板，无字时优先保留无字；不能额外添加通用标题框。源图合适的白色羽化可以保留，按[图文融合](text-layouts.md#图文融合与文字底层)约束完整效果范围。有底板且确实服务本图时保留，但不能因此给其他图也加底板。底板/羽化遮到我方商品时局部移位或缩小，记录必要适配。

`reference-replace`保留源图实际混排与各层级的字形关系；`structure-adapt`按已确定的字体方案实施，未指定时采用统一字族默认。竞品比我方枝数更多时保留编排方法，按我方实拍数量与密度重算，不追求相同花头填满面积。

## 对照后再交付

按“源图实际属性 → 本图设计 → 最终prompt/附件”逐项核对骨架、文字与底板、主体尺度/数量、光向/明暗和投影。至少让用户看得出每张保留了哪些具体特征、哪些有意不同。若全部只剩颜色相近，回到来源或适配决定，不标为结构接近。

策略阶段只能标`design-checked; render-unverified`。若之后获授权生成，采用实际源图与成图并排查看上述属性；字体混用、底板漏失、光向反转、稀疏或多枝分别记为差异并修订相应输入。不把一次prompt审查或生成成功等同于相似度、精确计数或字体排版验收，不伪造相似度分数。

旧套图更新时另记录旧文件→可用商品区域/补图→竞品图→新布局。旧图提供商品信息的范围取决于忠实度与清晰度；旧设计、竞品商品及旧文案不自动成为身份事实。新布局重建不受旧图“全背景保持”编辑默认约束，局部改版仍保留明确范围外正确内容。

## 高保真替换式适配（所有图类）

用户要求沿用竞品优点时，可以选择“保留优秀画面，替换商品并调整配色/文案”的路线。逐图指定一张主参考，先记录机位、裁切、背景建筑、道具位置、前中后景、主体落点、留白、光向/阴影和信息分区基准，再按有限自由度落实局部调整；尺寸图还保留箭头/标签组织，细节图保留窗格与引线，A+保留叙事与图文比例。不要用“参考风格”代替这些具体保留项，也不要求为了原创而重做场景。

将用户口语中的“一比一”落实为以上可核对的保持项，不先降级成模糊风格借鉴，也不承诺生成器逐像素复制。商品配色保持我方真实SKU；“调整配色”默认指环境、道具、文字及底板，不授权给商品换色。若用户指定另一商品颜色，先绑定其实际变体素材。

每图给出保留项、替换项、必要适配三列。替换我方SKU、准确文案和指定色彩；尺寸数字、支数、结构、材料和功能以我方依据为准。仅在目标市场与产品/容器搭配兼容时保留源图建筑和道具；不匹配时列明局部替换，不能为了继承画面保留不合适的楼群远景或容器。商品轮廓或画幅不兼容时，只改受影响的落点/留白/局部道具，说明理由，不扭曲商品来贴合竞品。竞品商标、水印、包装文字及专属宣称不作为保留项。

执行词明确上传附件的双重角色：我方实拍控制商品身份，竞品整图控制布局/场景/光影。直接编辑可用的原场景时保持明确未变的区域，将选定的换色、机位或装饰调整列入允许变化，删除与其冲突的“所有机位/道具完全不变”；生成重建时以具体空间关系约束接近程度，不承诺像素级相同。缺少实际风格附件时标记文字适配，不能声称已做到原图替换。交付前逐项对照，若场景、道具、布局和光影都被重写，就不称为高保真继承。
