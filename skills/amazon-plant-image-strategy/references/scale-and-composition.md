# 实物尺度、透视比例与主视觉校验

适用于花卉、盆栽、树木、花环及其他支持的植物商品。每张带场景/参照物的图在定版式前读取；尺寸图以真实测量端点为准，细节裁切不能被当作整件大小。以下是摄影与构图计算，不是平台占比规定。

## 尺寸对象与视图先绑定

DIM01的每条尺寸在Brief中绑定：测量对象/部位 → 原始数值与单位/事实来源 → 起止端点与整理状态 → 成图的具体全貌或局部视图 → 支持该视图的素材。整体尺寸只连到完整商品视图的对应端点；局部窗口仅在有独立实测依据且端点完整可见时标该部位尺寸。不从特写的像素大小、上传顺序或完整商品数值反推局部尺寸。

看不出素材是全貌还是局部、含盆与否或测量端点时，先向用户弹框澄清；缺完整视图时请求补图，不拿局部补画整件后标整体尺寸。等待期间继续其他资产。确认后在每条受影响prompt重复附件角色与尺寸绑定，不能只留在内部证据表。

## 三个数必须分开

1. **商品实物尺寸**：适用SKU、宽/高/深、含盆与否、整理状态、来源P。只给外沿宽度时不能顺手假设高度也相等。保持源图可信宽高关系，不能用独立拉宽/拉高塞进版式。
2. **商品对参照物的比例**：选明确端点与同向轴，如整件高度对同平面柜高、花材外宽对同深度桌宽、挂件外沿对完整门板宽。参考值分实测、用户确认、设计假设；“常见家具”不是该场景已测量的事实。
3. **商品画幅占比**：商品投影宽/高相对图片宽/高，用于取景。它由相机、空间和真实比例一起决定，不能写成第二个互相冲突的商品放大指令。

同款跨图固定的是实物尺寸与支持状态，不是相同像素占比。中远景可以较小，近景可以较大；不得通过缩门、矮桌、巨型茶杯或改小沙发维持商品占比。

## 每张图的尺度记录

|字段|最少需要记录的内容|
|---|---|
|Product|P来源、测量轴/端点、实物值与状态、轮廓宽高关系|
|Primary anchor|一个主要参照物、完整测量端点、尺寸值、实测/确认/设计假设|
|Plane / axis|相对镜头深度、是否同平面近似、轴是否可比/被透视压缩|
|Ratio|实物比、投影比或保守范围、计算方式与未知因素|
|Framing|主要参照物画幅占比，据此推导商品占比、位置与裁切限制|
|Secondary check|有用时用另一尺度线索复核；不强制每张塞满两个道具|
|Support / clearance|盆底/台面/地板/挂点关系、开合/通行/容纳余量|
|Verification|规划计算结果；出图后是否真的看到可比端点、实际目视/像素估计及局限|

门板比较需看门板左右边，不用窄的镶板内框冒充门宽。容器不换成更小/更大款。地面树的总高不能与远处近天花板的装饰物直接作无透视换算；杯子、蜡烛、书本尺寸变化大，只宜作辅助，除非实际规格已知。

## 先算比例，再定镜头与文字区

同深度、轴近似平行像平面时：

`商品/参照物投影比 ≈ 商品实物尺寸 / 参照物实物尺寸`

`商品画幅占比 ≈ 该投影比 × 参照物画幅占比`

如果一份设计写30cm宽花材对60cm宽同深度搁板，同时搁板占画宽80%，则商品约占40%画宽；不能又命令商品占70%。要更突出商品，可收紧镜头让参照物部分出框、减少道具或改变布局；说明取景变化，不能改变实物比。若此图需要完整参照物，又无法同时满足文字区与真实尺度，就改文字位置/分区或机位。

不同深度时，在透视近似和可比轴条件下：

`投影比 ≈ 实物比 × (参照物距相机 / 商品距相机) × 轴向投影修正`

镜头前方茶杯自然显大，不可拿其像素大小直接判断后景花盆尺寸。强斜视门面需同平面透视还原/可解释的构图估计；无足够几何资料就记“不可直接像素比较”，换近同平面的参照或更正面机位。不得从单张无标定图编造焦距/距离来让公式成立。辅助道具与商品深度不同，不能强制二者遵循同平面比例。

每张优先给**一个自洽的尺度目标**，再推取景；不要同时给很多独立且矛盾的百分比。给布局区间时它是容纳区域，商品在区内等比拟合，不是强制变形的宽高框。远景商品不够辨认时，先减背景竞争/缩短观看距离，不增密、不增大实物。

## 主视觉优先级，而非强制画面几何居中

商品可以偏左/右给文案留位，但应是第一视觉对象。检查商品清晰度、局部明暗/颜色分离、完整可辨轮廓，与前景道具/灯火/画作/文字的竞争。大面积深色近景、正脸人物、强亮灯点、高对比画作、相似且更茂盛的植物都可能夺焦；按当前图减少、缩小、降对比、后移或柔化**道具/背景**。不靠模糊商品、削弱枝梢或夸大尺寸提升主次。

“商品主视觉中心”指视觉关注优先，不要求每张都摆正中，也不要求所有场景固定相同占比。实际有用的小物可以保留，位置与作用见[场景拓展](scene-expansion.md)。

## 可选算术助手与边界

Python可用时，用 `scripts/scale_check.py` 校验已经选定的尺度记录；否则在brief手工给同样算式。程序不读图、不识别物件、不核实参照尺寸，不会把场景自动校准。输入只接受统一cm值，单位换算先另行核对。可比轴/深度关系由设计者负责。

助手的画幅占比输入针对可见完整参照物/完整商品，范围(0,1]。参照出框的近景可另选完整可比标尺或保留人工透视判断，不能把残留的可见宽度当完整实物宽度。

示例为合成设计输入，不是待填占位模板：

```json
{"assets":[{"asset_id":"SCENE01","product_cm":30,"reference_cm":60,"reference_basis":"design_assumption","projection_mode":"coplanar_parallel","reference_frame_fraction":0.8,"product_frame_fraction":0.4,"relative_tolerance":0.1}]}
```

```text
python scripts/scale_check.py --input project/scale-plan.json --output project/scale-audit.json
```

- `reference_basis` 为 `measured` / `user_confirmed` / `design_assumption`，假设始终显示警告，不包装为实测。
- `projection_mode` 为 `coplanar_parallel` / `explicit_factor` / `unresolved`。`explicit_factor`另给正数`perspective_factor`，说明其来源；未知透视选unresolved，程序不判断投影比是否合格。
- 可选`observed_product_px`与`observed_reference_px`必须成对，是人工确认可比端点后录入的像素估计，不是自动识别。`relative_tolerance`默认10%仅作诊断阈值，可按证据与误差修改，不是产品公差或平台容许失真。
- 输出能发现算术/规划比例矛盾或已录入观察的大幅偏差。没有观察值时`visual_check`为not_provided；输入一致、退出码0不代表成图保真。unresolved仍需人工处理，不能写通过。

## 出图后反馈（仅用户另行授权生图/复核时）

在原分辨率看完整轮廓、参照端点、前后关系和局部支持，再看小屏主视觉。可比时核对观察投影比与设计；不可比时说明原因，不给假精确百分比。明显偏差只修该图的尺度/取景及其后果（挂接、接触影、投影），保留商品身份和已合格其他图。不能只在报告写“约61cm”便视为画面比例已校准。
