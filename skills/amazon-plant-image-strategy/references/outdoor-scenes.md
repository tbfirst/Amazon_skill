# 室外场景提示词：先选用途，再落到具体空间

室外选题、室内候选过多或用户要求丰富庭院/门廊/阳台/花园时读取。入口为内置 `OUT-S01–12`、`OUT-G01–03`、`OUT-I01–03`、`OUT-C01–03`、`OUT-A01–03`，共24条原创文字模板。它们没有配套成图，未做Lovart生成验收；不是新增竞品观察、图像配方或已验证产品用途。

## 检索与数量

用 `python -X utf8 scripts/library_catalog.py search --kind template --query "室外" --limit 24` 查整组，再用 `show OUT-S03` 读取完整英文方向、中文说明和前置条件。可按“阳台”“安装”“昼夜”“A+”等词缩小范围。默认每轮为用户挑2–3个适配方向，可以继续换候选，不把24条全部塞进一次弹窗。

|类型|ID|可选方向|
|---|---|---|
|单场景12条|OUT-S01–12|美式入户门廊、后院铺石露台、城市阳台、外窗花箱、檐下吊篮、花园长椅、前院步道、露天餐桌、欧式石墙庭院、木平台休闲角、门外挂花环、庭院傍晚|
|四宫格3条|OUT-G01–03|四种住宅室外风格、四种有支撑的悬挂位置、四种室外桌面用途；每格有同款商品|
|安装/使用/维护3条|OUT-I01–03|花箱摆放、花环/吊篮固定、清洁与收纳；动作与步数由当前SKU实际方法决定|
|对比3条|OUT-C01–03|同地点昼夜、同地点晴雨、同地点整理前后|
|A+横幅3条|OUT-A01–03|室外主视觉横幅、三种室外用途、主场景＋两个真实细节|

24条是可适配的文字方向，不是所有商品都能使用的24种布局。G类中的四格为一张图，I类步数为同一资产内步骤，A类各一张横幅；仍遵守4张SCENE、5张A+及整套11张预算。原有46个图像来源布局配方与45条A+逐图分支保持各自计数，不把文字卡加进已观察配方数。

维护时编辑 `assets/reference-library/authored-outdoor.json`，再将其中卡片更新进 `catalog.json` 并重建 `index.md`。`import` 会保留目标目录这一独立原创文件并合并；ID冲突明确报错，不能用原库快照静默覆盖原创方向。通过远程库查不到OUT-ID时，使用技能自带catalog作明确的补充来源，单独记录卡片版本，不能声称它来自已锁定的远程版本。

## 户外适配与弹窗

A+同样可以安排门廊、庭院、窗箱、悬挂、池畔或夜景；五张可以全部室外，不设室内配额。是否适用由本品用途、暴露条件、支撑和真实尺寸决定；A+图类本身不构成限制。[已审核套图](curated-source-sets.md)提供实际图和逐图反推，与本页24条无配图原创OUT方案分别标记来源。池畔不证明可浸水，夜景不证明耐候，干燥花不能因参考为仿真花就自动获得长期露天用途。

1. 先读SKU说明与用户已提供的用途，区分**室外长期陈列、遮蔽处使用、临时活动摆放、室内隔窗看室外**。后三者不互相替代，也不由“有屋檐”推出适用性。室外场景不等于防水/耐晒/抗风测试。
2. 已确认室外范围时，积极提供对应室外候选；不能因缺一个不需要展示的性能参数就把所有图退回客厅。未知实际暴露范围时，弹窗具体问“资料允许露天、檐下还是仅临时摆放？”，说明哪些候选依赖回答，继续不依赖该项的文案/布局工作。室内限定商品不给它套露天模板；隔窗外景只是经选择的替代，不记作真正室外场景。
3. 按[场景类型](scene-types.md)询问4张内的类型分配和各张1600/2000/2048方图像素，再问尚未解决的地点、建筑风格、支撑、时段、文字等。已有明确回答或委托不重问。用户只要求“优化技能”时维护候选库即可，不要求用户此刻提供某个SKU或完成未来项目问卷。
4. 晴雨模板只在当前SKU的商品及涉及的电源/连接件都支持所画暴露条件时执行；“室外可用”不自动等于可淋雨。晴/雨图标签表达条件，不添加防水等级、寿命或测试结论。昼夜模板中无灯商品由真实环境照明照亮；有灯功能必须有灯位/电源/工作状态依据。
5. 安装、清洁、收纳、整形用说明书、实际操作照片或明确用户方法确定动作，不把模板里的流程规划当作事实。活体的光照/温度/养护依实际品种资料；无依据不套仿真花弯折、擦拭花瓣或免养护流程。

## 空间、风格与光影

户外候选按“空间用途＋商品支撑方式”分支。地插、盆栽、散枝、花环、吊篮和灯树不互相改造。选择12个单景中的6–10个适配方向进入初筛即可；窄用途商品可以更少。用户偏好室外时，先覆盖适用的室外空间，再根据缺口补室内，不按固定室内外比例分配。

- 门廊：门扇、门套、檐柱、台阶说明尺度；核开门方向与通路，不能默认复制一套商品做左右对称。
- 露台/木平台：铺石或木板接缝、门槛、坐具建立前中后景；阴影落在同一承影平面，商品数量与单包范围一致。
- 阳台/窗箱：栏杆、外窗台与立面明确室外关系；容器/挂点要真实可信，不能悬空、穿栏杆或改变盆底。
- 花园/步道：铺路边界、围栏/矮墙和远处住宅构成尺度；让背景植被更弱，不把额外花叶接到商品上。地栽只用于有依据的活体种植或真实地插方式。
- 露天餐桌/庭院聚会：以真实桌面高度与承托核尺度，餐具作从属道具；不靠新增第二套花材制造丰满效果。
- 挂花环/吊篮：保留真实挂件和承重关系，背景风格可换但安装方式不能凭空变；必要时另问支架/挂钩的随货或另购状态。

每个单景选一个主导照明：清晨侧光、明亮阴天、树荫散射、午后日光、落日低角度长影、蓝调时段与壁灯。明确方向、软硬和承影面；不要把所有室外图都写成金色夕阳。无灯商品不得自发光；大风不能让仿真商品产生未经证实的弯曲、飞叶或稳固演示。

12个S模板中的构图区都是建议，须按真实比例与[尺度校验](scale-and-composition.md)适配。不能为填满右侧区域放大实际小盆栽；改景别和留白，保留门窗/坐具尺寸依据。四宫格同款形态/固有色一致，但四种建筑风格、用途或机位应有真实差异；不是四种滤镜。

## 写入最终提示词

库中英文是供agent改编的设计模板。发布READY前把所有条件改成**本张唯一明确方案**：实际附件名与角色、尺寸/支撑/数量、具体场所、逐格或逐步骤构图、所选光源、准确文案、用户字体和唯一像素；不能把“用户选定的尺寸”“按批准的方法”等依赖对话的泛称留给Lovart猜。

文案按[文案与字体](copy-typography.md)先弹窗输入，空白提交/明确委托才AI写；字体优先用户选项。采用大标题、中等辅助句、小标签的有意层级，全部文字与字效避开完整商品；无字和A+原生字段选择照常保留。示例中的“晴雨”“傍晚”等是候选主题，不自动成为画上文字。

SCENE仍固定1:1，选择1600×1600、2000×2000或2048×2048；户外A+仍为1464×600默认，按横幅重新安排景别与文字区，不能直接裁掉方图商品上下部分。交付前检查环境暴露与事实、同款形态与数量、安装方法、尺度、光影、文案、字体、类型分配和逐图规格是否全部一致。
