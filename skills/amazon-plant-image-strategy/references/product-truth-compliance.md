# 产品真实性与平台核对

本文件区分三类约束：产品真实性底线、项目的保守设计约定、需要当次核实的平台规则。不要把本地文档当作永远有效的 Amazon 政策。

## 植物类产品身份

- 多角度照片必须先确认是否同一 SKU；混有不同尺寸、颜色、年份时分开，不“综合成更好看的版本”。
- 保留花叶形状、颜色、纹理、主要分枝、真实体量和密度。禁止复制花朵/叶片增加丰满度，禁止把塑料质感改写为真实植物材质。
- 对已知可整理的仿真枝条，允许实物可实现的展开与弯折；没有依据时不提供拆装、折弯或水洗步骤。保留真实部件，不从风格图借用花材。
- 随货盆、育苗盆、装饰套盆、托盘与摆拍家具分开记录。场景用套盆时须具有合理容纳关系，不能把实际随货盆变成另一款。影响购买理解的道具应去除或清楚区分，不能依靠极小免责声明解决。
- 不创造看不到的背面结构、根系、排水孔、内部填充或包装。需要的角度没有照片时，改用有证据的视角或请求补图。
- 尺寸必须区分含盆总高、植株部分高度、展开冠幅、盆高、盆口直径；记录单位、测量端点、状态和范围。换算保留原值并核算，不能用图片比例生成实测数据。

### 活体分支

需要时核实品种/物种、发货年龄或规格、季节状态、含盆/裸根、包装与到货表现。尺寸范围、自然差异和花期来自适用资料。不能用成熟盛花植株替代实际售卖幼苗，不能移除有代表性的自然差异以暗示固定外观。

未来长成效果只能在有依据且不误导的非 MAIN 场景中明确标识为示意，并区分实际到货状态；缺少时间与条件依据则省略。宠物安全/无毒、净化空气、抗过敏、必定成活、耐寒区或养护效果不能由外观推断。涉及相关主张时按可靠来源及当次要求另行核实。

### 仿真分支

“仿真”必须在策略和需要区分身份的文字中明确；生活场景不能暗示这是活体。材料、阻燃、抗 UV、耐水、抗褪色、无味或无毒需要与本产品匹配的依据。没有耐候证据时不要靠门廊、雨水或强日晒场景暗示全天候可用。没有材料依据时可描述可见纹理，不能猜测 silk/latex/PE 等。

## 每次运行的政策核对

从 [sources](sources.md) 的官方入口开始，结合站点和具体类目核实。记录 URL、读取日期、适用范围、核实内容及登录受阻等限制。冲突时以当前适用的官方规则优先；查不到则标“待平台复核”，不保证合规。

### Listing 与 MAIN 检查

当前默认交付只有六张附图和五张 A+ 图。以下 MAIN 规则用于研究竞品主图、识别不应模仿的做法，以及用户另行要求新增 MAIN 的情形；不据此自动新增我方主图，也不强迫所有附图白底。

美国站公开指南的基础约束包括真实呈现产品、主图纯白背景、商品充分占画面、整体完整，以及避免误导性未含物品。85% 是官方指南中的占比要求；对细长稀疏植株不要据此擅自加密或裁掉枝梢。多件套按真实销售单位及适用多件套规则核实。

本技能默认 MAIN 不添加文案、徽章、额外 logo、水印或拼接小图。商品本来具有的真实品牌标识保留，不能把“禁止叠加 logo”误读为磨掉商品印字。包装是否可展示须结合类目和商品特性。

所有图片都避免 Amazon 徽章/商标仿制、评价截图和星级图形；评论作为内部洞察而非成图社会证明。项目默认不把价格、促销、运费/到货承诺绘入图中。平台规则、类目例外与制作建议分别标记，不用一个 ALL 清单推导所有槽位都禁止文字。

### A+ 检查

依据当次官方指南核对文案、链接、保证、促销、资质与比较限制。项目默认排除保修/退款保证、价格、促销、物流承诺、联系方式、二维码、站外导流、客户评价和竞对品牌攻击。平台原生提供的交互或价格字段不等于允许把它们伪造画进图片。

“有检测报告”仅能支持其检测对象、条件和结论，不能任意使用认证图标。奖项需适用主体与年份等来源。Before/After 需要真实可比条件，不能由两张生成图伪造实验结果。型号表仅比较证据充分的本品牌选项，不虚构目录。

尺寸、支持模块、图槽数、字段字数和移动端规格按实际 A+ Content Manager 确定。模板不固定第三方像素值，也不把 SP-API 模型当成所有账户功能的完整清单。

Alt text 自然描述所见内容与必要文字；不堆词、不加入图片中不存在的性能。遵循实际字段长度，把完整原生模块文字单列，不能为了照抄全部图片文字而超字段限制。Listing 没有对应可编辑 alt 字段时标为交接说明，不声称一定可上传或改善自然排名。

### AI 人物与交付检查

若确需写真人感合成人物的提示词，核实当前 Amazon 的相关披露/元数据要求，并列为后续导出步骤；纯提示词无法设置或验证成图元数据。不要无关地为无人物植物图添加这项操作。

规划只完成文字预检。用户在 Lovart 出图后还需检查：SKU一致、尺寸/数量/随货范围、阴影与接触、文本拼写、移动端可读性、实际分辨率、背景像素、必要元数据和平台预览。未看图不标这些检查“通过”。
