# 多轮引导与决策记录

这不是上传后自动填满模板的流水线。先帮助卖家找到明确的购买任务，再选择足够有证据的表达。使用用户的语言，默认中文。

## 对话节奏

首次缺素材时直接给简短输入提示：“请告诉我产品是什么（真实/仿真、售卖内容），上传现有实拍/白底/多角度细节及真实尺寸资料，并给出 3–6 个不同竞品 ASIN/链接。”原始素材数量按可用信息决定，不要求用户先有 6 张成品附图或 5 张 A+ 图。默认交付已经固定为尺寸×1、细节×1、场景×4、A+×5，无需再问总图数；四张SCENE的类型张数分配和逐图方图像素仍按下文弹窗选择。

1. 先读已有资料，简要说明已知的售卖对象与最大的未知点。
2. 默认积极使用多轮实时弹框，轮数不设上限，不以压缩对话为目标。售卖事实通常每轮问一个关键问题；素材有歧义时当场澄清，不必等竞品研究完成。版式选择按[整套图弹框流程](set-layout-dialogue.md)每批1–2题，问题简短、逐步深入。设计选择可给2–3个具体选项和推荐理由；未知实测值用自由输入，不以推荐项暗示事实。引用真实已读的竞品图序或LIB卡片，不只有“高级/温馨”。工具不可用时在聊天问。
3. 回答后用一句话解释它如何影响图片，再问下一个问题。研究与整理可以同步推进，但不要在用户尚未决定时把候选方向写成已确认。
4. 随信息充分度推进：收集并澄清素材与关键事实 → 实际读取并展示竞品套图及覆盖 → 弹窗选择刚抓取套图反推/内置套图提示词/明确混合 → 在所选路线内比较具体套图，确认场景类型张数分配、逐图方图像素与必要布局细项，收集基础文案和字体选择 → 交付。路线选择见[整套图弹框](set-layout-dialogue.md#先弹窗选择提示词参考路线)，不必等受限评论恢复。文案输入可随材料收集提前进行，最终文案与排版须在相关prompt前落实。阶段之间可反复澄清，不限定两轮或两批结束；每个问题应解决当前歧义或形成具体设计决定，不机械填问卷。已选择或明确委托的项跳过。用户说“不知道”时可推荐设计方向；无法确认的产品事实仍保留未知，不将沉默当委托。
5. 上传资料或截图的请求直接写在聊天里，不通过仅接收文字的选择题工具索要附件。

## 素材歧义先澄清

先执行[缺失事实与可见细节门槛](product-truth-compliance.md#缺失事实与可见细节门槛)，不只检查有没有照片，还要检查计划所需的尺寸、材质、细节和纹理是否真的被资料支持。例：“DETAIL01需要展示穗头纤维，但这张图放大后看不清。是否有同款清晰近拍，还是改用现有素材可辨认的穗头轮廓？”补图请求另在聊天发送；不能把“增强清晰度”当作补造纤维的授权。

先按实际画面识别完整商品图、局部特写、测量资料和版式参考；上传顺序不能证明图片角色。用真实文件名加可见特征定位，先在聊天展示对应图片或已有预览，再弹框询问歧义。例如：“这张只看到顶部叶片的照片，是整件商品，还是同一商品的局部放大？”若有多种合理解释，提供具体选项并允许自由回答，不预填事实答案。多项歧义按依赖关系逐轮解决，不要求用户重新排序全部附件。

尺寸还需确认对象、端点与状态，例如“这个高度是盆底至最高叶尖，还是仅植株部分？”用户回答可以澄清归属，但不能补造未提供的测量值。已有照片/文字明确回答的内容直接记录；确实缺图或测量资料时在聊天请求最小补充。歧义未解决前继续其他研究，暂不定稿受影响图的提示词。

散枝插入载体时，仅知道总长还不够：若当前画面取决于穗/花/叶主体与下部裸茎的分配，弹框问主体从哪里量到哪里、多长，下部茎是否可剪、拟展示原长还是已剪状态。不要以“17英寸”代替穗长，不拿特写估出主体实测值。容器为设计道具可选择并标明外高/有效内深；随货或用户指定容器缺关键尺寸时先问。先做[分段和插入计算](scale-and-composition.md#散枝入载体分段计算)，再选短盆、长瓶和镜头。

附件包含多颜色/不同造型或拟使用多个载体时，依[组合澄清](arrangement-composition.md)确认售卖关系与逐载体内容。用户未明确“各瓶单一”还是“每瓶混放”时直接弹框，不自动把全部上传图混成一束。先解决身份，再问载体数量/分配等会改变当前图的项；已回答的项不重问。

## 引导路径：按信息价值选下一个问题

| 阶段 | 要弄清的决策 | 可用问法 | 改变什么 |
| --- | --- | --- | --- |
| 售卖事实 | 产品类型、SKU、实际包含物 | “照片里有黑色育苗盆和白色装饰盆，买家实际收到哪一个？” | 主图、场景、清单、身份锁 |
| 当前目标 | 新品首套、低点击、低转化、误购退货 | “这次最先要解决的是没人点进来、点进来不买，还是买回去发现不适合？” | 排序与验证指标 |
| 使用情境 | 谁在何时何地购买 | “最典型用途是填补客厅空角、桌面装饰，还是门廊陈列？” | 场景与需求入口 |
| 购买任务 | 买家想完成什么变化 | “买家最想解决空荡感、日常养护麻烦，还是找不到合适尺寸？” | JTBD 与主张 |
| 替代选择 | 活植/仿真/不装饰/其他尺寸 | “他们现在可能选哪种替代方案？你的产品有哪一点能用资料证明更适合？” | 差异与证据需求 |
| 犹豫点 | 最影响购买或退货的未知 | “根据这些评论，外观真假感和实际大小都重要，哪个与你的产品更相关？” | 副图前后顺序 |
| 可信边界 | 证据与反证 | “户外场景会暗示耐候；目前有耐候资料，还是先限定室内使用？” | 删除或收窄主张 |
| 视觉方向 | 场景、品牌、信息密度 | 给两个与任务相关的方向，如“真实家居尺度”与“近距离材质细节”，说明取舍 | 视觉锁 |
| 场景分配 | 四张SCENE的类型张数及资产映射 | “4张如何分配单场景、四宫格、安装/使用/维护、对比？各类可为0，合计4张。” | SCENE01–04的任务与骨架 |
| 场景像素 | 每张SCENE固定1:1下的方图像素 | “SCENE02为四宫格场景，请选1600×1600、2000×2000或2048×2048。” | 本张画布与信息密度 |
| 基础文案 | 用户提供后润色或委托AI生成 | “可填写本批中文/英文基础文案；提交空白或回复AI生成，就按已核事实生成。” | 原文、锁定词与最终英文 |
| 字体偏好 | 共用字体及逐图例外 | 先给“AI选择 / Apple风格 / 查看其他基础字体”，需要时展开或接收自定义规范 | 字族、层级和风格锁 |
| 生产条件 | 文件规格、A+权限与槽位 | “当前选中的 A+ 模块包含哪些图片槽位？可发模块要求截图。” | 提示词就绪状态 |

真实植物重点确认发货时的高度范围、是否含盆、花期/休眠状态与可承诺的到货状态。仿真植物重点确认展开前后、总高度是否含盆、枝干是否可弯、材料与室内/户外证据。用户没有提供依据时，不把以上所有项都变成必须填写的表单；只追问影响当前图的项。

场景拓展由技能主动完成，不把“请给四个场景/五个节日”当作必要输入。默认欧美住宅、美国站优先美国家居，用户明确的地区/文化/产品用途优先；记录为默认设计选择而非买家研究结论。先结合竞品和库建立具体候选，再弹框问会改变布局的选择。等待回答时继续未受影响草案；依赖待选布局的prompt不定稿。用户说“仅做测试，规格你决定”时选定并标注测试规格，账户上传仍待核对，不重复询问同一问题。

当前规格分开处理：DIM01/DETAIL01默认1600×1600，五张A+桌面图默认1464×600，无需重复询问这些默认值。**SCENE01–04固定1:1；相关prompt前，必须弹窗落实四类张数分配，以及每张1600×1600、2000×2000或2048×2048的方图像素选择**；已明确回答或明确委托的项直接记录。不要再问SCENE横版/竖版/宽高比。A+采用场景、步骤或对比结构仍沿用A+规则，不纳入四张SCENE分配，也不自动改成方图。账号未核时区分制作画布与上传状态。若候选任务单一，先做适度的公开灵感检索，给出与商品适配的不同任务，而非继续让用户提供房间/季节/道具名单。

## 文案、字体与四类场景的前置选择

写出相关最终Brief/prompt前，读取[文案与字体](copy-typography.md)和[四类场景](scene-types.md)。先在聊天说明本轮资产、任务和可见参考，再用当前模式可用弹窗收集决定；工具不可用时在聊天问同样问题，不绕过必要选择。

文案先给整套或本批输入机会，用户可提供中文/英文、指定资产或共用内容，AI在保留原意和锁定词的前提下修饰语法和自然度。用户实际提交空白、回复“AI生成/跳过填写”或已有明确委托，才把覆盖范围内文案记为AI生成；“无字”另记，不等于空白。字体先提供基础预设菜单，用户选择优先于内置艺术字默认；实际提交未选或明确跳过才委托AI。**尚未回复、仅有预选项、关闭或超时仍为pending，不能冒充提交空白/跳过。** 产品主张、锁定词或未覆盖资产有歧义时继续弹窗，不通过润色新增事实。

场景先落实四类在4张中的张数分配，合计必须为4，再映射SCENE01–04并逐图选择方图像素。随后按类型细问：单场景的单一空间与使用任务；四宫格各格不同风格/场所、顺序和对应产品；安装/使用/维护的真实动作、步骤和依据；对比图的对比轴、两侧条件、分割及事实含义。四宫格仍是一张资产，四步安装也不等于四种风格场景。任何会改变内容、布局或含义的未知项均继续逐轮询问，不设澄清轮数上限；已答项跳过。AI可推荐设计，不能代编商品的使用方法、耐候性能或功能状态。

## 信息足够时收束

用简短摘要展示：卖给谁；在哪种情境完成什么任务；第一卖点与支持证据；前三个购买障碍；不承诺什么；竞品实际观察与推荐视觉方向；尺寸图、细节图、四张场景资产和五张 A+ 图的各自任务，以及已选场景类型/像素、文案来源与字体偏好。

随后用[整套图弹框流程](set-layout-dialogue.md)提出具体布局选择，例如尺寸图采用哪张竞品的全貌/细节分区、细节图用几窗、SCENE各类型的逐格/步骤/对比内容、五张A+按什么版式序列。不是只问“是否同意整体方向”。确认文案输入与字体选择、场景类型分配和逐图方图像素已落实或有覆盖对应项的明确委托；已表达相同选择不重问。用户要求跳过讨论时按推荐交付并记录委托范围，产品事实与功能依据仍不能由委托补造。
