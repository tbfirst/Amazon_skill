# 三类参考图与提示词适配

内置图或混合路线读取。用户分类：`previews/assets/Aplus/`为A+（64张）、`dimensions/`为尺寸与细节设计图（14张）、`collected/`为场景方向（60张）。以实时本地可用性为准。目录是设计候选池，不是商品事实或目标画布；图片可用性与模板质量分别记录；缺图模板可按已审核文字使用，不自动恢复图片字节。

先检索资产对应类别，展示少量候选，打开最终入选全图，再读取分支。search/show只返回文字和路径，不代表看图。记录实际看见的属性与本图保留/调整项，不让生成器临时选版式。

```powershell
python -X utf8 scripts/library_catalog.py search --kind image --design-group dimensions-details --available-only --limit 14
python -X utf8 scripts/library_catalog.py show IMG-880f4592b15af043 --asset-role DIM01
python -X utf8 scripts/library_catalog.py show IMG-880f4592b15af043 --asset-role DETAIL01
python -X utf8 scripts/library_catalog.py search --kind recipe --design-group aplus --available-only --limit 5
python -X utf8 scripts/library_catalog.py search --kind image --design-group scenes --available-only --limit 6
```

两张可共享字族、配色和图形语言，但回答不同问题：DIM01主讲“多大、量哪里”，DETAIL01主讲“实际部位怎样”。不机械复制后只改标题，也不强制选不同模板。白底、深底、彩色标题和标签卡都是可选方向；参考配色不改变商品颜色。尺寸箭头不把整体值挂到局部；窗口数、支持视图和事实条件先解决。

14张已逐张打开；骨架和28个独立英文角色分支的维护源为`assets/reference-library/classified-layouts.json`。最终项目落实准确区块、间距、字体和文案，数字/数量/材质/性能来自SKU。默认1600×1600，不照搬源图像素。

## 场景：按任务和真实画面使用

`collected/`也有近拍、细节栏及数量/功能图；目录不把它们变为纯单景。结合历史图类、看图和已选SCENE类型判断用途；尺寸/细节的主要版式入口仍为dimensions-details。

- 门廊/台阶：IMG-acd8f482f2f0a6b5、IMG-6bc344ab57d2809d。逐容器核算数量、插入深度和尺度，写台阶纵深、光影与替代/同时陈列关系。
- 窗箱/栏杆/吊篮：IMG-1d823fe99cb881a3、IMG-10bf1ac26aae5b7d。明确容器售卖角色、支撑/挂点、侧向透视和建筑层次，悬挂物没有地面接触影。
- 室内/窗边：IMG-4b8cbe219b216f03、IMG-5bab4f4015af2e8c。解决装饰体、裸茎和容器几何；侧光/背光/窗影落在对应承接面，不套同一瓶。
- 暮色暖冷光：IMG-2a55e0ba7b0f4669、IMG-af2f37fe6f13da1a。无灯产品由外光照亮，不继承灯树自发光或功能。
- 多景用途：IMG-18d6a1bc0a626ec2。逐格场所/商品/机位/光/标签；源图四用途不替用户决定SCENE分配。

SCENE01–04各固定1:1并落实已选方图像素；内部拼版不改变整图规格或11图预算。跨品类可借建筑、字区和光影，必须替换身份与支撑。图库供agent分析与用户选择方向，是否送入生成工具按本张附件清单记录。

场景与A+通过`show IMG-ID`直接返回该图的`planningTemplate`；也可显式指定`--asset-role SCENE|APLUS`。129张（含5条外部回查文字分支）的可见布局维护于`reviewed-layouts.json`，与14张尺寸参考分开维护。卡片只保留跳转关系，A+组只保留逐图索引；无默认全组构图。精确光位、坐标、镜头、材质及性能不能由总览推定。

## 分类维护

移图/删图后运行`python -B -X utf8 scripts/refresh_local_library.py`，再用`--check`核对。按哈希修复配图、卡片、图序和索引；已删图失去本地可用标记，已审核的文字布局及独立模板继续保留，套图缺口照实记录。不下载、删除、恢复图片，不自动放行未知新图。

`selection.json`记录允许的图片哈希与分类路径；维护者源库重建也遵守该范围，不凭历史系列装回已删图。新图先视觉收录再更新选择。优化技能时用的标注示例不作为运行图库或生成附件。

独立模板可用`search --kind template --query "逆光"`或`show FUSION-06`读取；无内置图不代表模板不可用。依据质量审核与具体任务选择，配图仅在实际存在时展示。
