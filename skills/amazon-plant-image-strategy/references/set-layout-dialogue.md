# 整套图拆解、弹框与版式落地

在竞品视觉轮完成后、最终 Brief 和提示词之前使用。目标是让用户选到具体可复现的排版，而不是只确认“高级、自然、统一”。本环节是设计共创，不是发布或执行许可。

## 先看整套，再比较单图

按竞品分别建立图库与 A+ 的**有序图谱**：实际图序/区域、V-ID、图的任务、版式、文字密度、主体/背景关系、光影、跨图共同规则。沿实际缩略图打开大图，包括更多图片；缩略图网格（例如用户截图右侧红框）只是套图入口，不能代替逐图查看，也不能据此推断当前未打开图的内容。A+ 页面模块布局与一张位图内部排版分开。

把每套的重复规则与变化节奏写入 `design-strategy.md`：如相同标题/边距/强调色，尺寸图全貌加细节窗，单场景与拼版交替。图库图数、A+ 图数按实读记录，不要求竞品恰好也是11张。可访问视觉轮完成且有具体方案即可弹框，不必等受限评论区恢复。图库缺失时标明范围，不说“整套已读完”。

当前竞品采集/浏览合理恢复后仍失败时，按[套图回退](reference-library.md#套图查找与竞品失败回退)检索内置SET、打开可用原图，展示2–3个具体历史方案后弹框。可以选择整套节奏，也可以混用明确来源的单图结构；逐图确认和素材角色/尺寸绑定照常进行。无适配库图时提出原创候选并说明缺口，不能用不兼容商品或退役线框强行补位。

## 用可核对的方案提问

先展示简短对照表/可访问的参考图链接：方案简称、竞品 ASIN＋具体图序/V-ID 或 `LIB-卡片ID`、可借的结构、适配我方的调整和缺口。在 `layout-decisions.md` 记录11张资产的候选和待选状态。**先分析再问**，不要让用户自己重看全部竞品、寻找模板或提供四个场景。

有 `request_user_input_async` 等当前模式可用的文字弹框工具时，用它询问，每题2–3个具体方案，首项为推荐，支持用户自由输入。没有可用弹框时在当前聊天问同样的短问题并如实说明方式；不要调用仅限 Plan 模式的工具。附件请求仍在聊天中提出。弹框本身不显示参考图时，先在聊天展示图/链接，再以短标签对应。

下面是讨论主题，不是限制为两批完成。默认通过多轮短弹框逐步讨论，按用户回答继续追问，直到每张图的必要选择明确或被用户明确委托：

1. **尺寸图与细节图**：分别选择明确的骨架。例：“DIM01 建议采用竞品A图库第2张的左全貌＋右两圆窗；也可选 LIB-DIM-06 的绿色分栏＋三矩形细节。你希望采用哪一种？”选项应是本轮真正观察过的来源；这段只是问法示例，不能当作新项目观察。
2. **四场景与五张A+**：四场景可作为一组比较“单幅实景为主”与“部分拼版”，明确哪些资产变化；五张A+作为一组比较有序版式序列，如“全幅横幅→左右分区→三格近拍→用途组合→规格区”。一次组选择仍须列出每张的具体结构，不让生成器自行决定五张排版。

每批只问当前能改变设计的1–2个问题，批次可以很多。默认覆盖DIM01、DETAIL01、四张SCENE和五张APLUS的逐张实现；组级选择不能自动确认组内尚未展示的布局。先讨论整体骨架，再按需要询问全貌位置与大小、特写数量/形状、文字层级、尺寸标注、背景/道具、光影或A+叙事顺序；不要求每张机械问遍所有字段。两种选项只换滤镜不算有效骨架选择，颜色和光影则可在骨架明确后单独讨论。不要对每张无差异地重复问“是否同意”。已明确的决定（含用户选图、指定模板、明确授权自行选）直接记录，跳过对应弹框。

例如先选DIM01“左侧全貌＋右侧局部窗”或“居中全貌＋四周尺寸线”，回答后再问是否保留局部窗、具体展示哪个部位、尺寸线对应哪些已确认端点。先展示来源图/线框和推荐理由，再弹框；全貌/局部身份有歧义时先按[素材澄清](discovery.md#素材歧义先澄清)解决，不能让版式选择代替产品事实核实。这里是问法示例，不是要求每个项目使用这些骨架。

等待未答选择时继续整理证据、图库候选、文案和未受影响资产；**不能因等待超时把推荐项写成用户已选，或定稿依赖该选择的提示词**。用户说“你决定/直接出稿/跳过询问”则采用有理由的推荐并记 `delegated`；要立即草案又未决的项标 `proposed`。不重复询问已固定的图数与像素。

## 锁定与传递

`layout-decisions.md` 每资产一行，固定11个ID，至少记录：

|字段|内容|
|---|---|
|来源|主结构的竞品V-ID/图序或LIB-ID；辅助来源分别写，不混成无法定位的“参考竞品”|
|观察范围|大图已看/仅缩略图/仅模板文字/示意图；实际日期与定位|
|状态|pending / confirmed / delegated / proposed；用户回答或委托依据|
|骨架|画布比例、分区数量/顺序/位置、全貌/特写窗数量与形状、产品和文字区、尺寸线、阅读路线|
|套图规则|共用标题字族/层级、边距、色板、圆角/描边与标注风格；本图允许的变化|
|适配|真实SKU/比例/素材/文案的调整；不借用参考商品、件数、品牌、宣称|
|未决细项|具体问题、受影响资产/区域、待答状态；整体方向confirmed不能覆盖仍pending的细项|

确定骨架后，将它作为本张的 `LAYOUT BLUEPRINT` 完整写入 Brief 与英文 prompt：具体分区坐标或比例、安全区、主次比例、文字层级/行数、细节窗和连线规则。所有百分比是我方设计目标。改尺寸或减少证据不足的窗格时更新决定记录，不能为了填版虚构视角、测量或部件。

追溯链必须完整：**实际观察/模板 → 用户选择或委托 → 11张版式表 → Brief → 单张TXT → 总提示词汇总**。若无可用来源，提出原创骨架并标原创。目标是接近参考套图的信息组织与视觉节奏，使用我方商品与原创文案/场景；不能只输出相似摄影氛围，也不能承诺提示词必然生成同等效果。

成图后才能核对：分区/窗格数与位置、文字区与层级、完整商品/尺度、套图色板和节奏。当前技能只交付规划，不自动生成验收图。
