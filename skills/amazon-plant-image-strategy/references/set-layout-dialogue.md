# 整套图拆解、弹框与版式落地

适用模式：下文固定11图、4张SCENE和5张A+均为`new-set`默认。`set-refresh`先按[旧套图更新](set-refresh.md)记录的目标清单执行，SCENE数量为N、A+为M；类型分配合计N，没有该角色则不追加或强问。已明确的选择与规格沿用，角色/数量/画布有歧义时才澄清。

在竞品视觉轮完成后、最终 Brief 和提示词之前使用。先确定提示词参考路线，再讨论具体可复现的排版；同时落实[文案输入与字体](copy-typography.md)和[四类场景分配与方图尺寸](scene-types.md)的必要选择。本环节是设计共创，不是发布或执行许可。

旧套图更新先明确：默认重做旧设计；已指定竞品时不重问参考路线。在实际来源展示后，直接让用户选择“完整继承竞品画面，只替换产品/文案/指定配色”或“保留排版结构，重新设计场景与风格”，按[参考继承强度](reference-fidelity.md#先确定继承强度再应用设计默认)记录`designTransferMode`、覆盖资产和逐图例外。来源未定先选来源，强度未定再问强度，已有明确表达就复用。模式选择可以一次覆盖整套，但不替代未展示的逐图来源、不确认未知产品事实；之后只追问会改变该方向的未决细项，不能再次用通用风格菜单把已选来源改走样。

## 先看整套，再比较单图

按竞品分别建立图库与 A+ 的**有序图谱**：实际图序/区域、V-ID、图的任务、版式、文字密度、主体/背景关系、光影、跨图共同规则。沿实际缩略图打开大图，包括更多图片；缩略图网格（例如用户截图右侧红框）只是套图入口，不能代替逐图查看，也不能据此推断当前未打开图的内容。A+ 页面模块布局与一张位图内部排版分开。

把每套的重复规则与变化节奏写入 `design-strategy.md`：如相同标题/边距/强调色，尺寸图全貌加细节窗，单场景与拼版交替。图库图数、A+ 图数按实读记录，不要求竞品恰好也是11张。可访问视觉轮完成且有具体方案即可弹框，不必等受限评论区恢复。图库缺失时标明范围，不说“整套已读完”。

当前竞品采集/浏览合理恢复后仍失败时，按[套图回退](reference-library.md#可选外部库与研究回退)检索内置SET、打开可用原图，展示2–3个具体历史方案后弹框。可以选择整套节奏，也可以混用明确来源的单图结构；逐图确认和素材角色/尺寸绑定照常进行。无适配库图时提出原创候选并说明缺口，不能用不兼容商品或退役线框强行补位。

## 先弹窗选择提示词参考路线

若用户已要求按竞品更新旧套图，路线已选为competitor-derived，不重复问三选一；只解决具体主套图/主辅分配。其他情况下，实际读取到竞品有序图库及可访问A+后、细化目标布局前发起路线选择。不必等待受限评论恢复；下载成功、缩略图盘点不等于套图已读。先展示刚读套图的概览/代表图与ASIN、变体、图序、图库和A+覆盖情况。只读到图库或部分A+时如实标范围，不能把未读内容包装成完整套图；已有材料仍可用于明确受限的路线选择。

弹窗一题提供以下三个有实质差别的选项，按SKU适配给出推荐并允许自由输入：

| 选项 | 提示词从哪里来 | 下一步 |
| --- | --- | --- |
| 刚抓取的竞品套图 | 基于本轮已目视的具体套图，逐图反推版式、标题层级、场景、明暗、光向、阴影及整套节奏 | 若有多套，进一步选主要ASIN/套图；逐资产映射源图，追求信息组织和视觉风格接近 |
| 内置套图提示词 | 检索兼容的SET/配方及所选图的实际promptVariant，以其为设计主线 | 展示真实可用离线/已获取参考图并选择具体套图；竞品研究继续提供购买任务和异议洞察 |
| 明确混合 | 由用户选择或委托，将竞品与内置来源分配到具体资产/组 | 指定整套主线和各图来源，不随机拼接互相冲突的字体、色板与结构 |

示例问题：“已读取以上竞品套图。这次11张图希望主要按哪条路线规划提示词：A按刚抓取的套图反推、B选内置套图提示词、C指定混合？”只说明实际可用方案；没有可查看库图时明确文字模板路线暂无预览，不展示坏链接或把未缓存远程图当已可用。无适配模板时说明并给已有证据的替代，不凑出虚假套图。

路线选择不等于具体套图选择。多套已读竞品中，若用户尚未指定主ASIN/变体/套图，先展示各套实际预览和差异，再弹窗问“本轮具体跟随哪套？A［ASIN/变体］的布局和光影；B［ASIN/变体］；C明确分配主辅来源”。选项填真实来源，不只写品牌简称或抽象“信息型/氛围型”。已有确切选择或委托不重问。默认对所选套图做结构接近的适配；宽松灵感路线须有相应选择，不能悄悄降级。逐图执行[参考迁移约定](reference-fidelity.md)，包括真实参考附件、保留项、必要改动和对照检查。

选择竞品路线后，先分析该套图再写当前SKU的独立提示词，不用库默认模板悄悄覆盖它。保留布局/阅读顺序、主次/留白、标题表现、配色与跨图变化；实际商品、尺寸、数量、材质和品牌仍来自我方资料，文案原创。竞品的主图或额外资产只供研究，仍映射到已约定1+1+4+5范围，不复制其总图数或承诺像素一致。缺对应图位时标原创适配或经确认的辅助来源。

选择内置路线后，先锁定具体套图/逐图分支，再做我方事实替换与版式细化，不让用户自己翻全库。用户已明确指定路线/具体套图或明确委托则记录依据并跳过重复提问；沉默和弹窗超时不代表选择。等待时继续研究和证据整理，不定稿依赖待选路线的提示词。无弹窗工具才在聊天问同样问题。所有路线仍交付规划和提示词，不自动打开生成工具。

在`discovery.md`与`layout-decisions.md`记录`reference-route: competitor-derived | library-template | hybrid | original`、confirmed/delegated/pending、用户原答/委托、主套图、覆盖范围及各资产来源。`original`仅用于用户明确选择原创或无可用参考后的说明，不作为绕过弹窗的静默默认。

## 用可核对的方案提问

讨论室外A+时，可先从[已审核套图](curated-source-sets.md)展示2–3套匹配产品与支撑的真实样图，弹窗选择具体ASIN/变体/图序，再读对应逐图分支。室外A+不占用四张SCENE预算；同样保持五张A+总数和默认横幅规格。不要因为A+示例偏室内就自动把已选门廊或庭院改成客厅。

文字优化按[文案润色](copy-typography.md)与[八种文字布局](text-layouts.md)进行：在本图骨架内给2–3个具体文字区方案或直接执行已有选择/委托。基础输入、字体与布局回答可在同一工作流复用；不为每次语法修正再弹窗。只有锁定词、含义/事实或未定布局改变时问该项；用户若明确要更多精修轮次，再围绕具体差异继续。

用户偏好室外或候选偏室内时，从[室外扩展](outdoor-scenes.md)筛选适配SKU的2–3个具体方向进入本轮弹窗，可按回答继续换选。OUT系列已退役，不再检索或推荐；需要原创补充时明确标为设计建议，不伪造参考图或竞品来源；用户已选竞品路线时仍以竞品为主，原创补充需符合已授权参考路线。实际项目继续询问类型分配、逐图方图像素、文案和字体；维护技能时不要求用户回答未来商品问卷。

先展示简短对照表/可访问的参考图链接：方案简称、竞品 ASIN＋具体图序/V-ID 或 `LIB-卡片ID`、可借的结构、适配我方的调整和缺口。在 `layout-decisions.md` 记录11张资产的候选和待选状态。**先分析再问**，不要让用户自己重看全部竞品、寻找模板或提供四个场景。

有当前模式实际可用的文字弹框工具时，用它询问，每题2–3个具体方案，首项为推荐，支持用户自由输入；未知事实和基础文案可用自由输入。没有可用弹框时在当前聊天问同样的短问题并如实说明方式；不要调用仅限 Plan 模式或当前不可用的工具。附件请求仍在聊天中提出。弹框本身不显示参考图时，先在聊天展示图/链接，再以短标签对应。

下面是讨论主题，不是限制为两批完成。默认通过多轮短弹框逐步讨论，按用户回答继续追问，直到每张图的必要选择明确或被用户明确委托：

1. **尺寸图与细节图**：分别选择明确的骨架。例：“DIM01 建议采用竞品A图库第2张的左全貌＋右两圆窗；也可选 LIB-DIM-06 的绿色分栏＋三矩形细节。你希望采用哪一种？”选项应是本轮真正观察过的来源；这段只是问法示例，不能当作新项目观察。
2. **四类场景的张数分配**：按[四类场景](scene-types.md)先展示有依据的建议，再弹窗问4张SCENE在单场景、四宫格场景、安装/使用/维护图、对比图之间各占几张。各类可为0，合计必须为4，不默认四类各一张；比例不能映射为4张整数时继续澄清。记录SCENE01–04的类型与各自新增任务。
3. **每张SCENE的方图像素与类型细项**：SCENE01–04固定1:1，不再问横竖版或宽高比；相关prompt前逐资产弹窗选1600×1600、2000×2000或2048×2048，问题包含本张ID、类型与任务。已有逐图回答或明确覆盖这些资产的像素委托则不重问。再按类型问单场景空间/摆放、四宫格各格不同风格与顺序、安装真实操作与步骤依据、对比变量/条件/分割；整图像素、小格比例和商品画面占比不混为一谈。
4. **五张A+**：作为一组比较有序版式序列，如“全幅横幅→左右分区→三格近拍→用途组合→规格区”。一次组选择仍须列出每张的具体结构，不让生成器自行决定五张排版。采用场景、步骤或对比结构仍按A+默认1464×600或明确图位覆盖处理，不纳入4张SCENE分配，不自动变方图或增加图数。
5. **逐图是否要文案**：每张资产单独弹窗确认无字、短标题或信息标注，可同批多题；记录资产ID与实际回答。不能用整体风格、AI润色授权或推荐项代替。确认无字才跳过填写与字体问答，必要参数与无字冲突按[文案规则](copy-typography.md)澄清。
6. **基础文案与字体**：按[文案与字体](copy-typography.md)先给整套/本批基础文案输入机会，再只补问未覆盖或特有标签；有输入则保留原意修饰，实际提交空白或明确AI生成才委托。字体先展示AI、Apple风格及其他基础字体入口，用户明确选择的字族优先；实际提交未选或明确跳过才让AI匹配。字号、字重、行数、颜色与排版可参考已选模板和内置规则，不因选字体再强制重问已确定项。

每批只问当前能改变设计的1–2个问题，批次可以很多。默认覆盖DIM01、DETAIL01、四张SCENE和五张APLUS的逐张实现；组级选择不能自动确认组内尚未展示的布局。先讨论整体骨架，再按需要询问全貌位置与大小、特写数量/形状、文字层级、尺寸标注、背景/道具、光影或A+叙事顺序；不要求每张机械问遍所有字段，但任何影响结果的场景、步骤、对比或文字歧义均继续弹窗，直到明确或被有效委托，不设澄清轮数上限。两种选项只换滤镜不算有效骨架选择，颜色和光影则可在骨架明确后单独讨论。不要对每张无差异地重复问“是否同意”。已明确的决定（含用户选图、指定模板、明确授权自行选）直接记录，跳过对应弹框。

例如先选DIM01“左侧全貌＋右侧局部窗”或“居中全貌＋四周尺寸线”，回答后再问是否保留局部窗、具体展示哪个部位、尺寸线对应哪些已确认端点。先展示来源图/线框和推荐理由，再弹框；全貌/局部身份有歧义时先按[素材澄清](discovery.md#素材歧义先澄清)解决，不能让版式选择代替产品事实核实。这里是问法示例，不是要求每个项目使用这些骨架。

等待未答选择时继续整理证据、图库候选、文案和未受影响资产；**不能因等待超时把推荐项写成用户已选，或定稿依赖该选择的提示词**。文案实际提交空白/明确AI生成、字体实际提交未选/明确跳过可按[专门规则](copy-typography.md)记为委托；尚未回复、仅预选或关闭仍是`pending`，这项空白规则不适用于未知事实或场景分配/像素。用户说“你决定/直接出稿/跳过询问”则按实际覆盖范围采用有理由的推荐并记 `delegated`；要立即草案又未决的项标 `proposed`。不重复询问固定11张总数、SCENE的1:1、DIM01/DETAIL01的1600×1600或A+的1464×600默认值；SCENE类型分配和逐图方图像素必须已答或有明确委托，不能被默认像素规则跳过。

## 锁定与传递

涉及多个颜色/产品或多个载体的资产，先按[组合澄清](arrangement-composition.md)弹框解决未明的售卖关系、单一/混放规则和逐载体分配，再确认容器与构图。组合选择与版式选择分别记录；“三格替代用途”不能偷换成“同一场景三瓶同时陈列”。每个载体以[分段尺度](scale-and-composition.md#散枝入载体分段计算)验证内容物与有效内深，不能仅因参考图好看选不匹配的矮盆。

确定骨架后，将它作为本张的 `LAYOUT BLUEPRINT` 完整写入 Brief 与英文 prompt：具体分区坐标或比例、安全区、主次比例、文字层级/行数、细节窗和连线规则；场景图逐格写完已选风格/步骤/对比条件。`OUTPUT`写本张实际像素和比例，文案与字体复述本张最终方向，不让生成器再挑选方案。所有百分比是我方设计目标。四宫格仍在同一prompt内，不拆成额外资产；画布像素不改变商品实物比例。改尺寸或减少证据不足的窗格时更新决定记录，不能为了填版虚构视角、测量或部件。

追溯链必须完整：**实际观察/模板 → 用户选择或委托 → 11张版式表 → Brief → 单张TXT → 总提示词汇总**。若无可用来源，提出原创骨架并标原创。目标是接近参考套图的信息组织与视觉节奏，使用我方商品与原创文案/场景；不能只输出相似摄影氛围，也不能承诺提示词必然生成同等效果。

成图后才能核对：分区/窗格数与位置、文字区与层级、完整商品/尺度、套图色板和节奏。当前技能只交付规划，不自动生成验收图。
