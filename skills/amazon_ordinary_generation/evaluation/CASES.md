# 行为验收案例

以下以真实决策结果为验收点，不按固定措辞评分。工具故障可以保留coverage缺口，不能伪造事实使案例通过。

|请求/原始条件|应观察到的结果|
|---|---|
|“相框8×10，只有正面照，按竞品出11张，其他你定”|确认8×10含义；不虚构外框或背架；可推进正面外观与研究，依赖尺寸/背架的图blocked；设计委托覆盖风格但不补造事实|
|“挂钩是胶贴的，照TikTok钉式挂钩教程做安装图”|识别机制冲突，保留构图灵感时替换为本品有据动作；不画锤击胶钩，不照搬无痕/承重|
|“这张卡套主图，做RFID防盗卖点”，无相关证明|先区分卡套类型；不声称RFID或用阻挡电波画面暗示已证功能；可用结构/已支持任务替代|
|“狗笼外部36英寸，放一只大狗突出空间”|不把外尺寸当净空，不缩小狗；未有内部空间及适配依据的图阻塞或改空笼外尺寸展示|
|三个竞品gallery可看，A+一份失败，评论列表登录但页面内有4条评论|逐区段记录partial/blocked；保留可读4条并去重；不写全站无评论、20条样本或“普遍差评”|
|YouTube只有字幕，TikTok只有Shop文字|标text-only/shop-text；不伪造关键帧、时间戳或“已观看”；文字启发的构图标D提案|
|用户上传多颜色主图，没说混色销售|逐文件映射变体；不默认混装/同场景全包叠加；只问依赖组合事实|
|“旧5张图改竞品风格，保留产品，全部设计你定”|set-refresh targetAssetIds为实际5张，旧→新与参考→新分别记录，不扩为11；改布局而非仅滤镜|
|只上传主图和尺寸图，未提重做主图|默认11张附图/A+且无MAIN，主图作为identity；不要求用户先做成品附图|
|已选四张场景2048，全部无字，其余自定|复用回答，不重复问该范围；SCENE无新增字且商品原有印字保留，A+等其他ID文字决定按委托范围处理|
|用户没答文案弹窗；A+模块不知|未答不算空白授权；相关文案选择pending，A+可出注明图位待核的PROVISIONAL，不能据此编造商品事实|
|花环为售卖主体，挂钩只是布景道具|路由植物套图skill；空挂钩以绿植作使用道具则本skill，避免双重生成|
|一张A+拟用4图模块但仅剩2资产|调整模块/预算分配或说明新增需求，不把5张资产膨胀成5组多图|
|编译含READY、PROVISIONAL与BLOCKED|两份合集包含前两者的原文与条件；BLOCKED只列缺口，缺引用、重复ID、范围错均失败|

## 跨类目与未知商品回归

|请求/原始条件|应观察到的结果|
|---|---|
|四件装棉枕套，50×75cm为平铺尺寸，无填充物，只有正反照，“设计你定”|记录已确认事实不重问，使用柔性/数量模块；可推进平铺规格和可见表面；填充物若作道具说明不含，不要求安装或把平铺尺寸当蓬松尺寸；有设计委托不逐项再次求批|
|1米USB-C线，只有包装和接口照片，要求“100W、适配所有手机”|图片策划属于本skill；接口外形不证明协议/功率，阻塞或删除相应暗示；长度、可见接口和已证售卖内容能独立推进，不把全套都锁到性能补证|
|120枚白色圆贴，直径30mm，只有整版扫描图，要办公与礼物使用|先区分单枚数量与整版张数，保留已知直径，不虚构背胶/耐水/贴附效果；扫描图支持图案和正面，曲面粘贴/揭背等动作需相应证据；不问内部机械结构|
|印花保温杯，带盖与吸管，花卉图案，24小时话术未有对应依据|路由非植物；刚性容器、印刷、随货附件组合判断；容量与净含量不能混用，蒸汽/雪花不能暗示已证24小时性能；其余外观/内容图局部推进|
|密封瓶补充装，只见包装，净含量已核，用户委托全部布局|可把DIM调整为已核净含量/销售规格，保留ID并记录roleAdaptation；不捏造容器尺寸、液体颜色/配方，包装可以成为主体；不强要与当前图无关的内部照片|
|未知新商品，用户解释其功能和提供清楚资料，但名称从未列入skill|由用途、物理形态、接触对象和销售单位组合模块；无须改skill或让用户列全类目，按当前任务继续|
|带照明的织物收纳包|柔性、外形/图案、电源连接等模块可组合，不能只因选软体分支就丢失电池/接口条件；没有安装动作就不强加安装图|
|拉链压缩袋想照抽真空袋视频画同样动作|记functional-adjacent，不能凑直接竞品；可借“收纳更紧凑”的信息任务，不能带入泵、阀或任意压缩百分比|
|一件小饰品只有清晰正面，计划无参照的隔离外观图|按可见外观与源图比例推进，不把家具尺寸、电压、承载、背面结构当所有图必填；需要新增佩戴/尺寸暗示的图再触发相应补证|

新增脚本需运行成功与失败fixture，尤其精确保留原文和阻塞隔离。技能语法校验不证明行为全通过；真实SKU/生图效果应单独记录验证范围。
