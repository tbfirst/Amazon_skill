# 项目媒体存储与缓存复用

竞品图片属于项目研究材料，不属于技能程序。技能包只存规则、脚本、文本模板和小型测试样例，不新增真实竞品图片、视频、浏览器profile或下载缓存。

默认项目目录为工作区的 `outputs/<product-slug>/research/competitor-media/`，或用户明确指定的外部目录。不得解析成skill目录内部。本仓库 `/outputs/` 已被Git忽略；发布skill时仅打包skill源码目录，不递归打包项目输出。

允许在项目目录保存gallery、A+、aplusOther、品牌故事图片、截图、manifest、来源URL、哈希、实际尺寸、变体与模块序号。浏览器使用独立临时上下文，不复用私有登录资料。页面阻挡不绕过；只抓本任务ASIN及必要变体。

优先复用经过文件存在与可读性检查的缓存。已抓ASIN不代表图库完整，历史 `skipFutureCrawl` 不得阻止用户当前明确指定竞品的缺图补采；若该标记代表用户明确禁止访问则遵守禁止并报告。自动完成标记必须以区段实际覆盖为依据。旧去重表仅供迁移参考，不再把Windows固定路径当运行前提。

缓存状态区分 discovered/downloaded/visually-reviewed/reverse-analyzed。下载数不等于已看数，已看数不等于完整套图。保留上次成功结果，新采集写独立运行目录，失败不得覆盖成功记录。新运行不是绕过外部采集器的ASIN锁。

选中图片可供用户上传Lovart，提示词明确上传顺序与角色，同时完整写出布局。图片不再可用时先补采或改用完整文字蓝图，不引用不存在文件。默认保留本项目素材便于复查；不自动删除历史资料，也不自动把图片导入技能assets。用户要求清理时保留已确认需要的交付材料并按其范围执行。
