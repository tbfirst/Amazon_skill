# 通用视觉结构分析与提示词转译

用于把实际参考图的设计结构转成可执行指令，适用于单景、拼版、尺寸、细节和A+。复杂度决定分析深度，不预设场景数、分割形状、画幅、配色或字体。简单图只记录关键关系；复杂图补充决定其辨识度的几何、层次与文字细节。

## 从整体到局部，再回到整体

1. 查看整图，确定主要信息、视觉焦点、阅读顺序、疏密与留白。先描述实际看到的设计，不先挑一个熟悉模板套进去。
2. 识别有独立作用的元素与区域：商品、环境、道具、局部窗、文字、标注、装饰和效果。按作用分组；同色可能属于不同区域，不同色也可能属于同一场景。
3. 查看决定版式的局部：交接边缘、遮挡、字形、线条和材质。结合纹理连续性、透视、光照与对象关系，判断它是实物边缘、编辑分区、图形覆盖还是渐变过渡。
4. 返回整图核对这些解释是否一致。局部裁图坐标换算到整图；不凭孤立细节推断整体结构。

记录实际查看范围。看不清的属性保留为未知或少量候选解释，通过清楚原图/局部复核；仅在影响执行时询问。没有图像时只能提供设计提案，不能称为参考识别。图像中可见关系与我方设计建议分别记录，不伪造精确测量或字体识别。

## 用元素及关系描述结构

在已有layout-decisions和Brief中记录必要项。元素ID仅用于内部关联；最终词使用具体对象、位置和附件内容描述。

| 分析维度 | 需要识别与落实的内容 |
| --- | --- |
| 元素与角色 | 每个元素是什么、表达什么；主商品、道具、同款替代视图与随货件分开；局部窗取自哪个真实部位 |
| 区域与归属 | 实际区域数、嵌套关系、各自包含的内容；共享背景还是独立空间；不是所有图都有分区 |
| 几何与位置 | 主体/区域的范围、中心、方向、比例与形状；必要时给起终点、主要转折/曲率变化、圆角或重复间距；仅使用定义形状所需的锚点 |
| 边界与交接 | 裁切、描边、间隙、叠放或融合；边缘软硬、宽度、透明度与过渡范围。边界可见不等于存在一条装饰线 |
| 图层与遮挡 | 谁在谁前面、谁裁切谁、哪里允许穿出区域；区分物理遮挡与编辑遮罩，商品完整性与支撑仍须成立 |
| 对齐与节奏 | 共享基线/轴线、重复单元、间距、对称/非对称、疏密对比和留白；不能只记录独立包围框而丢失元素关系 |
| 视觉层级 | 第一焦点、次级信息和辅助内容；通过大小、位置、对比、清晰度和留白建立阅读顺序，不默认文字最大 |
| 空间与尺度 | 机位、景别、透视、前中后景、支撑与遮挡，实物尺寸及同平面参照；画面占比不等于实物尺度 |
| 配色与光影 | 色彩承担的角色、区域明度关系、商品与背景分离；光源方向/软硬、实际承影面、材质表现和焦点；不靠强撞色修补识别失败 |
| 文字与图形 | 已确认文案的准确内容、字形、排布、装饰效果及与其他元素的关系；不默认每图有字或文字必带底板 |

关系用明确动词表达：位于、包含、对齐、贴近、连接、覆盖、裁切、延续、分别归属。几何位置以整图或明确分区为基准，不能混用。先用自然语言说明结构，再按复杂度补必要坐标/比例；目测值标近似，坐标是设计目标而非模型精确执行保证。

## 找出真正值得保留的设计

从观察中选出决定该图质量与辨识度的少数关键关系，注明其作用，而非把每个背景像素都当成必须锁定的细节。判断移除或改变它，是否会损害信息清晰度、视觉平衡、参考特征或商品展示。

逐图分为：保留项、替换项、必要适配。保留项可以是几何关系、空间布置、光影逻辑或文字节奏；替换项是我方SKU、准确文案和指定配色。新商品的轮廓/数量/尺度与参考不兼容时，调整最小受影响区域并记录原因，不扭曲商品，也不无理由重做整个版式。

同一参考的成功手法不自动扩散至全套。每图依据自己的任务和来源选结构；跨图只共享有意设定的设计语言。高保真程度由用户选择、参考可用性和实际商品适配决定，不能仅靠色系相似宣称继承。

## 文字分析是独立的一层

先按逐图弹窗确认是否需要文案。无字图省略文字分析；有字图分别处理：

- 字形：衬线/无衬线/连笔、粗细反差、笔画末端、倾斜、字宽、连字、长尾与大小写。可描述可见风格，不凭低清图断言字体名。
- 排布：准确字符串和断行、主次大小、包围范围、对齐、基线方向、字距/行距及词语强调；区分靠近某形状与沿其路径排列。
- 效果与关系：字色、描边、投影和底层分别判断；文字相对图像、留白、区域边界和其他文字如何安排。全部字效避开商品保护区。

遵守用户字体选择；与参考混排冲突时说明适配。不能将有个性的文字概括为“艺术字”，也不能为复刻字形新增文案、色板或装饰效果。

## 从分析转成独立可执行提示词

按依赖顺序编写，而非照抄观察流水账：

1. 确定输出画布、实际身份/风格附件及各自作用。
2. 写明主体及必要的真实数量、结构、尺度与支撑。
3. 描述整体布局、区域归属和阅读顺序；仅有分区/多视图时展开对应关系。
4. 落实关键几何、对齐、图层、边界及前后空间，写出参考保留项和必要变化。
5. 描述各区域的实际内容、配色、光影、材质与融合要求，避免把独立空间误合并或把共享背景拆碎。
6. 按确认结果加入准确文字与排布，或明确无字；最后保留本图必要的防错条件。

每个关键分析结论要能找到对应的绘制指令。不要只写“复制参考构图”“高级感”或内部元素ID，也不把研究依据、问答状态和候选解释交给生成器选择。正式词只保留一种已定结构，长度由画面需求决定。

附件实际上传身份/风格两类参考。需要更严格结构且工具支持时，可另附布局示意或区域参考，并说明其控制范围及辅助标签不应绘制；未制作不称已附图。结构示意不替代商品实拍，亦不能保证像素级复刻。

## 分层核对与局部修订

先核对元素/区域归属与图层，再看几何位置、比例、对齐及阅读顺序，随后检查商品保真、光影质感和文字。关键关系不成立时，不能因颜色或情绪相似就通过。

核对覆盖单元素、多元素、嵌套、重复、跨区域和无文案等不同结构，不把某一种形状当通用验收模板。发现问题时定位到对应关系和指令，保留已正确部分，修改受影响项；不追加一串彼此冲突的禁令。

策略阶段只验证观察依据与指令覆盖。实际成图返回后再并排检查参考与结果，记录具体差异并修订；尚未生成不得宣称识别精度或复刻质量已验证。
