# 场景分配、方图像素与类型细项的多轮问答

在细化SCENE及场景/步骤/对比型A+前读取，按[多轮沟通循环](discovery-layout.md#多轮沟通循环)推进。new-set的SCENE为4张；set-refresh以已有targetAssetIds中的SCENE数量N为准，没有该角色就不追加或强问。四种类型是设计表达，不是固定每种一张。

## 分配之后继续问到具体内容

1. 先由商品任务、已看源图和真实用途提出2–3种适用分配，再弹窗选择`single / four-grid / installation / comparison`各占几张，各类可为0，合计N。不能把“给我四个场景”变成要求用户自行策划；技能先提供候选和理由。已有回答/明确委托直接落实。
2. 收到分配后说明它带来的结构变化，映射到具体SCENE ID与任务。用户只给无法整数映射的比例或合计不为N时，继续澄清，不自行凑数。选分配不等于已选每格内容、步骤或比较轴。
3. 对每张SCENE落实1:1下的方图像素，问题写明ID、已定类型和用途，提供1600×1600、2000×2000、2048×2048，按本图密度推荐；可接收其他明确方图像素。允许“四张都2048”等批量回答或明确委托，逐ID记入。不是每次都重问横竖比例；收到非方图要求才澄清是否明确覆盖默认。
4. 按下面类型表继续问当前图会改变结果的未决细项，每批通常1–2题。先给具体推荐，再根据回答追问；不要在类型/像素回答后直接把每格/步骤/比较条件交给生成器选择。
5. 逐图内容已定后进入[文案与字体](copy-typography.md)的独立问答；已有覆盖回答沿用。用户选择全套风格不能自动确认场景分配、像素和文字模式，明确委托则可覆盖所列项。

DIM/DETAIL默认1600×1600、A+默认1464×600，不重复问默认值。A+采用场景、四格、步骤或对比结构时，只沿用下面内容讨论，画布按A+实际规则，不纳入N张SCENE分配，也不自动扩成额外资产。

## 按类型逐步深入

|类型|先展示的具体方案|回答后继续落实的细项|事实边界|
|---|---|---|---|
|single 单场景|一个适合当前用途的场所、商品状态和全貌/近景方案|摆放/使用对象、支撑与接触、机位、是否出现人物/手部、道具及文字区；只补问未定项|不为所有商品安排住宅或室外；外观相似不等于有使用/适配依据|
|four-grid 四宫格|四格各自的不同任务/场所与左上到右下顺序|每格对应产品/状态/对象、替代用途还是同场同时使用、小格比例/边距及标签|四个滤镜或四个近拍不等于四种用途；每格数量不改变销售单元|
|installation 安装/使用/维护|当前SKU有据操作的真实先后与拟定步数|展示哪种操作、每步接触点与状态、手/工具/附件、结果、阅读顺序和说明|依据说明书、同款实拍或明确操作资料；不默认四步，不从竞品视频推导本品动作|
|comparison 对比|有据的对比目的、两侧条件与可读分割方案|变量/不变量、方向与比例、是否同地点同角度、标签是否暗示性能|优先本品真实状态/用途；不制造竞品失败、未知试验、兼容或优越性|

用户选定骨架后，若细项已含在明确展示并接受的方案内就直接记录，不为了多轮把同一内容拆开重问。用户想继续精修时围绕真实差异续问；对于已委托的配色、道具、机位微调，直接给出具体决定。

## 一段可能的续问路径

以下是假设本SKU资料确实支持四种用途的对话示例，不是所有商品的固定场景：

- 用户选“SCENE02四宫格”后，先说明这张将表现四个不同任务；展示四格用途候选，再实际弹窗问采用哪组或如何替换。
- 用户确定四格用途后，记录各格顺序；若顺序已有明确展示且用户接受，不重问。若“同时使用”会改变配套物数量或销售含义，先问该事实。
- 再落实本图方图像素（若此前已答则跳过），然后问本图是否加四个标签、是否输入基础文案或由AI拟写；有字才进入字体分支。
- 回答“标签由AI写”只解决该图文案来源，不替其他ID选择文字模式或像素。用户明确“此图所有细节你定”则立即落实，不继续强问。

顺序可随已有信息调整，轮数由真实未决事项决定。若“对比”究竟指状态展示还是性能测试、若“四格”究竟指四用途还是四步骤，都要先弹窗澄清，不靠漂亮版式掩盖含义差异。必要事实未答只阻塞依赖图。

## 逐图记录与交接

discovery.md保存sceneDistribution、合计N和实际回答/委托；layout-decisions.md逐ID记录sceneType、任务、canvas、类型细项及各自状态。四格逐格列明用途/顺序/状态，步骤列方法依据与连续变化，对比列变量/不变量与证据；整图像素、小格面积和商品实际尺度分别处理。

brief和最终prompt完整展开已选结构，不留“任选四个场景/自行安排步骤”给Lovart。改动类型/用途会影响文案、参考与画布密度时，一并更新下游内容。四宫格仍是一张图，A+也保留实际资产预算；未生成时只做设计检查，不声称画面或平台上传已验收。
