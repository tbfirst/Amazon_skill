# 参考继承强度、有限设计自由度与双向核对

参考路线、具体套图、逐图来源与继承强度分别确定。先实际查看并展示来源，再按[多轮沟通](discovery-layout.md)只问未定项。文字模板没有源图时记text-only，不冒称可完整继承某张未见画面。

## 两种继承方式

与植株版使用同一组选择，允许整套选择及逐ID例外：

- `reference-replace`：完整画面替换式适配。沿用选中源图的构图、场景关系、机位、裁切、分区、字体组合和光影；换成本品、准确文案及指定配色，执行必要适配和下节的有限调整。
- `structure-adapt`：排版结构适配。保留分区、阅读顺序、图文关系与信息层级，具体重定场景、道具、字体、配色、光影；每项写成唯一值，不交给生成器自由发挥。

新套和刷新都先展示选中源图，再用大白话实际弹窗选择：**“照着这张做，保留布景、道具关系、机位、排版和光影，主要替换我的商品与准确文案” / “保留排版，重新设计布景、机位和光影”**。分别记录reference-replace/structure-adapt；只选“竞品路线”或“四款组合”尚未回答程度，不能自动认定structure-adapt。已有“只换本品、小改”“只保留结构”或明确覆盖程度的设计委托直接沿用。旧记录的reference-adapt按实际内容解释，不扩大历史委托；含糊时只补问该项。

旧稿的`layout-rebuild / bounded-edit`与上述选择独立：重做旧稿也可完整继承新参考。实际上传清单分别命名商品来源、设计主参考和编辑底图，不能含糊写“保持原图”。

## 有限设计自由度

包括reference-replace在内，已选路线默认允许下列为更好展示本品的局部调整；不要求每图都改，不为范围内每个微调重复求许可。用户明确锁定的区域优先，具体改动在策划阶段定好：

|范围|允许的具体决定|不变的边界|
|---|---|---|
|可选道具配色|调整非随货、未锁定道具的明度/色相，使本品轮廓更清楚|商品本色、包装版本、固定或随货组件不随场景改色；不能以不透明遮掩不合理接口/容纳|
|机位与景别|在保留主要构图关系内适度移动相机，展示已有资料支持的表面|相机移动与产品转向分别处理；不能生成未知背面、内部或接口，不能靠扭曲实物补透视|
|少量装饰与类似替换|选择用途、体量或视觉作用相近的从属物件，保留原支撑/空间层次|不遮关键部位，不增加假随货、性能暗示、品牌或口号；对象适配及真实数量仍需依据|

记录“源值→选定值→展示目的”，例如背景托盘由暖白换为低饱和灰蓝以分离白色商品；重算反光、透视、接触与投影。改变后若主要分区、场景和光影都重新设计，按structure-adapt讨论，不再称完整继承。不用固定改动数量或角度阈值代替判断。

商品事实与物理适配、明确用户锁定、选中来源/强度、自主设计默认依次约束。图内文字的背景融合按[背景规则](background-copy.md)执行：默认自然背景直接落字，源底板/羽化须按已确认例外处理；不借这一适配重做其余构图。保留源字形组合不等于复制竞品原句、品牌或参数，也不能自动回答本品是否要字。

## 每张图的迁移约定

在layout-decisions和brief记录实际源ASIN/变体/区段/图序/文件、已看范围、目标ID、保留/替换/必要适配三列；另列窗口数/形状、区域归属、文字层级、主光、实际承影面及关键空间关系。按[视觉结构分析](complex-layout-analysis.md)从整体到局部再核整体，不凭缩略图猜字库或细节。

生成工具输入必须真的包含清单中的参考。URL、内部ID或聊天里看过不等于工具收到该图；不可用时保留具体文字蓝图并标text-only adaptation，与用户处理尚未授权的来源变化，不假称已视觉替换。本品实拍只控制身份，竞品图只控制已列设计关系，旧图只提供清楚可靠的商品区域或指定编辑底图。

### 高保真替换的实际输入与保持项

“一比一/照着做”落实为可核对的保持项，不承诺逐像素相同，也不主动降级成只借信息任务：

|应保留的关系|需要换的内容|必要适配|
|---|---|---|
|源图全貌/近拍比例、视窗形状/数量、分区与阅读顺序|本品真实轮廓、数量、状态与部件|因画布比例/本品外形改变局部边距，不把复杂源图简化成通用左字右物|
|实际场所、建筑锚点、前中后景、使用对象/道具的位置与动作|无法适配本品的配套物、人物身份与品牌|使用证据不足先补问；保留可行部分，不默认删光互动与装饰|
|机位高度/侧向、景别、主体占比、光向/软硬、明暗层次和承影面|本SKU实际反射/材质表现|随物理支撑重算接触影，不自动统一成浅墙左柔光|
|文字层级、字形组合、图形点缀与对齐节奏|准确英文、事实参数、品牌与专属图案|文字按背景融合的已定规则调整承载面，不能借此把其余画面重做|

选中后在上传清单放入该图的**清晰完整竞品图**，角色layout；联系表用来选源，不替代逐图附件。先打开完整原图反推，若只有联系表，先补原图再做精细复刻。sourceReference必须指向实际上传文件，不能把“出处为ASIN/G02，无需源图”写进竞品执行稿。文字降级需说明缺图原因并取得该范围的明确选择/委托，降低保真声明，不将其伪装成视觉替换。

若后来另外授权生图，仍要把layout附件实际传给工具；无字图也必须传，不从身份图自行猜竞品布景。成图只改变了背景色或文字、不再能辨认源图的主要关系时，定位差异后修订，不能写“一比一复刻完成”。

## 对照与修订

交付前逐项核对“实际源属性→用户回答/委托→本图决定→prompt/附件”，包括骨架、图层、文字、尺度/数量、机位、光向、明暗及投影。再反向查本图每条指令是否有本品依据或明确设计决定，不以颜色相似代替结构继承。

无字图不能因统一字形而加标题；单张源图的底板、窗形或光效不自动扩散全套。若用户回传成图，定位具体错误区域并修改对应指令，保留正确部分和旧revision。策略阶段只标design-checked; render-unverified，不宣称精确计数、字体渲染或相似度已验收。
