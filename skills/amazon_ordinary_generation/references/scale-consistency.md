# 整套尺度与适配一致性

出现使用者、配套对象或熟悉大小的参照物时读取。单张看似合理的布景，跨图可能暗示不同的产品大小、容量或适用对象；“在旁边、未接触”也可能形成这种暗示。保持同一SKU的物理尺寸与适配逻辑，同时保留多机位、多场所、动作、主题道具/图形和时段变化。

## 先定共用尺度，再分配变化

在layout-decisions保存简短的`scalePlan`，仅记录本项目有关的内容：

- **商品基准**：SKU/变体、已知尺寸及测量状态；尺寸、内外净空、容量、兼容与实际使用范围分别取证。不能从外尺寸推内净空，不能从生成图反推尺寸。
- **对象范围**：谁/什么会被买家理解为本品使用对象或配套物；确定与任务相关的体量、规格或姿态，以及依据。人物/宠物用身体尺度与体态描述，不只写年龄/品种名；设备、内容物用相关尺寸/型号，不只写“小型”。有实测值才写精确数字，普通布景不索要无关精密测量。
- **跨图不变项**：同一SKU的物理比例、对象的相关体型/规格范围、配套数量和支持的关系。不同人物、动物或物件可以出现，但不能无依据跨越体量/规格范围；无需机械锁成同一个个体或同一套道具。
- **允许变化项**：场所、机位、裁切、距离、时段、光影、姿态与不同主题装饰。必要的状态变化遵循已有实拍。多尺寸/多用途确有依据时可展示不同对象，按实际SKU/用途清楚映射，不强行缩成单一范围。

事实不够时只补问依赖项。用户授权自主选择对象不等于获得容纳、穿戴或兼容证据；可在授权范围内选保守且一致的体量，安排不暗示已证适配的场景，保留未知项。不靠“对象在旁边”或小字说明挽救明显冲突的尺度暗示，也不因此删掉全套使用者。

## 选源与逐图转译

1. 将源图中的使用者、内容物、配套物、熟悉大小的布景以及插图，分别标为实际使用、尺度参照、情境装饰或纯图形。主题装饰也需检查是否会被读成适配范围。
2. 对照本品与共用尺度约定，决定保留或换成体量/规格相符的对象。reference-replace仍保留场景、位置、动作关系、机位与光影；竞品中的对象体型、配套规格和适用范围不能自动继承。常规未锁定对象的必要适配记入替换项，不重复求许可；若用户明确锁定的对象与本品冲突，说明具体冲突再问。
3. 每图独立prompt正向写清本图对象的具体体量/规格、姿态、位置、相对深度、接触/支撑及与产品的关系，并展开本图相关的共用尺度约束。不要只写“尺寸合适”“同其他图”或在总策略中约束而单图遗漏。源图有明显冲突对象时，额外指出该对象须替换，不让生成器照搬。
4. 商品尺寸保持真实；对象也保持自然体态与规格。不得把真实的大对象缩成玩具、放大产品、拉伸外形或伪造内部空间来满足构图。需要腾空间时调整布景、站位或相机。远近透视引起的像素差异不是实物变大变小。

## 图形与整套核对

线描、剪影和主题图标可以是非比例装饰，但不能配合尺寸线、品种/型号名称或选择文案，暗示未证适配；有此风险时换成不指向错误对象的通用主题图形。无需将纯装饰绘成实物比例，也不应全删图形。

交付前将所有相关ID及拼图每格放在同一尺度表：商品基准→对象与尺度描述→角色/状态→位置与深度→源图替换项→本图约束。查是否有单张突然换成明显更大/更小的使用者、不同规格配套物，或让同一SKU看似换了尺寸；不只比较SCENE与SCENE，DETAIL/A+中的从属区域也要查。

若另获授权生图，实际结果先做单图核对，再并排检查整套，包括模型自行新增的对象。按已知尺寸、姿态、支撑面、相对深度和透视判断，不能直接用不同镜头的像素高度比或编造统一比例阈值。发现冲突先修正该对象或其位置，保留有效的构图、场景、文案与光影；保留旧revision，复核受影响图与全套。未看实图时只记规划已检查，不宣称生成尺度已验收。
