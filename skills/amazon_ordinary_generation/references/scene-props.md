# 欧美场景与配套道具

默认面向Amazon欧美市场，先使用所选竞品实际场景，保留成功的空间、主体位置、阅读顺序和光影；具体替换少量装饰、文案、配色与有证据支持的机位。参考中不适合目标站点的建筑或标识改为当地可信环境。默认不出现中国大陆高层住宅群、中文店招等与目标市场不匹配的背景；这是地点设定，不限制人物族裔。明确的项目地域要求优先。

## 无足够竞品时的文字场景候选

这些是原创设计方向，不是内置图片或已观察竞品。按SKU用途从约6–10个候选中筛选，范围窄时少列；不增加11图预算。SCENE与场景型A+共同安排，避免全套重复同一墙角。

|环境|可用空间锚点|可能适用任务|
|---|---|---|
|美式客厅|沙发边、踢脚线、木地板、自然窗光|家具式狗笼、边桌、收纳|
|欧美卧室|床侧、地毯、床头灯、柔和晨光|床边用品、收纳|
|玄关/家庭工作区|入户门、窄桌、书架或书桌|出门携带、卡套、办公整理|
|厨房/餐区|橱柜台面、餐桌、窗边|适用的餐厨产品，核接触与用途|
|车库/工作间|工作台、工具墙、地面分区|有据的工具/安装任务|
|门廊/遮蔽露台|低层住宅门廊、木平台、庭院纵深|明确支持此摆放条件的商品|

每个候选写地点、任务、室内外、时间光线、机位、产品状态、道具、来源或原创标签及淘汰理由。室内外都主动考虑，但室内专用品不为丰富场景而搬到雨中；A+不是室内场景的同义词。保留足够建筑纵深，不用巨大空墙替代场景。

## 配套物与使用状态

允许少量符合真实使用的配套道具，默认不需要逐件求许可；对适用性、尺寸、数量、销售包含关系或动作有疑问时立即弹窗。道具不能改变产品结构或暗示未证功能。记录 propRole、quantity、sizeBasis、position、interaction、includedInSale、evidence，未知不要由生成模型猜。

- 狗窝/狗笼可安排一只尺寸合适的狗自然躺卧。以有效内部净空与狗的体型/姿态核对，不能只凭外尺寸或犬种名保证适配，不挤压头部、穿栏或遮挡门与关键结构。净空/是否允许内部展示不明，弹窗问；等待时可继续空笼视角。
- 卡套可放适配尺寸、数量的普通示意卡，明确插入方向和露出部分；不得超过已知容量、误画银行卡敏感信息或自动增加透明卡槽。可用无品牌、无真实个人信息的卡片。容量、卡片规格或插槽机制未知时弹窗。
- 道具与产品分别计数，不将装饰物变成附赠物。有随货误解时优先调整画面，再按需要清楚说明不包含；明显宠物使用场景无需机械加入“狗不附赠”。
