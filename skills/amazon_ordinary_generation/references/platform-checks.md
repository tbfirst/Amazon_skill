# 当前Amazon规则核查

每个正式项目检查实际站点、类目、MAIN/附图/A+角色与账户模块；记录访问日期、原文来源、适用范围、可读部分和未核项。不要永久记住某次网页或论坛帖的像素规则。官方帮助正文优先于论坛讨论、营销文章与第三方汇总。

广泛类目覆盖不等于所有商品共用同一拍摄规范。按实际商品和拟展示内容查对应类目差异，例如服饰尺码/模特图、包装标签/内容物、电子兼容/规格、受证明要求约束的功能声明；仅在被触发时核查，不给普通装饰品附加不相关认证清单。没有当前类目来源时保留待核，不从邻近类目或某竞品图片推定适用。

2026-10-29建立技能时，前两个官方帮助页面的公开检索文本可读；未进入卖家账户检查模块和上传。以下仅为保守规划摘要，正式交付需重查：

- MAIN展示准确真实商品、颜色/数量/比例；检查白背景、完整商品、画面覆盖、文字与额外道具限制及类目例外。主图不沿用附图信息海报做法。
- 附图可用于用途、细节和尺寸说明，但不能混入伪造评分、客户评论截图、Amazon徽章/商标、价格促销等不合规元素。具体规则以当前角色与类目为准。
- A+需拥有使用文字与图片的必要权利；核实声明、奖项、保修/退款、外链/促销等限制。研究竞品广告不等于获得其品牌或摄影资产的使用权。
- 生成写实人物时核对平台当前披露/元数据要求；此skill只记录后续上传检查项，不替用户完成上传或承诺平台自动处理。

1464×600是设计母版默认。Basic/Premium、桌面/移动的真实图位与原生文字不同，未知时标uploadReview=pending并保持PROVISIONAL，不阻塞所有设计。遇到账户未开放某模块时重新映射既有资产，不捏造资格/额外ASIN。

无法核实规则时记录policyReview=pending、采用保守方案，清楚说明未验证范围；竞品正在使用某个图不等于该图合规或我们的账户会通过。
