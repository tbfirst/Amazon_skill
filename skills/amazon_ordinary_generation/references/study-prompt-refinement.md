# 榜单研究的逐图精修与恢复

仅用于 `ranked-reference-study`；先按 [参考改造](reference-redesign.md) 核实榜单与逐图覆盖。本页补充如何把实际观察转成质量明确、可恢复的研究prompt，不改变生产套图的事实与READY标准。

## 保留表达作用，再确定新的拍摄或版式

每图先写一个可检查的表达目标，例如“同时看清全貌与接触点”，而不是“高端、专业、8K”。把源图的成功关系落实到明确视图和区域：哪个对象最大、细节窗显示哪个真实部件、箭头连接什么、文字先读哪一层。

摄影图写清可见角度和透视、产品与支撑面接触、主光大小/方向、材质反射、阴影与主体分离。产品完整性与关键细节清晰优先；不靠极浅景深、过曝高光或夸大悬浮提高“高级感”。参考有柔光不代表目标必须使用同一场景。

平面规格表、线图和说明图按信息设计精修，机位/摄影布景可记 `not-applicable`。不要为满足“改角度”把二维尺寸图变成透视畸变图，或给白底主图增加不适用装饰。尺寸线必须对应测量轴与状态；不能用改变机位伪造容量、体积差或尺度。

改造卡须形成一个确定方向：背景/强调/文字的实际颜色，主体区域与留白位置，证据支持的取景，重新选择的从属道具或无道具决定，光影与文案层级。商品本色、标签、零件和套装数量不随美术方向改变。缺失的背部、内部或使用动作不是可自由改造的区域。

若保留“比较”的任务，比较对象、基线和条件也必须成立；若源图用表格或数字表达功能，不能改成只有氛围的生活方式图后仍声称保留其功能。跨SKU练习未知数据时，转为ADAPTATION_RECIPE并明确待映射项，不给变量配方标可执行状态。

## 单图精修审查

1. **源→描述**：原图确实目视；顺序/变体明确；可见的视图数、尺度关系、文字任务与描述吻合。看不清的小字保持unknown，不从同类商品补齐。
2. **描述→新设计**：保留的任务在新区域中仍读得懂；更改的是具体构图/调色/机位/场景等适用元素；允许保留同一成熟布景与版式，替换产品并按实际需要做具体局部修改，不以重做构图作为通过条件。
3. **身份→画面**：每件实物、开合/连接状态、标签和销售数量有参考支撑；道具边界清楚；重复视图明确为同款不同视图，不暗示多件装。
4. **决定→prompt**：只保留一个方向，包含实际输出比例、上传顺序和参考作用；具体copy逐条列出，不把观察卡的unknown或内部ID当生成器指令。不写“same as above”。
5. **文字→验证结论**：静态审查只说明prompt一致性；没有生成结果就记录 `generationValidation: not-run`，不能声称商业摄影质量、还原度或功能表达效果已验证。

失败只回退受影响的一图：观察不足则停在discovered/downloaded，保留文件待目视；缺SKU事实则保留观察和改造卡并转配方；prompt与决定冲突则修订prompt。不要用通用提示词覆盖原失败记录，也不要把未看图的商品计入逐图完成数。

## 恢复记录

项目JSON与原图放在研究输出目录，不把整批下载图片塞进skill。每个榜单保留URL、节点/层级、实际采集时间和源页快照路径；每款记录原始排名、ASIN/变体、纳入或排除原因；逐图至少保存以下字段：

```json
{
  "imageId": "项目内唯一ID",
  "section": "gallery 或 aplus",
  "sourceOrdinal": 1,
  "sourceUrl": "实际图片URL",
  "localPath": "项目内图片路径或null",
  "status": "discovered / downloaded / visually-reviewed / reverse-analyzed / redesign-written / prompt-reviewed",
  "observation": null,
  "retainedRelationships": [],
  "redesignedElements": {},
  "removedSourceIdentity": [],
  "productLocks": [],
  "promptKind": "STUDY_VARIANT 或 ADAPTATION_RECIPE",
  "promptPath": null,
  "review": {"sourceMatch": "pending", "redesignCoherence": "pending", "identityIntegrity": "pending"},
  "generationValidation": "not-run",
  "gaps": []
}
```

这是字段说明，不是已完成项目。状态推进以实际动作发生为准；源图替换、变体变化或文件失效时，保留旧revision并使依赖观察/审查失效。恢复时从最后真实检查点继续。索引分别汇总榜单已核产品数、已下载/目视/反推/精修图数、gallery/A+覆盖与缺口；“30款已发现”不等于“30套已研究完成”。
