# 多图产品状态确认

固定外观的空间关系不唯一、单图遮挡或新机位缺证时，先按[外观歧义与视角证据确认](appearance-evidence.md)核对；不能把所有差异解释为状态变化。

先按用户上传顺序记录每张图的主体、固定部件、可动部件、遮挡、机位和可能状态。同一商品可以有展开、折叠、拆装、打开、关闭或收纳状态；外观差异不能自动判定为两个SKU，也不能自动解释为可折叠。

当身份、部件消失、功能、动作或图间关系有任何疑问或异议，立即使用可用文字弹窗询问。例：“图1有前挡板，图2正面开放，这两张是同一产品挡板展开/折叠的状态，还是不同款？若为同款，挡板折叠后位于哪里？”给出同款不同状态/不同款/尚不能确认等真实选项；预选不算回答。无弹窗工具则在聊天询问，不默默猜测。

确认后记录 image → SKU → state → 部件位置 → 允许动作 → 证据/用户回答。固定身份与可变状态分开锁定；每张brief与独立prompt写出选用状态、应显示和收起的部件及位置，不用全局“所有图部件必须始终可见”破坏功能展示。

未答只阻塞依赖该差异的图，继续竞品研究及确定视角的图。用户确认功能但缺少动作几何时，继续问必要位置或在聊天索取细节；不发明铰链、拆卸方式、未知背面。已明确回答不重复询问。
